## 새 기능

### 터미널에서 파일 바로 열기
- `ls` 결과나 로그에 찍힌 파일·폴더 이름을 우클릭하면 메뉴 맨 위에 그 파일의 동작이 나옵니다: 미리보기, 편집, 실시간 보기, 다운로드, SFTP 에서 위치 열기, 경로 복사. 폴더는 SFTP 에서 열기와 `cd` 입력.
- 이름에 마우스를 올리면 밑줄이 생깁니다. `Ctrl+클릭` 으로 바로 편집 창을 엽니다.
- `편의` 메뉴의 `SFTP 를 현재 폴더로`: SFTP 패널을 터미널이 있는 폴더로 엽니다.

### 세션 연결 정보 공유
- 사이드바의 세션·폴더를 우클릭해 연결 정보를 텍스트로 복사하고, 받은 사람은 `텍스트로 세션 추가` 로 붙여 넣어 자기 세션으로 추가합니다.
- 비밀번호는 `비밀번호 포함 복사…` 를 고르고 공유 암호를 정했을 때만 암호화되어 들어갑니다.

### 터미널 우클릭 메뉴
- `스니펫` 에서 바로 스니펫을 추가하고 관리합니다. 글자를 선택한 채로 열면 그 글자가 명령으로 들어갑니다.
- `편의`, `세션` 메뉴를 종류별로 구분선으로 나눴습니다.

### 서버 파일 편집
- 백업 비교 화면에 `스크롤 동기화` 와 화면 아래 공용 가로 스크롤 막대를 추가했습니다.
- 서버의 백업 파일을 더 많이 인식합니다: `index.jsp.261102`, `index.jsp_bak`, `index_261102.jsp`, `bak_index.jsp`, `index (1).jsp` 등.
- `.env`, `.conf`, systemd 유닛 같은 설정 파일에 문법 강조를 넣었습니다 (주석은 흐리게, 키는 강조). 백업 파일도 원래 파일과 같은 강조를 받습니다.
- 백업 패널의 안내 문구를 읽기 쉽게 정리했습니다.

### 업데이트와 창
- 업데이트 설치가 설치 화면 없이 진행되고 끝나면 앱이 다시 열립니다. 이번 버전으로 올라온 뒤의 업데이트부터 적용됩니다.
- 앱을 닫을 때의 창 위치와 크기를 기억합니다.

## 개선
- 파일이 많은 폴더: SFTP 목록이 보이는 줄만 그려서 2만 개 폴더도 멈추지 않습니다. 읽는 동안 "불러오는 중… N개" 를 보여 줍니다. 터미널 왼쪽 탐색기는 300개씩 나눠 보여 줍니다.
- 스니펫 추가 창을 한글로 바꿨습니다.
- DB 계정 창이 좁은 창에서 버튼이 잘리지 않습니다.
