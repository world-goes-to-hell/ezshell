## 새 기능

### 터미널 우클릭 메뉴
- 터미널(분할 셸 포함)에서 우클릭하면 메뉴가 뜹니다: 복사, 붙여넣기, 그리고 `분할` / `편의` / `세션` 하위 메뉴.
- **분할**: 좌우 분할, 상하 분할, 4분할, 분할 해제
- **편의**: 이름 찾기, 내용 찾기, 화면에서 찾기, 화면 지우기, 파일 탐색기
- **세션**: 탭 복제, 로그 저장 시작/중지, SFTP, 연결 종료
- 이름 찾기·내용 찾기는 `find` / `grep` 명령을 만들어 터미널 입력줄에 채워 넣습니다. 찾을 위치는 현재 폴더 / 루트(/) / 폴더 지정 중에서 고르고, 실행은 Enter 로 직접 합니다.

### 사이드바
- 줄 배경색 대신 폴더 색을 선 하나로 표시하고, 기본 아이콘 자리에 연결 상태 점을 둡니다.
- 접힌 상태에서 마우스를 올리면 전체 사이드바가 터미널 위로 겹쳐서 열립니다. 줄임말 타일은 없앴습니다.
- 접기·펼치기 버튼 아이콘이 상태마다 다릅니다.
- 세션에 마우스를 올리면 접속 정보를 자세히 보여 줍니다.

### 서버 파일 편집
- 백업을 좌우로 비교하고, 바뀐 부분마다 화살표로 백업 내용을 가져올 수 있습니다.
- 서버에 사람이 만든 백업 파일(`.bak`, 날짜가 붙은 파일 등)도 백업 목록에 보입니다.

### 그 밖에
- 실시간 보기: 로그가 나오는 동안에는 더 자주 확인해서 `tail -f` 에 가깝게 따라갑니다. 오류·경고 개수를 눌러 해당 줄로 이동합니다.
- MCP 확인 창: 명령을 MCP 활동 패널처럼 줄을 나누고 색을 입혀 보여 줍니다 (`원문 보기` 로 전환).
- DB: 서버에 별칭을 붙일 수 있습니다.
- 탭 우클릭 메뉴에 `왼쪽 탭 닫기` 추가, 터미널 파일 탐색기 너비 조절.

## 수정
- 커스텀 테마 만들기 창이 잘려 보이던 문제
- 큰 파일을 편집할 때 스크롤이 끊기던 문제 (1MB 를 넘는 파일은 문법 강조를 끕니다)
- 경고 개수는 표시되는데 경고 줄로 이동할 수 없던 문제
- DB 계정 창의 버튼 위치와 글자 정렬
