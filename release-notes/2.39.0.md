## 하위 Git 저장소

- 로컬 작업 아래에 있는 Git 저장소들을 찾아, 브랜치·받을 커밋·수정 중 여부를 사이드바에 보여 줍니다.
- **모두 최신으로**(빠른 감기만)와 **브랜치 바꾸기**(로컬·원격 추적 브랜치)를 지원합니다.
- 원격 자동 확인은 믿는 로컬 작업에서만 켤 수 있고, 기본은 꺼져 있습니다.

## 실행 구성의 기동 순서와 실행 묶음

- 실행 구성을 단계별로 띄웁니다. 같은 단계는 동시에 띄우고, 포트·로그 문구·헬스 URL 로 다음 단계로 넘어갈 때를 정합니다. 모두 중지는 역순으로 끕니다.
- **실행 묶음**으로 고른 구성만 기동 순서대로 실행할 수 있습니다.
- 워크트리 메뉴에서 찾은 기동 명령을 고르면, 값이 채워진 실행 구성 창이 열립니다. 직접 입력하는 실행도 찾은 명령이 미리 채워집니다.

## Claude 프로필

- 설정에서 Claude 프로필을 만들고, 새 에이전트와 채팅을 프로필별 계정으로 열 수 있습니다.

## 채팅 보기

- Claude 의 질문 카드에서 선택지를 가리킬 때마다 카드 높이가 바뀌고 선택지가 위아래로 움직이던 문제를 고쳤습니다. 이제 미리보기 칸의 크기가 고정됩니다.
- 플러그인 알림 상자가 질문 화면 위에 겹치면, 채팅에서 답한 뒤 터미널에서 다시 답해야 하던 문제를 고쳤습니다.
- CLI 가 띄운 화면을 터미널에서 다룬 뒤 채팅으로 돌아올 수 있습니다.
- 업데이트 뒤 Codex 채팅에서 "입력칸을 찾지 못했습니다"가 다시 나오던 문제를 고쳤습니다 (이 버전이 설치된 뒤 받는 다음 업데이트부터 효과가 있습니다).

## 그 밖의 변경

- 새 탭(+) 메뉴의 로컬 터미널이 작업 폴더에서 열립니다. 앞 탭이 하위 폴더에 있으면 그 폴더에서 여는 항목도 함께 보입니다.
- 프로젝트 검색이 검색어를 기억하고, 열었던 검색 기록을 보여 줍니다.
- 에이전트 기록에서 역할을 보고 검색할 수 있습니다.
- 빠른 캡처 바로작업, 브라우저 탭, 탭 복원의 에이전트 되살리기를 고쳤습니다.
- 다른 ezShell(개발용 실행 등)이 함께 켜질 때, 쓰던 로컬 셸을 가져가 버려 셸이 모두 꺼질 수 있던 문제를 막았습니다.
