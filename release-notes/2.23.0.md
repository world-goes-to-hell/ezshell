## 에이전트 채팅 보기

- 채팅 전용 테마를 고를 수 있습니다 (`카톡 모드`, `미드나잇`, `종이 노트`). 채팅 머리줄이나 설정에서 바꿉니다.
- 입력칸에 `/` 를 치면 슬래시 명령 목록이 뜹니다. 직접 만든 명령과 스킬도 나오고, `/config` 처럼 CLI 가 자기 화면을 여는 명령은 그 칸을 터미널로 돌려 조작하게 한 뒤 위의 `채팅으로` 띠로 돌아옵니다.
- 질문마다 쓴 토큰(입력·출력·캐시)과 걸린 시간, 그 질문이 쓴 5시간·주간 한도가 답변 아래에 보입니다.
- 지난 질문 목록을 열어 검색하고 그 질문으로 이동합니다.
- 서브에이전트가 하는 일을 채팅 안에서 보고, 서브에이전트 대화를 따로 열어 볼 수 있습니다.
- 이미지를 여러 장 첨부해 보낼 수 있습니다.
- 답변에 포인터를 올리고 `띄워 두기` 를 누르면 그 답변을 작은 별도 창으로 띄워 둡니다. 다른 탭(브라우저 탭 등)을 보면서 읽을 수 있고, `원래 대화로 가기` 로 그 채팅으로 돌아갑니다.

## 쉬는 에이전트

- 오래 쉬고 있는 Claude Code·Codex 의 메모리를 비워 PC 메모리를 돌려받습니다 (기본 10분). 설정 > MCP > 에이전트 메시지에서 바꿉니다.
- 셸에 직접 띄운 에이전트는 `잠재우기` 를 켜면 쉬는 동안 끄고, `깨우기` 를 누르거나 메시지가 오면 같은 대화로 다시 엽니다.

## 작업 개요와 사이드바

- `Tab` 을 빠르게 두 번 누르면 로컬 작업 개요가 열립니다. 다른 프로그램을 쓰고 있어도 ezShell 이 앞으로 오며 열립니다 (Windows).
- 사이드바 작업 트리에 그 작업의 브라우저·SSH·DB 탭도 보입니다. 세션 목록에서 연 SSH 탭은 `일반` 묶음에 들어갑니다.
- 작업 트리의 프로젝트 줄에 포인터를 올리면 나오는 X 로 목록에서 뺄 수 있습니다 (폴더와 열린 터미널은 그대로). 같은 저장소의 워크트리를 따로 등록해도 프로젝트가 하나로 보입니다.
- 탭에 워크트리 표지가 붙습니다.
- 로컬 작업 창이 `추가` 와 `열기` 두 모양으로 나뉘었습니다. 작업 목록 제목 줄의 `+` 로 폴더를 추가합니다.
- 세션 목록 빈 곳을 우클릭해 폴더나 세션을 추가합니다.

## 파일 창

- 여러 파일을 한 창의 탭으로 엽니다.
- 작업 공간 파일에서 `Git 비교` 로 이전 버전과 지금 내용을 나란히 봅니다.
- 단축키 설명을 창 안에서 볼 수 있습니다.
- 작업 공간의 파일 목록에서 이름·경로로 검색합니다.

## 브라우저 탭

- 브라우저에서 내보낸 비밀번호 CSV(Chrome·Edge·Firefox)를 가져와 로그인 입력란을 채웁니다. 로그인 정보는 마스터 비밀번호로 암호화해 저장합니다.
- 페이지 검토에서 보낸 요청의 상태(답장 대기·읽음·답장 도착 등)를 기록으로 봅니다.
- 설정에서 브라우저 탭 폭을 바꿉니다.
- 사이드바를 겹쳐 열었을 때 브라우저 페이지가 사이드바를 가리던 문제를 고쳤습니다.

## 그 밖에

- 설정에서 터미널이 보관할 출력 줄 수를 정합니다.
- 상태 줄의 UI 배율과 창 투명도를 같은 모양의 막대로 조절합니다.
- 칸을 끌어 옮긴 뒤 덮개가 남던 문제를 고쳤습니다.
