## 업데이트해도 작업 중인 셸이 이어집니다

- 이 버전부터 앱을 업데이트할 때 로컬 터미널의 셸이 끊기지 않습니다. 셸은 앱 밖의 보관 프로세스에서 계속 돌고, 업데이트한 앱이 다시 켜지면 같은 탭에 그대로 다시 붙습니다.
- 셸 안에서 일하던 Claude·Codex 에이전트도 같은 ID 로 이어집니다. 받은편지함과 역할이 남아 있고, 잠금을 풀면 업데이트 전처럼 메시지를 주고받습니다.
- 이 기능은 **2.37.0 이 설치된 상태에서 받는 다음 업데이트부터** 동작합니다. 이번 2.37.0 으로 올리는 업데이트에서는 예전처럼 셸이 닫힙니다.

## 로컬 프로젝트 실행 구성

- 사이드바 **로컬 작업**의 워크트리 카드에서 서버 실행 방법을 구성으로 저장하고, **기동**·**재기동**·**중지**·**모두 실행**을 할 수 있습니다. Spring Boot(Gradle·Maven), Node 개발 스크립트, 직접 입력한 명령, Tomcat 을 지원합니다.
- 서버가 실패하면 알림과 함께 오류 묶음과 진단(누락 클래스, JDK 버전, 포트, 인코딩, Maven 저장소 문제 등)이 카드에 보이고, 고칠 방법을 제안합니다. 오류 내용을 에이전트에게 바로 보낼 수도 있습니다.
- **바로 반영**을 켜면 Java 파일을 저장할 때 서버를 다시 띄우지 않고 실행 중인 서버에 반영합니다.
- Tomcat 은 구성마다 전용 설정으로 띄우고, 이클립스 프로젝트·워크스페이스의 서버 설정을 가져올 수 있습니다.
- 설정 > **개발 도구**에서 JDK, Tomcat·Maven·Ant·Gradle·Node 를 내려받거나 이 PC 에 설치된 것을 찾아 씁니다.
- 에이전트는 `run_list`·`run_start`·`run_log` 같은 도구로 저장된 구성을 다룰 수 있습니다. 구성마다 에이전트 조작을 허용할지 고를 수 있습니다.

## 그 밖의 변경

- 에이전트 메시지 MCP 를 Aside 브라우저에서도 쓸 수 있습니다.
- 포인터 효과를 다른 프로그램 위에서도 쓸 수 있습니다 (Windows, 포인터 효과 탭의 **다른 프로그램에서도 쓰기**).
- 터미널의 오류·경고 줄 강조가 채팅 보기 위로 비치던 문제를 고쳤습니다.
- 캡처 코멘트 칸이 더 커지고, 줄 수에 따라 늘어납니다.
