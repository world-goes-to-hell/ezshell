## 새 기능

### 다른 프로그램의 세션 가져오기
- 설정 > 세션 백업 > `다른 프로그램에서 가져오기…` 에서 **Xshell·Xftp·PuTTY·MobaXterm·Tabby·OpenSSH config** 의 세션을 옮겨 옵니다.
- 이 PC 에 설치된 프로그램은 자동으로 찾아 버튼으로 보여 주고, 다른 사람에게 받은 파일(`.xsh`, `.xts`, `.reg`, `.mxtsessions`, `config.yaml`, ssh `config`)은 `파일 고르기…` 로 엽니다.
- `내 세션 | 가져온 세션` 두 목록을 나란히 두고, 가져온 쪽의 폴더나 세션을 내 쪽 폴더 안이나 세션 사이에 끌어 놓아 원하는 자리에 넣습니다. `모두 적용` 은 체크한 세션을 `가져옴 - <프로그램>` 폴더 하나에 넣습니다. 내 쪽에서 `새 폴더` 도 만들 수 있습니다.
- 호스트·포트·계정·폴더 구조·점프 호스트·키 파일 경로를 가져옵니다. **저장된 비밀번호는 가져오지 않습니다.** 원래 프로그램에 비밀번호가 있었던 세션에는 `비밀번호 다시 입력` 표시가 붙습니다.
- 이미 있는 세션(같은 호스트·포트·계정)은 `이미 있음` 으로 표시되고 처음부터 체크가 꺼져 있습니다.
- Termius 는 읽을 수 있는 파일이 없어, OpenSSH config 로 내보낸 파일을 고르면 됩니다.

### SFTP 로컬 주소줄 바로 가기
- SFTP 패널의 내 PC 주소줄을 누르면 Windows 탐색기처럼 **바탕 화면·홈·문서·다운로드·사진·음악·동영상**과 **내 PC 의 드라이브**(이름 포함, 예: `새 볼륨 (D:)`)가 펼쳐집니다.
- 드라이브 선택 상자도 실제로 있는 드라이브만 보여 줍니다.

### Oracle 데이터베이스
- 서버에서 돌고 있는 Oracle 을 자동으로 찾아, 다른 DB 처럼 읽기 전용으로 조회합니다.
- 오래된 버전(11.2 이상)은 계정 화면의 버튼 한 번으로 접속용 구성 요소를 내려받아 연결합니다.

## 개선
- 사이드바를 접었을 때 누를 수 없던 버튼 대신, 연결된 탭 수(초록)·끊긴 탭 수(빨강)·진행 중인 MCP 요청 수(노랑)를 보여 줍니다.
- 터미널 아래쪽의 `SFTP` 버튼을 터미널 상단 머리줄(파일 탐색기 버튼 옆)로 옮겼습니다.
- 터미널 파일 영역 테두리를 `ls`·`ll` 같은 파일 목록 출력에만 그립니다 (`docker ps` 같은 출력에는 그리지 않습니다).
- MCP 활동에서 DB 조회나 `docker ps` 처럼 표로 나오는 출력이 줄바꿈 없이 칸을 맞춰 보이고, 좌우로 스크롤합니다 (한글 포함).
- 휴대폰 원격 접속: 인증 앱 코드로 접속하면 하루 동안 코드 없이 다시 들어옵니다. 로그인 화면의 체크로 끌 수 있습니다.

## 수정
- 자동 로그아웃(TMOUT)이 걸린 서버에서 셸이 끝났을 때 재연결을 반복하던 문제를 고쳤습니다.

## 보안
- 키 파일은 이 PC 의 경로만 읽습니다. 네트워크 경로(`\\서버\공유\...`)나 장치 경로로 된 키는 읽지 않고 다시 고르라고 알려 줍니다.
