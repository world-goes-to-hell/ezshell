## 새 기능

### 로컬 터미널
- 탭 줄의 `+` 메뉴와 시작 화면의 `로컬 터미널` 로 이 PC 의 PowerShell 을 탭으로 엽니다.
- 10개까지 열 수 있습니다. SFTP, 분할, 로그 저장, 탭 복제는 SSH 탭에서만 됩니다.

### 터미널 우클릭 메뉴
- `모두 선택`
- `편의` 에 `전체 출력 복사`, `출력을 파일로 저장…` (스크롤해서 지나간 출력까지 포함)
- `스니펫`: 저장한 스니펫을 입력줄에 넣습니다. 실행은 Enter 로 직접 합니다.
- 글자를 선택한 채로 이름 찾기·내용 찾기를 열면 선택한 글자가 찾을 말로 들어갑니다.

## 수정
- SFTP 목록에서 파일을 우클릭하고 `다운로드` 를 누르면 "다운로드할 파일 선택" 알림만 뜨던 문제 (`삭제`, `업로드` 도 같은 문제)
- SFTP 우클릭 메뉴가 창 아래쪽에서 포인터보다 한참 위에 뜨던 문제
