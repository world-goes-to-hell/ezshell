## MCP 설정

- 설정 > MCP 의 SSH MCP 자동 설정에서 에이전트를 고를 수 있습니다: Claude Code, Codex, Gemini CLI, OpenCode, Cursor. 고른 에이전트의 설정 파일 형식에 맞게 등록하고, 바꾸기 전에 원본을 백업합니다.
- 프로젝트 설정은 접속 토큰 대신 환경 변수 `EZSHELL_MCP_TOKEN` 을 참조합니다.

## 에이전트 채팅 보기

- Claude 가 선택지 질문을 하면 채팅 아래에 `답변 대기 중` 과 그 질문이 보이고, `질문에 답하기` 로 바로 답하러 갑니다.
- 분할한 칸의 배치 그림에서 칸마다 어떤 에이전트인지 알아봅니다. 칸을 누르면 답할 질문이 있는 칸은 그 질문으로 포커스가 갑니다.

## 그 밖에

- 에이전트 메시지 연결이 막 시작한 에이전트를 놓치던 경우를 고쳤습니다.
