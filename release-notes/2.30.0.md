## 에이전트 메시지

- 에이전트에 붙인 역할이 앱을 다시 켜도 남습니다. 같은 대화를 다시 열면 그 역할이 돌아오고, `/clear` 로 대화를 새로 시작해도 같은 칸의 역할은 이어집니다.
- 관계도를 **크게 보기** 로 창 가득 볼 수 있습니다. `Ctrl+휠` 로 확대·축소하고, 빈 곳을 끌어 옮기고, `화면에 맞추기`(`Ctrl+0`)로 모든 카드를 한눈에 봅니다. 오른쪽 메시지 패널은 접을 수 있습니다.
- 관계도에서 옮겨 둔 카드 자리를 기억합니다. 같은 대화를 다시 열면 그 자리에 나오고, `배치 초기화` 로 되돌립니다.
- 에이전트 안내(툴팁)가 이름·종류와 상태·위치 세 줄로 정리되었습니다.
- 메시지 기록의 머리줄이 누구의 메시지인지 이름으로 보여 주고, 보낸 말풍선에는 `→ 받는 에이전트` 가 붙습니다.
- 에이전트의 메시지 연결이 끊겨도(앱 재시작, `/mcp` 재연결) 스스로 다시 붙습니다. 같은 칸의 에이전트는 원래 이름을 그대로 씁니다.

## 에이전트 채팅 보기

- 답변 속 파일 링크의 미리보기가 앱 창 오른쪽에 **서랍** 으로 열립니다. 칸이 좁아도 채팅이 줄어들지 않고, `Esc`·바깥 클릭으로 닫습니다.
- 말풍선에 마우스를 올리면 시각이 말풍선 옆 같은 자리에 나옵니다. 시각을 가리키면 날짜와 초까지 보입니다.
- `답장`·`띄워 두기` 버튼이 짧은 답변의 글자를 가리지 않습니다.
- Codex 의 `/mcp` 결과가 서버 카드로 보입니다. 연결 상태와 도구 수를 보여 주고, `자세히 보기` 와 인증이 필요한 서버의 `로그인` 을 바로 누를 수 있습니다.
- Codex 슬래시 명령의 출력에 앞 화면의 내용이 섞이던 문제를 고쳤습니다.

## 테마

- 설정 > 테마 에 **마우스 포인터** 가 생겼습니다. 큼직한 화살표·고대비·정밀 같은 실용 모양부터 고양이 발바닥·말랑 젤리·반짝 별·하트·픽셀 레트로까지 9가지와 크기 3단계를 고릅니다.
- **마우스 효과** 를 움직일 때(별가루·무지개·혜성 꼬리, 비눗방울, 벚꽃, 고양이 발자국 등)와 누를 때(물결, 하트 퐁, 폭죽, 별 팡, `톡!` 등)로 나눠 고르고, 터미널 위에서 켤지 정합니다. 처음에는 모두 꺼져 있습니다.
- 영역 캡처의 도구 막대·코멘트 상자가 앱 테마 색을 따릅니다.
- 앱을 켤 때 나오는 시작 화면의 창 모양이 테마를 따릅니다. macOS 테마가 아니면 창 버튼이 오른쪽에 그려집니다.
