## 바이트 데몬

- 상태 줄 맨 오른쪽에 작은 데몬이 숨어 있습니다. 누르면 잠깐 즐길 수 있는 미니 게임 창이 열립니다.
- 미니 게임 셋: **오류 잡기**(로그 줄을 기어가는 벌레 잡기), **명령어 타자**(나오는 명령을 그대로 빠르게 치기), **금요일 배포**(판돈을 걸고 어디서 멈출지 고르기).
- 게임과 데몬 쓰다듬기로 바이트를 모아 생산자(메모지 요정, 시계 고양이, 고무 오리 등)를 사면, 창을 닫아 둔 동안에도 바이트가 쌓입니다(최대 8시간).
- 창의 색과 모양은 지금 쓰는 테마를 따릅니다. 아이콘을 숨기려면 명령 팔레트에서 `미니 게임 아이콘 숨기기` 를 고르세요.

## 작업 개요

- 작업 개요(로컬 작업 현황)를 여는 키가 `Tab` 두 번에서 `Ctrl+Alt+Space` 로 바뀌었습니다. 터미널에서 Tab 두 번으로 자동완성을 하다가 개요가 열리던 문제가 없어졌습니다.
- 설정 > 키보드 단축키에서 이 키를 바꿀 수 있습니다. 다른 프로그램을 쓰는 중에도 동작합니다.

## 영역 캡처

- 캡처 편집 화면의 `추가 캡처` 로 여러 장을 이어서 찍고, 썸네일을 보며 고친 뒤 한 번에 `복사` 하거나 `바로작업` 으로 보낼 수 있습니다(최대 8장).
- Esc 로 캡처를 닫을 때 "화면을 캡처하지 못했습니다" 알림이 뜨던 문제와, 끌어서 고른 영역이 가끔 선택되지 않던 문제를 고쳤습니다.

## 에이전트 채팅 보기

- 채팅에 첨부한 이미지를 누르면 크게 볼 수 있습니다.
- 답변 속 작업 폴더의 HTML 파일 링크를 `브라우저로 열기` 로 브라우저 탭에서 볼 수 있습니다.
- 끝난 서브에이전트가 `작업 중` 으로 계속 남아 있던 문제를 고쳤습니다.

## 작업 공간

- 파일 검색이 훨씬 빨라졌습니다(처음 검색 약 10배, 다시 검색은 바로). 폴더가 바뀌면 목록도 따라 바뀝니다.
- `node_modules`·`build`·`dist` 같은 설치·빌드 폴더의 안은 기본으로 검색하지 않습니다. 필요하면 결과 아래 `포함해서 검색` 을 누르세요.

## 그 밖

- 브라우저 탭의 즐겨찾기 화면을 폴더 트리 모양으로 정리했습니다. 줄이 낮아져 한눈에 더 많이 보입니다.
- 접힌 사이드바가 브라우저 탭을 연결된 SSH 세션 수에 넣어 세던 문제를 고쳤습니다.
