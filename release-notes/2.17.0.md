## 새 기능

### 휴대폰에서 MCP 확인 요청에 답하기
- Claude 의 확인 요청이 PC 확인 창과 함께, 원격 접속으로 들어와 있는 휴대폰에도 뜹니다. 휴대폰에서 `허용` / `거부` 를 누르면 PC 창도 닫힙니다.
- 휴대폰에 보이는 내용은 PC 확인 창과 같습니다 (세션, 요청 사유, 위치, 명령 원문, 위험도, 파일 변경 내용).
- 명령이 길어 다 보이지 않으면 끝까지 내려 봐야 `허용` 이 켜집니다.
- 휴대폰이 접속해 있거나 알림을 받을 수 있는 동안에는 답을 기다리는 시간이 60초에서 **4분**으로 늘어납니다.
- 누가 답했는지는 감사 로그에 남습니다. 설정 > `원격 접속` 의 `휴대폰에서도 확인 요청에 답하기` 로 끌 수 있습니다.

### 휴대폰 알림
- 확인 요청에 PC 에서 15초 안에 답하지 않으면 휴대폰에 알림이 옵니다 (PC 를 1분 넘게 쓰지 않고 있으면 바로). 브라우저를 닫아 두어도 옵니다.
- 알림에는 요청 종류와 위험도만 들어갑니다. 명령, 경로, 세션 이름은 넣지 않습니다.
- 알림을 쓰려면 Tailscale 관리 화면에서 **HTTPS 인증서**를 켜야 합니다. 켜면 원격 접속 주소가 `https://<PC 이름>.<tailnet>.ts.net:8722` 로 바뀌므로 휴대폰을 한 번 다시 등록하고, 휴대폰 페이지에서 `알림 켜기` 를 누르세요.
- 켜지 않으면 지금처럼 동작하고 알림만 없습니다.

### 휴대폰에서 MCP 활동 보기
- 휴대폰 페이지의 `MCP 활동` 에서 요청 목록과 상태, 명령과 출력을 시간순으로 봅니다. 실행 중인 요청은 `중지` 할 수 있습니다.

### 휴대폰 세션 목록
- PC 사이드바와 같은 폴더 구조, 폴더 색과 세션 색, 순서로 보입니다. 폴더를 접고 펼 수 있습니다.

## 개선
- 명령 팔레트의 `업데이트 내용 보기` 가 최근 10개 버전의 이력을 보여 줍니다.
- 터미널 파일 영역 테두리가 명령마다 따로 그려집니다. `ls ../` 나 `ll /var/log` 처럼 다른 폴더를 나열하면 그 폴더 기준으로 파일을 찾습니다.

## 수정
- `cd` 한 뒤에도 이전 출력에 새 폴더 이름의 테두리가 남던 문제를 고쳤습니다.
- `cd` 만 했는데 그 줄에 테두리가 생기던 문제를 고쳤습니다.
- 휴대폰 세션 목록에서 이름 없는 세션이 서버 주소로 표시되던 것을 고쳤습니다.
