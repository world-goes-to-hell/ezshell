## 프로젝트 검색

- **Shift 를 빠르게 두 번** 누르면 앞에 있는 로컬 탭의 프로젝트에서 **파일 이름**으로 찾습니다.
- **Ctrl+Shift+F** 로 프로젝트의 **파일 내용**을 찾습니다. 결과는 파일별로 묶이고, 줄 번호와 찾은 글자가 강조됩니다. 대소문자 구분을 켤 수 있습니다.
- Enter 로 파일 창에서 열고, 내용 결과는 그 줄로 바로 갑니다. 터미널에 입력하던 중에도 동작하며, `node_modules` 같은 설치·빌드 폴더와 Git 이 무시하는 파일은 빠집니다.

## 에이전트 작업 중 표시와 CPU

- 에이전트가 일하는 동안 칸과 사이드바에 보이는 표시를 설정 > 테마 > **창 효과**에서 고를 수 있습니다: 안쪽 번짐(기본), 테두리 깜빡임, 도는 빛, 움직이지 않음.
- 지금까지의 **도는 빛**은 작업 중인 곳마다 화면을 계속 다시 그려, 에이전트가 여럿이면 CPU 를 많이 썼습니다. 기본값을 훨씬 가벼운 안쪽 번짐으로 바꿨습니다.

## 업데이트해도 셸이 이어지는 기능 고침

- 업데이트 뒤 같은 세션 탭이 두 개씩 생기고, 채팅으로 보던 칸이 터미널로 돌아오던 문제를 고쳤습니다.
- 업데이트 뒤 채팅에서 보낼 때 "에이전트의 입력칸을 찾지 못했습니다"가 나오고 터미널을 한 번 봐야 동작하던 문제를 고쳤습니다.
- 이 고침은 이 버전이 설치된 뒤 받는 다음 업데이트부터 효과가 있습니다.

## 다른 프로그램 위 포인터 효과

- 빠르게 움직일 때 입자가 띄엄띄엄 생기던 것을 앱 안처럼 촘촘하게 채웠고, 꼬리가 꺾인 직선 대신 곡선으로 이어집니다.
- 멈췄다가 움직일 때 효과가 늦게 시작하던 것을 줄였습니다.

## 브라우저 탭

- 주소창에 입력하면 방문 기록과 즐겨찾기에서 주소를 자동완성합니다.
- 로그인 상태 유지가 기본으로 켜져, 앱을 다시 시작해도 로그인이 풀리지 않습니다.
- 요소 수정 요청을 보낼 때 프로젝트를 먼저 고르고 그 프로젝트의 에이전트를 고릅니다.

## 그 밖의 변경

- 에이전트 CLI 가 스스로 띄운 질문 화면이 채팅 보기에서도 보입니다.
- 설정 > 개발 도구 탭을 JDK, 확장 바로 반영, 빌드·실행 도구 카드로 정리했습니다.
- 사이드바 실행 구성 줄에서 버튼이 잘리던 문제를 고쳤습니다. 포트 표시를 누르면 브라우저로 열립니다.
- 바로작업의 프로젝트 목록을 저장소마다 하나로 묶었습니다.
