## 업데이트

- 업데이트 뒤 사이드바의 탭마다 같은 에이전트가 둘씩 보이던 문제를 고쳤습니다. 셸이 이어지지 않은 이전 에이전트는 이제 정리됩니다.
- 업데이트 설치 중 이전 버전 제거가 실패하면, 원인을 찾을 수 있도록 임시 폴더에 진단 기록을 남깁니다.

## 하위 저장소

- 원격 주소를 바꾼 뒤 Git 로그인이 필요하면 한국어로 안내하고, **터미널에서 로그인** 단추로 그 저장소 폴더의 터미널을 열어 로그인 명령을 준비해 둡니다.
- 원격 주소 창의 단추 크기와 정렬을 맞췄습니다.

## 에이전트와 터미널

- 새로 연 에이전트 세션에 메시지 알림이 두 번 들어가고 Enter 가 눌리지 않던 문제를 고쳤습니다.
- 칸이 하나뿐인 탭도 `Alt` 를 누른 채 지그재그로 문지르면 탭이 닫힙니다.

## 실행 구성

- 바로 반영에서 함께 고친 파일 중 일부만 반영되어 `NoSuchMethodError` 가 나던 문제를 고쳤습니다. 반영되지 못한 변경은 다음 저장 때 함께 다시 보냅니다.
