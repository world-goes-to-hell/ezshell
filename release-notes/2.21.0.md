## 작업 공간

- 상태 줄의 `작업 공간` 이 로컬 셸 작업용 패널을 터미널 오른쪽에 엽니다. 터미널을 가리지 않고 옆에 자리를 차지하며, 왼쪽 가장자리를 끌어 폭을 바꿉니다.
- **대화 기록**: 이 PC 에서 실행했던 Claude Code·Codex 대화를 보여 줍니다. 대화 내용으로도 찾을 수 있고, `이어서 실행` 을 누르거나 대화를 탭·칸으로 끌어 놓으면 그 폴더에서 같은 대화로 다시 엽니다.
- **파일**: 폴더를 그 자리에서 펼치고, 파일을 누르면 바로 열어 고치고 저장합니다. 이미지·PDF 는 미리보기로 열립니다.
- **Git**: 커밋하지 않은 변경을 폴더 트리로 보여 주고, 파일마다 추가·삭제 줄 수와 상태를 표시합니다. 파일을 누르면 바뀐 내용이 펼쳐지고, 파일 창으로 열면 마지막 커밋과 좌우로 비교합니다. 커밋을 누르면 그 커밋에서 바뀐 파일과 내용을 봅니다.

## 탭과 화면

- **작업별로 탭이 나뉩니다.** 탭 줄은 지금 작업(로컬 작업 프로젝트)의 탭만 보여 주고, 탭 줄 왼쪽의 작업 이름을 눌러 다른 작업으로 바꿉니다. 숨은 탭도 계속 실행됩니다.
- **화면을 4개까지 나눌 수 있습니다.** 나뉜 화면의 탭을 끌어 끝에 놓으면 화면이 하나 더 생기고, 화면 사이 경계를 끌어 폭을 바꿉니다. 두 번 누르면 모두 같은 폭이 됩니다.
- 앱을 닫았다 열어도 열려 있던 탭을 다시 열지 묻습니다. 로컬 터미널에서 돌던 Claude Code·Codex 는 칸마다 같은 대화로 이어서 열립니다.
- 탭 이름에 에이전트 이름을 붙이지 않고 폴더 이름만 보여 줍니다.
- 탭의 첫 터미널도 칸으로 나뉘어 있으면 `이 칸 닫기` 로 닫을 수 있습니다.

## 에이전트

- 메시지를 받은 에이전트가 바로 수신 확인을 보냅니다. 작업 중이면 지금 하던 일을 먼저 마치겠다고 답합니다.
- 막 띄운 에이전트가 메시지를 받고도 깨어나지 않던 문제와, 붙여 넣은 문장에 Enter 가 눌리지 않아 대화가 멈추던 문제를 고쳤습니다.
- 로컬 터미널 칸마다 아래에 Claude Code·Codex 의 사용량(5시간·7일 한도, 컨텍스트, 모델, effort)이 표시됩니다. 같은 폴더에 Codex 를 여럿 띄워도 칸마다 따로 보입니다.
- 에이전트가 도는 터미널에서 `Shift+Enter` 로 줄을 바꿉니다.

## 사이드바

- 세션 목록 위 검색칸에서 이름·호스트·계정·폴더로 세션을 찾습니다. 목록을 거르지 않고 찾은 세션을 강조하며, `Enter` 로 접속합니다.
- `로컬 작업` 이 저장소 → 워크트리 → 탭 트리로 바뀌었습니다. SSH 세션을 프로젝트에 끌어 놓아 묶어 둘 수 있습니다.
- 사이드바 맨 아래 버튼 줄을 없앴습니다. 에이전트 메시지·로컬 작업·배치 명령·세션 통계는 명령 팔레트(`Ctrl+P`)에서 엽니다.
- 접힌 사이드바에서 로컬 작업에 묶인 서버의 탭은 로컬 작업 쪽에 셉니다.

## 파일 창

- 마크다운 파일을 `일반`, `나란히`, `마크다운` 으로 볼 수 있습니다. `나란히` 는 고치는 대로 오른쪽 문서가 바뀌고, 가운데 선을 끌어 폭을 조절합니다.
- `.properties`·`.yml` 같은 설정 파일에서 주석·키·값이 색으로 구분됩니다.
- 설정 파일의 `${NAME}` 을 `Ctrl+클릭` 하면 그 이름을 정하는 곳(.env, compose, yml, properties 등)을 찾아 그 줄에서 엽니다.
- 분리한 창(서버 파일, SFTP, 터미널, DB, MCP 활동)은 `Ctrl+휠` 로 화면 배율을 따로 바꿉니다. 실시간 보기의 오류 이동은 `Alt+휠` 과 `F8` 입니다.
- 긴 파일을 비교할 때 첫 변경 이후를 모두 바뀜으로 표시하던 문제를 고쳤습니다.
