## 에이전트 채팅 보기

- Claude 가 선택지 질문을 하면 터미널 화면 대신 채팅 카드로 답합니다. 질문이 여러 개면 단계별로 고르고, 여러 개 고르기·**직접 입력**도 됩니다. 마지막에 고른 답을 확인하고 `보내기` 를 누르면 Claude 에 그대로 전달됩니다.
- 답한 질문은 대화 안에 질문과 답으로 남습니다.
- 카드의 `터미널에서 답하기` 로 Claude 의 원래 질문 화면에서 답할 수도 있습니다.
- 좁은 칸에서도 Claude 의 질문 화면을 알아봅니다.
- 채팅 테마가 늘었습니다: 디스코드풍, 레트로 아케이드, 복숭아 소다, 네온 시티, 앰버 CRT, 흑백 만화.

## 로컬 작업

- 로컬 작업의 `서버` 줄과 워크트리 아래 SSH·DB 탭 줄에 세션에 지정한 색이 보입니다 (세션 색이 없으면 폴더 색).

## 브라우저

- 브라우저 탭의 수정 요청에 이미지를 첨부하거나 스크린샷을 붙여 넣을 수 있습니다.
- 브라우저에서 내보낸 비밀번호 파일(CSV)을 가져올 수 있습니다.

## 그 밖에

- Windows 에서 `Ctrl+Win+Alt` 로 화면의 영역을 캡처합니다.
