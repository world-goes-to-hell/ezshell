## 화면

- 사이드바의 로컬 작업마다 색을 직접 고를 수 있습니다. 작업 머리줄을 우클릭해 **색상…** 을 누르세요.
- 직접 고르지 않은 작업은 작업 수에 맞춰 어울리는 색을 자동으로 나눠 갖습니다. 이웃한 작업끼리 비슷한 색이 되지 않고, 탁한 색은 쓰지 않습니다.
- 자동 색 방식을 고를 수 있습니다: **조화로운 여러 색**, **비슷한 계열**, **모두 같은 색**.

## 하위 저장소

- 로컬 작업 아래의 Git 저장소를 세 단계 깊이까지 찾습니다 (예: `group/team/service`).

## 실행 구성

- Tomcat 구성을 만들 때 IntelliJ(로컬 Tomcat, Smart Tomcat)와 VS Code 의 Tomcat 실행 설정을 읽어 포트·컨텍스트 경로·웹 폴더·VM 인자를 가져올 수 있습니다. **설정 파일 선택…** 으로 다른 위치의 설정 파일도 고를 수 있습니다.

## 에이전트

- 채팅에서 `\` 로 끝나는 글을 보내면 Claude 에 전송되지 않던 문제를 고쳤습니다.

## 업데이트

- 다른 터미널의 Claude·Codex 가 쓰는 ezShell 메시지 MCP 가 설치 폴더 밖에서 실행됩니다. 업데이트 설치 중 "Failed to uninstall old application files" 로 실패하던 원인 중 하나를 막습니다.
- 업데이트 설치가 실패하면, 그때 설치 폴더를 쓰던 프로세스를 진단 기록에 함께 남깁니다.
