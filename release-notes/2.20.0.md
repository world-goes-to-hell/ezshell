## 업데이트해도 탭이 이어집니다

- 업데이트 알림의 `재시작` 을 누르면 열린 탭을 기억했다가, 다시 시작한 뒤 잠금을 풀면 **`업데이트 전에 열려 있던 탭을 다시 열까요?`** 라고 묻습니다. `다시 열기` 를 누르면 탭 이름, 칸 배치, SFTP 패널과 폴더, 있던 폴더(`cd`), 로컬 터미널, 계정을 저장한 DB 탭까지 차례로 다시 엽니다.
- 묻기 전에는 어느 서버에도 접속하지 않습니다. 실행 중이던 프로그램과 화면 내용은 이어지지 않습니다.
- 저장하지 않은 빠른 연결은 비밀번호를 남기지 않으므로, 접속 정보가 채워진 연결 창으로 다시 열 수 있게 보여 줍니다.
- 파일 전송이 진행 중이면 업데이트 전에 한 번 묻고, 저장하지 않은 서버 파일 편집 창이 있으면 먼저 저장하도록 알려 줍니다.

## 탭과 칸을 자유롭게 옮기기

- **탭을 다른 탭의 칸으로 합칠 수 있습니다.** 탭을 끌어 다른 탭의 터미널 위나 탭 줄의 다른 탭 위에 놓거나, 탭 우클릭 `칸으로 병합` 을 고릅니다. 셸은 끊기지 않고 화면도 그대로 이어집니다.
- 같은 세션의 탭끼리만 합쳐지고, 다른 세션의 탭을 가져가면 합칠 수 없다고 알려 줍니다.
- **놓을 위치를 고를 수 있습니다.** 칸의 위·아래·왼쪽·오른쪽 가까운 쪽에 놓으면 그쪽 절반에 들어가고, 끄는 동안 들어갈 자리가 표시됩니다. 칸 손잡이(⋯)로 칸을 옮길 때도 가운데에 놓으면 자리 바꾸기, 가장자리에 놓으면 그쪽으로 옮기기입니다.
- 화면을 좌우로 나누려면 터미널 영역의 가장자리 끝까지 끌어 놓습니다.
- **`Alt` 를 누른 채 터미널을 끌면** 칸 안에 선을 그어 그 자리에서 칸을 나누거나, 옆 칸으로 끌어 두 칸을 하나로 합칩니다 (끌어 간 쪽 칸은 닫힙니다).
- 탭의 첫 칸도 다른 칸처럼 탭 줄로 끌어 새 탭으로 뺄 수 있습니다.
- 사이드바 탭 목록에서 칸으로 나뉜 탭은 배치 그림으로 보이고, 칸을 누르면 그 셸로 바로 갑니다.
- 세션에 연결하면 사이드바에서 탭으로 연결 표시가 날아가고, 연결된 세션마다 초록 점이 표시됩니다.

## 터미널

- `tail -f` 로 로그를 볼 때처럼 **오류·경고 줄에 바탕색이 칠해집니다.** 우클릭 `편의` 에서 끄고 켭니다.
- 창으로 분리한 SFTP·터미널·DB 창이 마지막으로 두었던 위치와 크기에서 다시 열립니다.

## 컨테이너·실시간 보기

- 컨테이너 패널에서 **이름으로 검색**할 수 있습니다. 여러 이름은 공백이나 쉼표로 나눠 입력하고, 찾은 컨테이너는 맨 위로 올라와 강조됩니다. 나머지 컨테이너도 그 아래에 그대로 보입니다.
- 로그 실시간 보기에서 오류와 기준점을 `F8`/`F9`, `Alt+휠`(또는 `Ctrl+휠`)로 오가고, 맨 위·맨 아래로 바로 갈 수 있습니다. 오른쪽 목록 패널에서 골라 이동하고, 목록에서 고른 수준이 이동에도 적용됩니다.
- 스택 트레이스는 여러 줄이어도 오류 한 건으로 셉니다. 기준점에 이름을 붙일 수 있고, 줄바꿈 버튼으로 긴 줄을 접어 볼 수 있습니다.
- 셸이 하나일 때 `Alt` 끌기 표시가 파일 탐색기와 머리줄까지 덮던 문제를 고쳤습니다.

## 설정·보안

- 설정 > 백업 > `화면 설정` 에서 테마, 단축키, 패널 크기 같은 화면 설정을 파일로 내보내고 가져올 수 있습니다.
- 세션에 저장한 **DB 계정 비밀번호, root 전환 비밀번호, 점프 호스트 비밀번호가 세션 파일에 암호화되지 않고 저장되던 문제를 고쳤습니다.** 이번 버전에서 잠금을 풀면 자동으로 암호화됩니다.
