## 실행 구성

- 실행 구성이 많은 프로젝트(예: MSA 서비스 30개)를 위한 **실행 패널**을 더했습니다. 오른쪽 작업 공간 패널의 **실행** 탭에서 모든 구성을 단계·상태·포트·브랜치와 함께 표로 보고, 이름·폴더·포트로 거르거나 단계별·묶음별로 실행할 수 있습니다. 키보드(↑↓, Enter, Space, L, R)로도 조작합니다.
- 구성 수가 기준을 넘으면 사이드바는 요약만 보여 줍니다: 실행 중·종료·응답 없음 개수와 문제 있는 구성, ★ 로 고정한 구성. 기준은 **설정 > 개발 도구**에서 바꿉니다 (기본 8개).
- 사이드바를 우클릭하면 패널에서 할 수 있는 동작을 모두 쓸 수 있습니다. 접혀서 안 보이는 구성도 **구성 고르기**에서 고릅니다.
- 구성을 ★ 로 고정하면 사이드바에 늘 보입니다.
- 실행 중인데 헬스 URL·포트가 응답하지 않는 구성을 **응답 없음**으로 알려 줍니다 (기동 순서에 헬스 URL 또는 포트 기준을 정한 구성).
- 예상치 못하게 종료하면 실행 구성 줄과 알림에 원인을 한 줄로 보여 줍니다.

## 터미널

- 로컬 터미널을 우클릭해 **터미널 재시작**을 누르면 같은 칸, 같은 폴더에서 새 셸이 열립니다. 셸이 끝난 칸에는 **새 셸로 재시작** 버튼이 나옵니다.
- 탭을 마우스 휠 버튼으로 눌러 닫을 수 있습니다. 보던 탭을 닫으면 바로 전에 보던 탭으로 돌아갑니다.
- 사이드바에서 로컬 터미널 탭을 닫을 때 뜨는 확인 창에서 Enter 가 **모두 종료**입니다.
- 마우스 포인터 세트(설정 > 테마 > 마우스 포인터)의 글자(I) 포인터 세로 줄을 가늘게 해, 끌기를 시작할 위치가 잘 보입니다.

## 에이전트

- 우클릭 메뉴의 채팅 전환 이름을 **채팅 모드** / **터미널 모드**로 바꿨습니다.
- Codex 에 인용 답장을 보내면 말풍선이 두 개 보이던 문제를 고쳤습니다.
- 채팅 머리줄의 종을 누르면 아직 처리하지 않은 메시지 목록이 열리고, 메시지마다 **지금 알리기**로 에이전트에게 바로 알릴 수 있습니다.
- 답변 속 파일 미리보기에서 HTML 은 처음에 **브라우저 보기**로 열리고 **소스 보기**로 바꿀 수 있습니다. 마크다운도 **문서 보기**·**소스 보기**를 바꿔 봅니다. 브라우저 보기는 스크립트와 옆 파일(이미지·스타일)을 불러오지 않으니, 그때는 **브라우저로 열기**를 씁니다.
- 작업 공간 **변경** 탭에서 파일마다 그 파일을 고친 에이전트를 보여 줍니다. 두 에이전트가 커밋 전 같은 파일을 고치면 **겹침**으로 표시하고, 나중에 고친 에이전트에게 알립니다. 커밋 상자의 **에이전트로 고르기**로 한 에이전트가 고친 파일만 골라 커밋할 수 있습니다 (훅을 쓰는 Claude Code·Codex 만 해당합니다. 사람이 고친 파일은 표시하지 않습니다).
- **변경** 탭의 **동결**로 병합처럼 저장소를 혼자 써야 할 때 다른 에이전트에게 파일을 고치지 말라는 긴급 메시지를 보냅니다. 계속 작업할 에이전트 하나와 이유를 정할 수 있고, 해제하면 다시 알립니다. 편집을 막지는 않고 알리기만 합니다.
- 에이전트가 메시지를 **긴급**으로 보내면, 받는 에이전트가 작업 중이어도 채팅에 바로 알림이 들어가 하던 일보다 먼저 처리합니다. 메시지 목록에는 **긴급**으로 표시됩니다.
- 빠른 캡처의 **바로작업**으로 새 Codex 세션을 열면 승인과 샌드박스 없이 실행합니다 (Claude 의 `--dangerously-skip-permissions` 와 같은 방식).
- 빠른 캡처의 **바로작업 > 새 세션에 요청**에서 Codex 를 고르면 요청이 입력칸에 남고 넘어가지 않던 문제를 고쳤습니다.

## 검색

- 프로젝트 검색에서 `.*` 또는 `Alt+R` 로 정규식 검색을 켤 수 있습니다.

## 화면

- 워크트리가 하나인 프로젝트는 브랜치를 프로젝트 줄에 보이고, 그 아래 줄에 이름과 브랜치가 되풀이되지 않게 했습니다.
- **설정 > 진단 정보**에서 앱·CLI 버전, 에이전트 상태, 최근 오류를 모아 **복사**하거나 **파일로 저장**하고 로그 폴더를 열 수 있습니다. 메시지 내용과 비밀 값은 담지 않고, 홈 폴더는 `~` 로 바꿉니다. 명령 팔레트의 **진단 정보 복사**로도 씁니다. 앱이 놓친 오류는 이제 로그 폴더에 남습니다.
- 바로작업으로 ezShell 창이 들어간 영역을 캡처해 에이전트에게 보내면 앱 상태(버전, 에이전트 상태, 최근 오류)가 요청 끝에 저절로 붙습니다. 다른 프로그램만 찍으면 붙이지 않습니다.
