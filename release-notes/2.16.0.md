## 새 기능

### 원격 접속 (휴대폰 브라우저)
- 밖에서 휴대폰 브라우저로 이 PC 의 ezShell 에 들어와, 저장된 세션의 터미널을 쓸 수 있습니다. **Tailscale** 로 연결된 기기에서만 열립니다.
- 설정 > `원격 접속` 에서 켭니다. 인증 앱(Google Authenticator 등)에 QR 을 한 번 등록하고, 휴대폰으로 등록 QR 을 찍으면 됩니다. 접속할 때마다 인증 앱의 6자리 코드를 입력합니다.
- PC 의 ezShell 이 켜져 있고 잠금이 풀려 있을 때만 접속됩니다. 앱을 잠그면 접속 중인 기기를 모두 끊습니다.
- 휴대폰에는 세션 이름과 폴더만 보이고, 서버 주소·계정·비밀번호는 PC 밖으로 나가지 않습니다.
- 휴대폰 터미널 아래에 `Esc` `Tab` `Ctrl` 방향키 줄이 있습니다.
- 기본은 꺼져 있습니다. 휴대폰을 잃어버리면 설정의 기기 목록에서 해제하세요.

### DB: SQL Server 연결
- MySQL/MariaDB, PostgreSQL 에 이어 **SQL Server** 에 접속해 조회할 수 있습니다 (트리, 쿼리, 자동완성, 추출).
- 조회만 됩니다. 쿼리는 실행 뒤 항상 되돌리고, 데이터를 바꾸는 문장은 보내기 전에 막습니다.

### DB: 결과 추출
- 결과 막대의 `추출` 로 조회 결과를 **Excel**, CSV, TSV, SQL INSERT, JSON, Markdown 으로 저장하거나 복사합니다.

### DB: DDL 복사와 외래 키
- 트리의 테이블·스키마 줄에서 버튼이나 `Ctrl+Shift+C` 로 DDL 을 복사합니다.
- 외래 키가 걸린 열은 머리글에 고리 표시가 붙습니다. 누르면 연결된 테이블 목록이 나오고, 셀을 우클릭하면 `연관 테이블 조회` 로 그 값의 자료를 바로 찾습니다.

### DB: 결과 표
- 끌거나 `Shift+클릭` 으로 여러 셀을 고르고 `Ctrl+C` 로 복사합니다. 행 번호를 누르면 그 행 전체를 고릅니다.
- 누른 셀의 행이 계속 강조됩니다.
- 머리글을 끌어 열 순서를 바꿉니다.

### 터미널 파일 영역 테두리
- `ls` 결과처럼 파일 이름을 우클릭·`Ctrl+클릭` 할 수 있는 영역을 테두리로 보여 주고, 기준 폴더를 오른쪽 위에 적습니다.
- `cd` 하기 전에 찍힌 이름은 다른 폴더의 파일이므로 더 이상 지금 폴더에서 찾지 않습니다.
- 우클릭 `편의` 메뉴에서 테두리를 끌 수 있습니다.

## 개선
- DB 계정 창에서 `접속` 을 누르면 진행 상황과 경과 시간을 보여 줍니다.
- DB 트리의 테이블 실행 버튼이 쿼리를 넣고 바로 실행합니다.
- DB 트리 너비를 손잡이로 조절할 수 있습니다.
- 접힌 사이드바의 누를 수 없던 `»` 버튼을 없앴습니다.

## 수정
- 새로 설치한 사용자에게도 `업데이트 내용` 창이 뜨던 문제를 고쳤습니다.
- 실시간 보기 창을 열면 작업 표시줄에 ezShell 버튼이 하나 더 생기던 문제를 고쳤습니다.
- 설정 창의 탭 이름이 두 줄로 접히던 것을 고쳤습니다.
