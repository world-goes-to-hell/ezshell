## 휴대폰·태블릿 원격 접속

- 휴대폰과 태블릿에서도 PC 와 같은 구조로 씁니다. 연결 목록·로컬 작업·PC 탭은 왼쪽(휴대폰은 ☰ 서랍), 열어 둔 셸·PC 탭·채팅은 위쪽 탭 줄, 연결 상태와 작업 수는 아래 상태 줄에 나옵니다.
- 탭을 바꿔도 열어 둔 SSH 셸이 닫히지 않습니다. PC 탭과 채팅은 앞에 있을 때만 받아 와 전송량을 줄입니다.
- 태블릿에서는 사이드바를 접거나 폭을 바꿀 수 있고, 가로로 두면 탭 두 개를 나란히 봅니다.
- 하드웨어 키보드로 `Ctrl+Tab`·`Ctrl+숫자` 탭 이동, `Ctrl+W` 탭 닫기를 씁니다. 터미널·탭을 길게 누르면 복사·붙여넣기와 닫기 메뉴가 나옵니다.
- 연결 목록·에이전트 칩·채팅이 PC 와 같은 모양이고, 터미널은 PC 테마의 색과 글꼴을 따릅니다. 로그인 화면이 밝게 깜빡이지 않습니다.
- 휴대폰 홈 화면에 **앱으로 설치**할 수 있고, 등록 링크로 새 기기를 등록할 수 있습니다.
- PC 에서 연 웹페이지를 휴대폰에서 보고, 요소를 골라 에이전트에게 수정 요청을 보낼 수 있습니다.
- 확인 질문의 "계속 허용" 같은 선택지는 휴대폰에서 고를 수 없고 `PC에서만` 으로 표시됩니다.
- 인증 코드 6자리를 넣으면 바로 접속하고, 화면 확대를 막지 않으며, 버튼이 손가락으로 누르기 쉬워졌습니다.

## 다시 시작한 뒤에도 이어서

- Windows 를 다시 시작하거나 PC 가 갑자기 꺼져도, 다음에 켜면 열려 있던 탭을 다시 열지 묻습니다.
- 로컬 터미널에서 새로 띄운 Codex 에게 붙인 역할도 저장되어, 그 대화를 이어서 열면 역할이 돌아옵니다.

## 에이전트와 채팅

- 채팅 답변을 다른 에이전트에게 **인계**할 수 있습니다. 답변에 포인터를 올려 `인계` 를 누르고 받을 에이전트를 고릅니다.
- 에이전트가 다른 에이전트가 왜 멈췄는지 확인하고, 사람의 답이 필요하면 PC 알림으로 사용자를 부를 수 있습니다.
- 채팅에서 `/model`·`/effort` 를 보내면 선택 화면을 터미널로 넘겨 바로 고를 수 있습니다. 예전에는 확인 질문 카드로 잘못 보였습니다.
- Claude 가 처음 여는 폴더를 신뢰할지 물을 때 채팅에 안내가 나오고, 터미널에서 답하면 채팅으로 돌아옵니다.
- 메시지 도착 카드에는 역할이 있으면 역할만 보입니다.
- 사이드바 배치 그림에서도 작업 중인 에이전트의 칸에 빛이 돕니다.
- 오래된 Antigravity CLI 에서 `agy` 가 실행되지 않던 문제를 고쳤습니다. 채팅 보기를 쓰려면 `agy update` 로 업데이트하라는 안내가 나옵니다.

## 작업 공간

- 파일 트리의 폴더를 우클릭해 **파일 탐색기로 열기** 를 할 수 있습니다.
- `변경`·`Git 기록` 탭을 처음 열 때 기다리지 않습니다.
