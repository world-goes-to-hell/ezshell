## 시작 화면

- 앱을 켜면 바탕화면 위 작은 터미널 창에서 `ezshell --boot` 가 입력되고 실행된 뒤 앱이 나타납니다. 창 색은 고른 테마의 터미널 색을 따릅니다.

## 에이전트 채팅 보기

- 채팅에서 보낸 글이 바로 말풍선으로 보입니다. `/compact` 같은 슬래시 명령도 보이고, 터미널 보기로 갔다 와도 사라지지 않습니다. "답변 생성 중" 표시도 그대로 남습니다.
- 압축 안내("이전 대화를 요약했습니다")가 한 번만, `/compact` 다음에 나옵니다.
- 답변 속 파일 링크가 열립니다. 줄 번호가 붙은 링크(`README.md:187`)는 그 줄에서 열리고, 상대 경로 링크(`docs/x.md`)는 에이전트의 작업 폴더를 기준으로 엽니다.
- MCP 도구의 결과와 인자가 JSON 한 줄 대신 들여쓴 목록으로 보이고, 여러 줄 글은 줄바꿈대로 보입니다.
- 머리줄의 `메시지` 버튼으로 채팅 보기에서도 그 에이전트의 메시지와 안 읽은 수를 봅니다.
- 탭을 다시 열 때 채팅 보기로 보던 칸은 채팅 보기로 열립니다 (앱 재시작 뒤 복원과 창 새로 고침 모두).

## 모델·노력 수준 바꾸기

- 로컬 터미널 아래 사용량 줄의 모델 이름이나 노력 수준을 누르면 메뉴로 바꿉니다. 이 세션에만 적용되고, 기본 설정은 바꾸지 않습니다.
- 한 번 불러온 목록은 기억해 두어 다음부터 바로 뜨고, 메뉴의 새로고침 버튼으로 다시 불러옵니다.
- 바꾸면 사용량 줄에 새 모델과 노력 수준이 바로 보입니다.

## 에이전트 메시지

- 수신 확인 대신 읽음 표시로 바뀌었습니다. 받는 에이전트가 메시지를 읽으면 메시지 창에 `읽음`, 읽기 전에는 `안 읽음` 이 보입니다.
- 보낸 에이전트는 `check_sent` 로 자기 메시지가 읽혔는지, 답을 받았는지 확인하고 필요하면 다시 요청합니다.
- 메시지가 전달될 때 보낸 에이전트의 아이콘이 받는 칸으로 날아가고, 도착 안내에도 에이전트별 아이콘이 붙습니다.
- 칸 폭에 따라 알림 문장의 Enter 가 가지 않아 에이전트가 메시지를 놓치던 문제를 고쳤습니다.

## 탭과 터미널

- 등록하지 않은 폴더에서 연 로컬 터미널 탭은 그 폴더 이름의 묶음으로 모이고, 그 묶음에서 연 브라우저 탭도 같은 묶음에 들어갑니다.
- 창을 다시 불러온 뒤 분할했던 로컬 터미널 탭이 칸 배치째 돌아옵니다.
- 로컬 터미널에서도 `Ctrl+Shift+H` 로 입력했던 명령을 다시 찾아 넣습니다.
- 터미널 출력의 웹 주소를 누르면 ezShell 브라우저 탭이나 기본 브라우저로 엽니다.
- 터미널을 우클릭해 메뉴를 열 때 Codex 입력칸에 클립보드가 붙여 넣어지던 문제를 고쳤습니다.

## 브라우저 탭

- 탭 이름에 지금 보는 페이지의 제목이 나옵니다 (직접 바꾼 이름은 유지).
- 도구 모음 버튼이나 `F12`, `Ctrl+Shift+I` 로 그 페이지의 개발자 도구를 엽니다.
