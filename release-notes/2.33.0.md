## 휴대폰 원격 접속

- 휴대폰에서 PC에 열려 있는 SSH 탭의 주 터미널을 이어 볼 수 있습니다. 저장한 세션에는 입력도 할 수 있고, 빠른 연결은 보기만 됩니다.
- 휴대폰에서 PC의 Claude Code·Codex 대화를 읽고, 글을 보내고, 작업을 중지하거나 확인 질문에 답할 수 있습니다.
- `설정 → 원격 접속`에서 `휴대폰에서 PC 탭 이어 보기`와 `휴대폰에서 에이전트 쓰기`를 각각 켤 수 있습니다. 휴대폰 화면은 PC의 ezShell 테마를 따릅니다.

## Claude 채팅과 에이전트 메시지

- 번호가 붙은 여러 줄을 보내면 확인 대기 오류가 뜨던 문제를 고쳤습니다. 실제 선택 질문이 뜨면 채팅에서 질문과 선택지를 확인할 수 있습니다.
- Windows의 ezShell 로컬 PowerShell에서 `claude`를 실행하면 별도 등록 없이 `ezshell-cli-mcp`가 연결됩니다.
- 마우스로 답장이나 도구 항목을 누른 뒤 포인터를 옮겨도 메시지 시각이 남던 문제를 고쳤습니다.

## Windows 업데이트

- 이 버전부터 업데이트 설치를 위해 앱을 종료할 때 로컬 셸과 메시지 MCP 연결을 함께 정리합니다. 설치 폴더가 사용 중이라 이전 버전을 제거하지 못하는 경우를 줄입니다.
