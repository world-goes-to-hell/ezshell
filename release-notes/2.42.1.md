## 업데이트

- 업데이트로 앱이 다시 켜진 뒤, 터미널에서 직접 띄운 Claude Code·Codex 에게 메시지가 닿지 않던 문제를 고쳤습니다. Claude 는 메시지 연결이 끊긴 채 남고, Codex 는 상태가 알 수 없음으로 남아 받은 메시지 알림이 입력칸에 가지 않았습니다.
- 업데이트 뒤 잠금을 먼저 풀면, 이어서 돌던 에이전트의 상태 보고와 메시지가 새 앱에 닿지 않던 문제를 고쳤습니다.
- 업데이트 뒤 이어받은 Codex 가 작업 중으로 보이지 않던 문제를 고쳤습니다.
- 터미널에서 직접 띄운 에이전트가 업데이트 뒤 끝나도 목록에 남아 있던 문제를 고쳤습니다.
- 위 고침 가운데 이전 앱이 넘겨주는 정보에 달린 부분(Codex 의 작업 중 표시 등)은 2.42.1 을 설치한 뒤의 다음 업데이트부터 완전히 적용됩니다.

## 에이전트

- 메시지 연결이 끊긴 에이전트를 사이드바 칩의 점선 테두리와 툴팁의 **메시지 연결 없음** 으로 알려 줍니다. 에이전트가 `list_agents` 로 찾을 때도 `connected: false` 로 나와, 같은 폴더의 에이전트 수를 사이드바와 다르게 세지 않습니다 (메시지는 연결된 뒤에 보낼 수 있습니다).
