## 에이전트 채팅 보기

- 채팅에서 보낸 글이 **CLI의 입력 대상이 바뀌었습니다** 로 막히던 문제를 고쳤습니다. 이제 Claude 입력칸 위에 보이는 이름(세션 이름 등)과 관계없이 그 칸의 에이전트에게 보냅니다.
- 세션 이름이 길어 Claude 입력칸 위 줄이 이름으로 가득 차도 입력칸을 찾습니다. 예전에는 채팅·캡처 바로작업·메시지 알림이 **입력칸을 찾지 못했습니다** 로 실패했습니다.
- 답변 속 폴더 링크(`mockups/` 같은 경로)를 누르면 오른쪽 작업 공간의 **파일** 트리가 열리고 그 폴더까지 펼쳐 잠깐 강조합니다. 작업 폴더 밖의 폴더는 예전처럼 파일 탐색기로 엽니다. 우클릭 메뉴에서 `작업 공간에서 보기`·`파일 탐색기에서 열기` 를 고를 수도 있습니다.
- 채팅 테마 목록에 같은 이름이 두 번 보이던 문제를 고쳤습니다(`카톡 모드` 와 `카톡 모드 (앱 테마)`). 예전에 `(앱 테마)` 쪽을 골라 두었다면 같은 이름의 채팅 테마로 바뀝니다.
- 질문별 한도 표시가 질문 전과 마지막 답변 뒤의 사용률(`12% → 14%`)을 함께 보여 주고, 그사이 한도가 초기화되었으면 그렇게 적습니다.

## 터미널

- 칸 안에서 `Alt` 를 누른 채 **지그재그로 문지르면** 그 칸을 닫습니다. 칸이 붉게 칠해지는 것을 보고 손을 떼면 닫히고, `Esc` 로 취소합니다. 함께 나뉘었던 칸이 빈자리를 채웁니다.

## 작업 공간

- Git 이 **변경** 과 **기록** 두 탭으로 나뉘었습니다.
- **변경** 탭에서 파일·폴더를 골라 메시지를 쓰고 `선택한 N개 파일 커밋`(`Ctrl+Enter`)으로 커밋합니다. 고르지 않은 파일은 그대로 남고, 커밋 훅도 터미널에서처럼 실행됩니다.
- 사이드바 로컬 작업에 **개발 서버** 가 생겼습니다. 프로젝트의 기동 명령(Spring Boot 의 `bootRun`, `package.json` 의 `dev`·`serve`)을 찾아 보여 주고, `기동` 을 누르면 그 폴더의 터미널에서 실행합니다.
- `Tab` 두 번으로 여는 작업 개요의 터미널 미리보기가 화면 높이의 대부분까지 커졌습니다.

## 브라우저 탭

- 작업 폴더의 HTML 파일을 브라우저 탭에서 바로 미리 봅니다. 주소줄에는 로컬 파일 경로가 보입니다.
- 즐겨찾기·방문 기록 화면에서 검색하고, 여러 개를 골라 한 번에 지울 수 있습니다.

## 설정

- 설정 > 테마 가 색 테마와 창 모양 설정으로 정리되었습니다.
- 마우스 포인터의 모양과 크기를 따로 고릅니다.
