## 파일 끌어 놓기

- 파일 탐색기에서 로컬 터미널로 파일을 끌어 놓으면 파일 경로가 입력됩니다. 공백이나 특수 문자가 든 경로는 따옴표로 감쌉니다.
- 채팅 보기에서는 PNG·JPG 를 끌어 놓으면 이미지로 첨부하고, 다른 파일은 커서 위치에 경로를 넣습니다.

## 하위 저장소의 원격 주소

- 하위 저장소 메뉴의 **원격 주소…** 에서 원격 주소를 보고 바꾸거나, 원격을 추가·삭제할 수 있습니다.
- `http://` 주소 때문에 받기가 실패하면, 실패한 줄의 **원격 주소 바꾸기** 에서 **HTTPS 로 바꾸기** 와 **연결 확인** 으로 바로 고칠 수 있습니다.
- 비밀번호가 들어간 주소는 저장하지 않고, 이미 저장된 비밀번호는 화면에서 가려서 보여 줍니다.

## 파일 탐색기에서 ezShell 로 열기

- Windows 파일 탐색기의 오른쪽 클릭 메뉴에 **ezShell로 열기** 가 생깁니다. 로그처럼 확장자가 없거나 낯선 파일도 ezShell 의 파일 창에서 열 수 있습니다.
- 편집기로 열기에 너무 큰 텍스트 파일은 읽기 전용 미리보기로 엽니다.

## 설정 창

- 설정 창을 넓히고, 왼쪽 세로 목록에서 항목을 고르도록 바꿨습니다. 창이 좁으면 위쪽 **설정 항목** 목록에서 고릅니다.

## 그 밖의 변경

- MCP 승인 창의 요청 사유를 눈에 띄는 상자로 보여 줍니다.
- 서버 로그를 띄운 로컬 터미널에 맨 위·맨 아래로 바로 가는 단추가 생겼습니다.
- 실행 구성 줄에서 오류 수를 누르면 첫 오류 줄로 가고, 기동 단계 번호를 보여 줍니다.
- 빠른 캡처에 마우스 포인터 효과가 함께 찍히던 문제를 고쳤습니다.
