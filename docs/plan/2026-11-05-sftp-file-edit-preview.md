# 서버 파일 편집과 미리보기 (SFTP)

- 날짜: 2026-11-05
- 상태: 구현 완료 (배포 전)

## 요구

- SFTP 패널에서 서버 파일을 열어 고치고 저장한다. 원치 않는 수정을 막도록, 저장하기 전 파일을 반드시 백업한다.
- 단축키는 Windows 편집기와 같다 (Ctrl+F 찾기, Ctrl+H 바꾸기, Ctrl+S 저장, Ctrl+Z/Ctrl+Y, Ctrl+G 줄 이동). Vim/Emacs 키는 넣지 않는다.
- PDF, 이미지(jpg, png 등), txt, log 같은 파일을 미리 본다.

## 결정 사항

### 여는 곳과 창
- SFTP 패널(본창·분리 창)의 서버 파일 우클릭 메뉴에 `미리보기`, `편집` 을 둔다. 더블클릭 동작은 바꾸지 않는다.
- 파일마다 창 하나(`?remoteFileMode=true&docId=...`). 같은 파일을 다시 열면 그 창을 앞으로 가져온다.
- 창은 자기 SFTP 채널을 탭의 SSH 연결에서 따로 연다. SFTP 패널을 닫아도 편집 창은 계속 쓸 수 있다. 창을 닫으면 채널을 닫는다.
- main 은 문서 ID 마다 세션, 경로, 마지막으로 본 내용을 갖고, 그 창(webContents)에서 온 요청만 받는다.

### 편집 (텍스트)
- 편집기는 CodeMirror 6. 확장자별 문법 색(`@codemirror/language-data`, 필요할 때 불러옴), 찾기/바꾸기 문구는 한국어.
- 5MB 이하 UTF-8 텍스트만 편집한다. NUL 바이트가 있거나 UTF-8 이 아니면 편집하지 않는다.
- 줄바꿈: 파일이 CRLF 만 쓰면 CRLF 로 저장한다. 섞여 있으면 LF 로 통일된다고 알리고, diff 에도 보인다.
- 쓰기 권한은 열 때 `r+` 로 열어 보고 바로 닫아 판단한다. 없으면 읽기 전용으로 연다.
- `/proc`, `/sys`, `/dev` 는 열지 않는다 (MCP 와 같은 규칙).

### 저장
1. Ctrl+S → main 이 연 내용과 지금 내용의 diff 를 계산해 보여 준다 (`fileEdit.describeChange`, 300ms 제한).
2. 사용자가 확인하면, 확인한 내용의 SHA-256 이 같을 때만 저장을 진행한다.
3. 서버의 지금 내용을 PC 에 백업한다. 백업 파일을 쓰지 못하면 저장하지 않는다.
4. `remoteFile.writeIfUnchanged` 로 쓴다: 파일을 한 번 열어 그 핸들의 내용이 연 내용과 같을 때만 같은 핸들에 덮어쓴다 (소유자·권한 유지, 실패하면 되돌림). 백업한 내용 = 덮어쓰기 직전 서버 내용이다.
5. 그사이 서버 파일이 바뀌었으면 쓰지 않고(이때 만든 백업은 지운다), `다시 불러오기`(내 변경 버림) 또는 `서버 내용과 다시 비교`(새 서버 내용 기준 diff → 확인 → 백업 → 저장)를 고르게 한다.
6. 저장하지 않은 변경이 있으면 창을 닫기 전에 묻는다.

### 백업
- 위치: `문서\ezShell Backups\<세션 이름> (<계정>@<호스트>)\<서버 경로의 폴더들>\<파일 이름>.<YYYYMMDD-HHmmss>.bak`. 경로가 너무 길면 파일 이름과 경로 해시로 줄인다.
- 파일마다 최근 20개만 남긴다.
- 서버에 `.bak` 을 만들지 않는다: `/etc/cron.d`, `sudoers.d`, `conf.d/*` 처럼 폴더 안 파일을 모두 읽는 곳에서 백업이 설정으로 적용될 수 있고, 폴더에 쓰기 권한이 없을 수 있다.
- 편집 창의 `백업` 목록에서 내용을 보고 되돌린다. 되돌리기는 편집기 내용을 바꾸는 것이고, 저장은 같은 절차(diff·백업)를 거친다.
- 백업은 세션 로그처럼 PC 에 평문으로 남는다.

### 미리보기
- 이미지(png, jpg, jpeg, gif, webp, bmp, ico, svg): 50MB 까지 읽어 `blob:` URL 로 `<img>` 에 표시한다. svg 도 `<img>` 라서 스크립트가 돌지 않는다.
- PDF: 50MB 까지 읽어 `blob:` URL 을 iframe 에 넣는다 (Chromium PDF 뷰어, Electron 28 에서 확인함).
- 그 밖의 파일(txt, log, conf 등)은 텍스트로 본다. 5MB 이하는 전체를, 더 크면 마지막 1MB 만 보여 준다 (앞부분 생략 표시). 읽기 전용 CodeMirror 라서 Ctrl+F 가 된다. `새로고침` 으로 다시 읽는다.
- CSP 에 `img-src 'self' blob:`, `frame-src blob:` 를 추가한다. blob URL 은 앱 스크립트만 만들 수 있다.

### 하지 않는 것
- root 권한 파일 저장 (SFTP 는 로그인 계정 권한). 읽기 전용으로 열린다.
- 탭으로 여러 파일 열기, 새 파일 만들기.

## 구현하며 바뀐 점
- 5MB 상한은 그대로 두었다. diff 는 3,000줄까지만 보여 주고(개수는 정확), 그 이상은 "앞부분만" 으로 알린다.
- 찾기 칸에 커서가 있을 때 CodeMirror 의 키가 닿지 않아 Ctrl+S, Ctrl+H 를 편집기 바깥 틀에서 따로 받는다.
