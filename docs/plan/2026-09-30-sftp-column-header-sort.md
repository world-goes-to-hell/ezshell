# SFTP 파일 목록: 컬럼 머리글 + 정렬, `..` 행 더블클릭

## 요구사항
1. SFTP 패널 파일 목록에 컬럼 머리글(이름, 수정일, 크기 등)을 추가하고, 머리글을 눌러 정렬을 바꿀 수 있게 한다.
2. 로컬 목록에서 폴더는 더블클릭해야 이동하는데, `..`(상위 폴더) 행은 한 번 클릭만으로 이동한다. 동작을 맞춘다.

## 현재 구조
- `FileList.tsx` 하나를 로컬/원격 목록과 분리된 SFTP 창(`SftpWindow`)이 함께 쓴다.
- 행에는 `.file-name`(가변), 원격만 `.file-owner`, `.file-permissions`(88px), `.file-mtime`(100px), `.file-size`(72px)가 있다. 머리글은 없다.
- 정렬은 메인 프로세스가 목록을 줄 때 "폴더 먼저, 이름순"으로만 한다.
- `..` 행은 `onClick={goUp}`, 일반 폴더 행은 `onDoubleClick`으로 이동한다. 원격 목록도 같은 코드라 똑같이 동작한다.

## 설계

### 정렬
- `lib/fileSort.ts`에 순수 함수 `sortFileItems(files, { key, direction })`를 두고 단위 테스트한다.
  - 키: `name` | `owner` | `permissions` | `modifyTime` | `size`
  - 폴더는 방향과 관계없이 항상 파일보다 위(Windows 탐색기와 같음)
  - 값이 같으면 이름순으로 보조 정렬. 이름은 숫자를 인식하는 한국어 비교(`localeCompare(..., { numeric: true })`)
  - 폴더의 크기는 0으로 취급(폴더끼리는 이름순)
- `FileList`는 받은 목록을 정렬한 결과를 모든 곳(선택, 범위 선택, 키보드 이동, 우클릭)에 그대로 쓴다. 선택은 이름 기준이라 정렬을 바꿔도 유지된다.
- 기본값: 이름 오름차순. 같은 머리글을 다시 누르면 방향이 바뀐다. 다른 머리글을 누르면 그 컬럼의 기본 방향(이름·소유자·권한은 오름차순, 수정일·크기는 내림차순)으로 시작한다.
- 정렬 상태는 패널(로컬/원격)마다 따로 기억하고, 폴더를 이동해도 유지된다. 패널을 닫으면 이름순으로 돌아간다(2026-09-30 사용자 결정).

### 머리글
- 새 컴포넌트 `FileListHeader.tsx`. 목록 스크롤 영역 맨 위에 `position: sticky`로 고정한다(스크롤바 유무와 관계없이 행과 칸 폭이 맞는다).
- 행과 같은 칸 폭을 쓰고, 정렬 중인 컬럼에 ▲/▼ 표시와 `aria-sort`를 단다.
- 원격: 이름 / 소유자 / 권한 / 수정일 / 크기, 로컬: 이름 / 수정일 / 크기

### `..` 행
- 한 번 클릭은 목록에 포커스만 주고, 더블클릭으로 상위 폴더로 이동한다(일반 폴더와 같게). 로컬/원격 모두 적용.
- 키보드(Backspace, ←, Alt+↑)로 상위 이동하는 동작은 그대로.

- 단위 테스트: 정렬 11개 추가, 전체 231개 통과, 타입 체크 오류 0건.
- E2E(임시 SFTP 서버, CDP DOM 검사):

  - 머리글과 행의 칸 위치 차이 0px
  - 이름 오름/내림, 크기 내림(5000 → 300 → … → 1), 수정일 내림 순서 확인, 폴더는 항상 위
  - 정렬을 바꿔도 선택 유지, 폴더를 이동해도 정렬 유지
  - `..` 한 번 클릭은 이동하지 않고 더블클릭으로 상위 이동(원격), 로컬도 한 번 클릭으로 이동하지 않음
- 참고: 하단 SFTP 패널은 심볼릭 링크를 여전히 파일로 취급하므로(2026-09-29 결정), 디렉토리 링크는 파일 그룹에 정렬된다.
