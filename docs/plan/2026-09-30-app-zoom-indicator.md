# UI 배율(Ctrl+휠) 표시 개선

## 배경
Ctrl+마우스 휠로 앱 전체 배율을 바꿀 수 있지만, 현재 배율이 몇 %인지 알 방법이 없다.
기존 구현은 `webFrame.setZoomLevel(level ± 0.5)` 이라서 배율이 109.5%, 120%, 131.4% 처럼 어중간한 값이 되고, 100%로 되돌리는 방법도 휠을 반대로 굴리는 것뿐이다.
(Ctrl+0 은 main 프로세스가 가로채 터미널 글꼴 크기 초기화에 쓴다.)

## 결정 사항
| 항목 | 결정 | 이유 |
|---|---|---|
| 배율 단계 | 브라우저와 같은 고정 단계 50·67·75·80·90·100·110·125·150·175·200% | 표시되는 숫자가 딱 떨어지고 익숙하다 |
| 적용 방식 | preload 에 `getAppZoomFactor`/`setAppZoomFactor` 추가 (`webFrame.setZoomFactor`) | 단계를 정확한 % 로 맞추려면 factor 를 직접 지정해야 한다 |
| 즉시 피드백 | 배율이 바뀌면 화면 위쪽 가운데에 "UI 배율 125%" 표시를 1.5초 띄움. [−] [+] [100%] 버튼 포함, 마우스를 올리면 유지 | 휠을 굴리는 순간 결과를 바로 본다 |
| 상시 표시 | 하단 상태 표시줄 오른쪽에 현재 배율 표시, 100%가 아니면 강조하고 클릭하면 100%로 복귀 | 표시가 사라진 뒤에도 현재 상태를 알 수 있다 |
| 저장 | `uiStore`(localStorage persist)에 저장하고 시작할 때 적용 | 재시작해도 배율이 유지된다 |
| 터치패드 | 휠 delta 를 누적해 한 단계씩 넘김 | 정밀 터치패드는 작은 delta 를 연속으로 보내서 한 번에 여러 단계가 넘어간다 |
| 하위 호환 | 새 preload API 가 없으면(앱 재시작 전) 기존 방식으로 동작 | dev 모드에서 preload 는 재시작해야 반영된다 |
