# 세션 연결 정보를 텍스트로 공유

- 날짜: 2026-11-12
- 구분: 중간 (남이 준 텍스트를 받아들이므로 검사 로직은 테스트 먼저, 검토 1회)
- 상태: 진행 중

## 요청
사이드바 세션 우클릭으로 연결 정보를 텍스트로 복사하고, 다른 사람이 그 텍스트를 붙여 넣어 자기 세션으로 추가한다. 비밀번호는 경고 창에서 확인하면 함께 복사한다.

## 형식 (`lib/sessionShare.ts`)
```
[ezShell 세션] <이름> · <계정>@<호스트>:<포트> (비밀번호 없음 | 비밀번호 포함)
ezshell-session:v1:<base64url(JSON)>[.<base64url(암호 상자 JSON)>]
```
- JSON 은 `{ session }` 또는 `{ folder: { name, backgroundColor, folders, sessions } }`. 폴더를 복사하면 하위 폴더·세션 전부.
- 첫 줄은 사람용 설명. 앱은 `ezshell-session:v1:` 로 시작하는 토큰만 찾는다 (메신저가 앞뒤에 글을 붙여도 됨).
- 넣는 것: 이름, 호스트, 포트, 계정, 인증 방식, 점프 호스트(주소·포트·계정·인증 방식), 타임아웃, keepalive, 자동 재연결, 자동 실행 스크립트, root 전환 여부, 색상. 비밀번호 포함을 고르면 비밀번호·패스프레이즈·su 비밀번호·점프 호스트 비밀번호·패스프레이즈.
- 항상 빼는 것: id, 폴더, 개인 키 경로(PC 마다 다름), MCP 접근 허용, DB 계정·별칭.

## 비밀번호 (공유 암호, 2026-11-12 사용자 승인)
- 앱에 키를 넣는 방식은 쓰지 않는다 (앱을 받은 누구나 풀 수 있다). 보낼 때마다 사용자가 공유 암호(10~200자)를 정하고 다른 경로로 알려 준다.
- `lib/shareCrypto.ts`: PBKDF2-SHA256 600,000회 → AES-256-GCM. salt 16바이트, iv 12바이트, 매번 새 난수.
- 암호화 대상은 세션들의 비밀번호 배열(폴더는 깊이 우선 순서)만. AAD 는 토큰의 평문 부분 글자 그대로: 호스트를 바꿔 치면 복호화가 실패한다.
- 평문 비밀번호 항목은 받지 않는다 (토큰에 있어도 버림). 반복 횟수는 100,000~2,000,000 만 받는다 (작은 값으로 약하게, 큰 값으로 앱을 멈추게 하는 토큰 방지).
- 가져오기에서 공유 암호를 넣어 풀거나 `비밀번호 없이 추가`.

## 읽기 (보안 경계)
- zod 엄격 스키마. 모르는 항목은 버린다 (`mcpEnabled`, `privateKeyPath`, `dbConnections` 가 들어 있어도 무시).
- 호스트·계정·이름: 앞뒤 공백 정리, 제어 문자 거부, 길이 제한 (호스트 253, 계정 64, 이름 100). 포트 1~65535 정수.
- 스크립트 4,000자, 비밀번호 1,000자까지. 토큰 2MB, 폴더 200개·세션 1,000개·깊이 10단계 초과 거부.
- 결과는 새 객체. `mcpEnabled: false`, `saveSession: true` 를 붙여 새 연결 창으로 넘긴다.

## 화면
- 세션·폴더 우클릭: `연결 정보 복사`, `비밀번호 포함 복사…` (경고와 공유 암호 입력 창 `SharePassphraseDialog.tsx`).
- 사이드바 머리줄 버튼과 폴더 우클릭: `텍스트로 세션 추가` → `SessionImportDialog.tsx`. 클립보드에 토큰이 있으면 채움. 미리보기(이름·주소·계정·인증·점프 호스트·비밀번호 포함 여부), 자동 실행 스크립트는 경고와 함께 원문 표시.
- `세션 편집에서 열기` → 기존 `ConnectModal` (duplicateFrom 경로, 제목 `공유받은 세션 추가`). 저장 경로는 기존 그대로.
