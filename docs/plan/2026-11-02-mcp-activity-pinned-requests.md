# MCP 활동: 진행 중인 요청을 패널 위에 고정

- 날짜: 2026-11-02
- 상태: 구현 완료

## 문제

요청이 끝나지 않은 채 다른 명령이 계속 오면, 진행 중인 요청이 기록 위쪽으로 밀려 올라가 아직 진행 중인지 알 수 없다.

## 결정 사항

1. 진행 중인 요청을 패널 위쪽에 고정한다. 터미널 보기와 목록 보기는 기록 위에, 서버별 보기는 영역마다 그 세션의 요청만 고정한다.
2. 카드 형식:

   ```
   [명령 한 줄, 길면 ...] [경과 시간] [중지] [접기/펼치기]
   [출력 마지막 줄]
   [출력 마지막 줄]
   [출력 마지막 줄]
   ```

   출력은 항상 3줄 높이를 차지한다 (출력이 나올 때마다 카드 높이가 바뀌면 아래 기록이 움직인다). 파일 전송은 출력 대신 진행 막대를, 확인 대기는 대기 문구를 보여 준다.
3. 시작한 지 3초가 지난 요청만 고정한다. 바로 끝나는 명령까지 고정하면 명령마다 카드가 나타났다 사라져 아래 기록이 흔들린다.
4. 기록에는 그대로 남긴다. 고정 카드는 요약이고 전체 출력은 기록에서 본다. 고정 때 기록에서 빼면 끝날 때 중간에 끼어들어 읽던 위치가 흔들린다.
5. 고정 순서는 오래 실행된 순서로 둔다 (새 요청이 와도 카드 위치가 그대로다). 고정 영역이 패널 높이의 40% 를 넘으면 그 안에서 스크롤한다.
6. 접힘 상태는 메모리에만 두고, 처음에는 펼친 상태다.
7. 마지막 줄 계산은 출력 끝부분 16KB 만 본다. 렌더링마다 최대 512KB 출력을 처리하면 패널이 느려진다.
8. 고정 영역이 나타나 기록이 줄어들어도 맨 아래를 따라가던 기록은 맨 아래를 유지한다.
