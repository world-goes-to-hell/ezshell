# 사이드바 세션 순서 드래그 변경

- 작성일: 2026-09-28
- 상태: 구현 완료

## 요구사항
- 같은 폴더 안에서 세션 위치를 드래그 앤 드롭으로 변경 (사용자 요청)
- 설계 승인 시 함께 합의: 다른 폴더의 세션 위에 놓으면 그 폴더로 옮기면서 그 위치에 넣음. 폴더 순서 변경은 범위 밖

## 설계
| 항목 | 결정 | 이유 |
|---|---|---|
| 순서 저장 | 세션 배열 순서 자체를 바꿈. 별도 order 필드 없음 | 사이드바는 이미 저장된 배열 순서대로 표시. 기존 데이터/백업과 호환 |
| 위치 판정 | 대상 행의 위쪽 절반이면 앞, 아래쪽 절반이면 뒤 | 흔한 목록 재정렬 방식 |
| 표시 | 대상 행 위/아래 모서리에 2px 강조색 선 (`inset box-shadow`) | 행 높이가 변하지 않아 드래그 중 목록이 흔들리지 않음 |
| 이벤트 | 세션 행이 세션 드래그의 dragover/drop 을 처리하고 전파를 막음. 폴더 드래그는 통과시켜 기존 폴더/최상위 드롭 유지 | 세션 위에 놓았는데 최상위 드롭까지 실행되면 폴더 밖으로 빠짐 |
