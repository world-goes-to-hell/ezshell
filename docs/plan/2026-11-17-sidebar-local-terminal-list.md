# 사이드바의 로컬 터미널 목록

작성일: 2026-11-17
상태: 구현 완료 (2026-11-17)
구분: 중간 (UI 기능)
목업: ezShell 사업의 `sidebar-local-terminals` (사용자가 ③안 선택)

## 동작
- 로컬 터미널 탭이 하나라도 열려 있으면 사이드바의 목록 영역이 위아래로 나뉜다: 위는 세션 목록, 아래는 열린 로컬 터미널 목록. 하나도 없으면 아래 영역을 그리지 않는다.
- 높이: 손대지 않으면 터미널 개수만큼 늘어나고, 목록 영역의 절반에서 멈춘다 (넘치면 아래 영역 안에서 스크롤).
- 가운데 손잡이를 끌면 그 높이로 고정한다. 이때는 절반을 넘겨도 되지만 세션 목록에 96px(약 세 줄)은 남기고, 아래 영역은 64px(머리줄 + 한 줄)보다 작아지지 않는다. 손잡이를 두 번 누르면 자동 높이로 돌아간다. 방향키 위·아래로도 조절한다.
- 줄을 누르면 그 탭으로 이동(`terminalStore.focusTerminal`, 분할 화면이면 그 패인에 포커스), X 는 탭 닫기와 같은 경로(`App.tsx` 의 `handleCloseTerminal`), 머리줄의 + 는 새 로컬 터미널, 머리줄 글자를 누르면 접기/펼치기.
- 지금 보고 있는 탭의 줄을 강조한다 (분할 화면이면 포커스가 있는 패인의 활성 탭).
- 접힌 사이드바(띠)에는 `로컬` 과 개수를 한 묶음 더한다.
- 높이와 접힘 여부는 `localStorage` 의 `sidebarLocalPane` 에 남긴다.

## 파일

## 검증
- 단위 테스트 7개 (`localTerminalPane.test.ts`).
- 개발 서버 화면에서 실제 포인터 입력으로 확인: 3개 → 131px, 10개 → 243px(목록 영역 488px 의 절반), 위로 끌기 → 392px(상한), 아래로 끌기 → 74px, 저장값 일치.
- 구현 중 잡은 문제: 포인터를 뗄 때 한 단계 전 높이가 저장됐다 (뗄 때의 처리기가 직전 렌더의 값을 갖고 있었다). 끄는 동안의 최신 높이를 ref 에 둔다.
