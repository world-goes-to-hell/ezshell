# 분리 창(SFTP 창, 터미널 창) 디자인 정리

## 요구사항
SFTP 패널과 터미널 탭을 새 창으로 분리할 수 있는데, 분리된 창의 디자인이 전혀 정리되어 있지 않다.

## 조사 결과 (2026-09-30, 검증용 앱에서 두 창을 띄워 캡처 + 계산된 스타일 확인)

### SFTP 창 (`SftpWindow`)
| 문제 | 원인 |
|---|---|
| 테마가 적용되지 않음 (메인 ayu-mirage, SFTP 창은 기본색) | `initializeTheme()` 를 호출하지 않아 `data-theme` 이 없다 |
| 최소화/최대화/닫기 버튼이 브라우저 기본 버튼(회색 바탕, 검은 테두리) | 존재하지 않는 클래스 `title-btn` 사용 (터미널 창은 `title-bar-btn`) |
| 업로드/다운로드/전송 큐 버튼이 32px 정사각형에 갇혀 아이콘이 사라지고 글자가 줄바꿈 | 하단 패널의 아이콘 버튼 규칙 `.sftp-btn`(32×32 고정)이 그대로 적용됨 |
| 제목이 `SFTP - 17907574` | 세션 이름 대신 세션 ID 를 표시 |

### 터미널 창 (`TerminalWindow`)
| 문제 | 원인 |
|---|---|
| 설정한 터미널 글꼴 크기/글꼴이 적용되지 않음 | `fontSize: 14`, `JetBrains Mono` 고정 |
| 분리하는 순간 기존 출력이 사라지고 빈 화면 | 화면 버퍼가 메인 창 xterm 에만 있고 새 창으로 넘기지 않는다 |
| 제목 표시줄/테마 | 정상 |

### 공통
- 두 창의 제목 표시줄이 서로 다른 마크업/CSS 로 따로 구현되어 있다.
- 테마를 바꿔도 이미 열린 분리 창에는 반영되지 않는다(창마다 별도 렌더러, localStorage 는 공유).

## 설계
1. **공용 제목 표시줄 `PopoutTitleBar`**: 아이콘 + 제목 + 보조 정보(`user@host`) + 추가 버튼 자리 + 창 제어 버튼.
   메인 창 `TitleBar` 와 같은 높이/색/버튼 스타일(`title-bar-*`)을 쓴다. SFTP 창과 터미널 창 모두 이것으로 바꾼다.
2. **테마 공유**: 분리 창 시작 시 테마 적용, 메인 창에서 테마를 바꾸면 분리 창이 `storage` 이벤트로 즉시 따라간다(분리 창에는 테마를 바꾸는 화면이 없어 메인 쪽 수신은 두지 않음). `hooks/usePopoutTheme.ts`.
3. **SFTP 창 도구 모음**: 창 전용 스타일로 아이콘 + 글자 버튼(높이 30px)으로 정리하고 전송 큐 배지 위치를 맞춘다.
4. **SFTP 창 제목**: `SFTP · 세션 이름 (user@host)`. 기존 `ssh-get-session-info` IPC 로 호스트 정보를 얻는다.
5. **터미널 창 글꼴**: `loadSettings()` 로 사용자의 터미널 글꼴 크기/글꼴을 적용한다.

6. **터미널 화면 유지** (2026-09-30 사용자 결정: 같이 고침)
   - `xterm-addon-serialize`(xterm 5 호환 0.11.0)로 화면을 문자열로 만들어 넘긴다. 최근 5000행까지.
   - 분리: 탭이 사라지기 직전에 화면을 캡처 → `open-terminal-window` 로 메인 프로세스에 맡김 → 새 창이 `take-terminal-snapshot` 으로 한 번 가져가서 먼저 그림.
   - 병합: 분리 창이 화면을 캡처해 `merge-terminal-to-main` 으로 전달 → 메인 탭이 마운트될 때 먼저 그림.
   - 단일 ↔ 분할 화면 전환으로 탭이 다시 만들어질 때도 같은 방식으로 화면을 보존한다(기존에는 사라졌다).
   - 메모리에만 보관한다(터미널 출력에는 비밀번호 등이 있을 수 있어 디스크에 쓰지 않음).

- E2E(검증용 앱 + 임시 SSH 서버, 12개 항목 통과)
  - SFTP 창: 테마 적용, 제목 "SFTP · 분리 창 테스트 tester@127.0.0.1:2222", 창 제어 버튼이 메인과 같은 46×32 투명 버튼,
    도구 모음 "업로드/다운로드/전송 큐" 가 아이콘 + 글자 한 줄(높이 30px)
  - 터미널 창: 테마, 제목 + user@host, 병합/최소화/최대화/닫기, **분리 전 화면 유지**
  - 메인에서 테마를 바꾸면 두 분리 창에 즉시 반영
  - 병합하면 메인 탭에 분리 전 + 분리 창에서 입력한 내용이 이어서 표시
- 캡처로 디자인 확인(SFTP 창, 터미널 창 어두운/밝은 테마).

## 코드 리뷰 반영 (2026-10-01)

- [MEDIUM] 분리 직후 몇 ms 사이 출력이 메인 창 버퍼에 남았다가, 병합 시 최신 화면 뒤에 붙어 순서가 뒤바뀌던 문제
  → 새 창이 열린 뒤 메인 창의 해당 세션 버퍼를 비운다(`discardSshDataBuffer`). 그 몇 ms 출력은 기존처럼 빠질 수 있다.
- [LOW] 병합 직후 탭이 마운트되기 전에 닫히면 넘겨받은 화면이 메모리에 남던 문제 → `removeTerminal` 에서 함께 버림.
- [LOW] 80×24 기본 크기에서 복원되어 vim/top 같은 전체 화면 프로그램이 잘릴 수 있던 문제 → 복원 전에 크기를 먼저 맞춤.
- [LOW] 병합 순간 몇 ms 사이 출력 누락 → 영향이 작아 주석으로만 남김.
- 남은 범위 밖: 메인에서 터미널 글꼴을 바꾸면 이미 열린 분리 창에는 반영되지 않는다(창을 새로 열 때 적용).
- 재검증: 테스트 269개 통과, 타입 체크 오류 0건, 분리 창 E2E 12개 항목 통과.
