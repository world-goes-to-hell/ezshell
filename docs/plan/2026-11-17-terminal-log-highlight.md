# 터미널의 오류·경고 줄 강조

상태: 구현 완료 (2026-11-17), 배포 전

## 요청

터미널에서 `tail -f` 로 로그를 볼 때 오류·경고 줄이 눈에 띄지 않는다. 파일 실시간 보기 창에는 강조가 있는데 터미널에는 없다.

## 결정

- 터미널 화면에 보이는 줄 가운데 오류·경고 줄에 옅은 바탕색과 왼쪽 선을 그린다 (오류 빨강, 경고 노랑).
- 판정 규칙은 파일 실시간 보기와 같은 `lib/logLevels.ts` 의 `classifyLine` 을 쓴다 (줄의 첫 수준 단어, 수준 단어가 없으면 예외 이름·스택 줄).
- `tail -f` 인지 가리지 않고 모든 출력에 적용한다 (`docker logs -f`, `journalctl -f`, `cat` 도 같은 로그다). 명령을 알아내려면 프롬프트를 읽어야 하는데 분할 셸·로컬 셸에서는 믿을 수 없다.
- 모든 터미널에 적용한다: 탭의 주 터미널, 분할 셸, 로컬 터미널, 분리한 창.
- 기본 켜짐. 우클릭 `편의` 의 `오류·경고 줄 강조 끄기/켜기` (`localStorage` 의 `terminalLogHighlight`).
- 서버에는 아무것도 보내지 않는다. 화면에 보이는 줄만, 프레임당 한 번 읽는다.

## 구현

- `lib/terminalLogRows.ts` (`visibleRowLevels`): 화면의 줄을 읽어 줄 번호 → 수준. 터미널이 너비에서 접은 줄은 한 줄로 이어 판정하고 접힌 모든 줄에 칠한다. 커서가 있는 줄(입력 중)과 명령 줄(`user@host:~$ grep ERROR app.log`)은 뺀다.
- `Terminal/terminalLogHighlight.ts` (`attachLogHighlight`): xterm 꾸밈(decoration)으로 그린다. 줄마다 표식(marker)에 달아서 출력이 흘러도 줄을 따라가고, 수준이 그대로인 줄의 꾸밈은 다시 만들지 않는다. 전체 화면 프로그램(vim, less)에서는 그리지 않는다.
- 메뉴 항목은 `terminalMenuCommon.tsx` 의 공통 항목이라 SSH·로컬 터미널 메뉴 모두에 나온다.

## 확인

- 단위 테스트 9개 (`terminalLogRows.test.ts`), 전체 2,636개 통과, 타입 검사 통과.
- 실제 앱(로컬 터미널): 오류·예외·스택 줄 빨강, 경고 노랑, INFO 줄과 명령 줄은 그대로, 출력이 더 흘러도 같은 줄에 유지, 메뉴로 끄고 켜기.
- 확인하지 못한 것: SSH 서버에서의 실제 `tail -f`, 분할 셸, 분리한 창 (같은 함수를 붙였지만 화면으로 보지는 않았다).

## 알고 있는 한계

- 프로그램이 스스로 색을 입힌 출력에도 바탕색이 겹친다.
- 소문자 `error` 단어만 있는 줄은 강조하지 않는다 (`0 errors` 같은 정상 줄 때문에, 파일 보기와 같은 규칙).
- 처음 보는 모양의 프롬프트에서 수준 단어가 든 명령 줄은 강조될 수 있다.
