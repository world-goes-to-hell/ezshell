# MCP 활동 서버별 보기: 영역 숨기기

- 날짜: 2026-10-24
- 상태: 구현 완료

## 요구

서버별 보기에서 영역마다 X 버튼으로 그 서버의 영역을 숨긴다. 그 서버에 다시 활동이 생기면 영역이 다시 보여야 한다.

## 결정 사항

1. 숨길 때 그 영역의 가장 최근 요청 ID 를 기억한다 (`sessionId → 요청 ID`). 영역의 가장 최근 요청이 기억한 ID 와 같으면 숨기고, 다르면(새 요청이 들어왔으면) 보인다.
   새 요청은 확인 대기든 바로 실행이든 모두 "다시 활동" 으로 본다. 숨길 때 이미 실행 중이던 요청의 출력이나 상태 변화는 새 활동으로 보지 않는다 (사용자가 그것을 보고 숨겼으므로).
2. 다시 보일 때는 영역 전체(이전 요청 포함)가 원래 자리에 나온다. 영역 순서는 첫 요청 순서라 그대로다.
3. 숨김 목록은 메모리에만 둔다 (활동 목록 자체가 메모리에만 있으므로 재시작하면 의미가 없다). 활동 목록을 지우면 함께 지운다.
4. 상단 막대에 숨긴 서버 수와 "모두 보기" 버튼을 둔다 (실수로 숨긴 것을 되돌릴 수 있게).
5. 판정 함수는 `lib/mcpActivity.ts` 의 `hideLane`, `isLaneHidden` 에 두고 테스트한다.
