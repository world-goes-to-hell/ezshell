# 채팅 답변을 다른 에이전트에게 인계

작성: 2026-11-25 (사용자 요청: 답변의 `답장`·`띄워 두기` 옆에 `인계` 버튼, 다른 에이전트를 고르고 코멘트를 붙여 넘기기)

## 동작
- 채팅 보기에서 답변에 포인터를 올리면 `답장`·`띄워 두기` 옆에 `인계` 버튼이 나온다.
- 누르면 채팅 화면 위에 인계 카드가 열린다 (대화 목록은 보이는 줄만 그리므로, 줄 안에 카드를 끼우면 높이가 바뀌어 대화가 움직인다).
  - 받을 에이전트 목록: 지금 연결된 다른 에이전트(이 칸의 에이전트는 뺀다). 줄마다 `리뷰어 · Codex 9` 이름, 상태, 폴더 이름을 보여 준다. 같은 프로젝트의 에이전트가 위에 온다.
  - 코멘트 입력칸(선택, 2,000자). Ctrl+Enter 로 보낸다.
  - 넘길 답변의 앞부분 미리보기(접힘).
  - `인계`·`취소`. Esc 는 카드만 닫는다 (채팅 보기의 Esc 인 작업 중지로 넘어가지 않게).
- 보내면 받는 에이전트의 받은편지함에 사용자 이름으로 메시지가 간다. 브라우저 탭의 `수정 요청` 과 같은 경로(`agentMessages.sendAsUser`)라 받는 쪽은 평소처럼 깨워지고, 읽음·답함 표시와 답장은 에이전트 메시지 창에서 본다.
- 성공하면 `Codex 9 에게 인계했습니다` 알림, 실패하면 카드 안에 이유를 보여 준다.

## 메시지 형식 (main 이 조립)
```
[인계] Claude Code 4(리뷰어)의 답변을 넘깁니다.

<코멘트>

--- 넘겨받은 답변 ---
<답변 본문>
```
메시지 한도 8,000자(`agentMessages.js` 의 `MAX_TEXT`) 안에 들도록 답변 끝을 줄이고 `(이하 생략)` 을 붙인다. 코멘트는 줄이지 않는다.

## 구현 위치
- 화면: `AgentChat/AgentChatCover.tsx` 의 답변 버튼 줄에 `인계`, 새 `AgentChat/ChatHandoff.tsx`(카드)와 CSS. 에이전트 목록은 이미 받고 있는 에이전트 메시지 스냅숏에서 고른다.
- main: IPC `agent-chat-handoff` (`src/agentChat/ipc.js`). 창은 셸 id·받는 에이전트 id·코멘트·답변 글만 보낸다.
- `main.js` 에서 `sendAsUser` 를 채팅 IPC 에 넘긴다.

## 검사 (main)
- 본창의 주 프레임, 잠금 해제 상태에서만 받는다.
- 보내는 칸의 셸에 에이전트가 있어야 하고, 받는 에이전트는 지금 연결된 에이전트여야 하며 자기 자신은 안 된다.
- 코멘트·답변은 `cleanChatText` 와 같은 규칙(제어 문자 거부)으로 검사한다.

## 범위 밖
- 원본 대화 전체나 이미지 넘기기, 여러 에이전트에게 한 번에 보내기, 휴대폰 채팅의 인계.
