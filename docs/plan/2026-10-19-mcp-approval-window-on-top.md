# MCP 확인 창이 뜨면 앱 창을 맨 위로

- 날짜: 2026-10-19
- 상태: 구현 완료

## 문제

MCP 확인 요청이 오면 작업표시줄 깜빡임과 Windows 알림만 있어서, 앱 창이 다른 창 뒤에 있거나 최소화되어 있으면 확인 창을 놓친다 (응답이 없으면 60초 뒤 거부).

## 결정 사항

1. 확인 요청이 화면에 떠 있는 동안 앱 본창을 "항상 위" 로 두고, 최소화되어 있으면 복원한다 (`setAlwaysOnTop(true)` + `showInactive()` + `moveTop()`).
2. 키보드 포커스는 가져오지 않는다. 사용자가 다른 프로그램(Claude Code 터미널 등)에서 입력하던 Enter·Esc 가 확인 창으로 들어가 의도하지 않게 응답하는 것을 막기 위해서다. 작업표시줄 깜빡임과 알림은 그대로 둔다.
3. 응답, 시간 초과, 취소(요청 중단, 잠금, MCP 끄기) 중 무엇으로든 확인이 끝나면 "항상 위" 를 푼다. 다음 요청이 대기열에 있으면 바로 다시 올린다.
   끝나는 시점은 `createApprovalBroker` 의 `onClose(id)` 로 받는다 (`dismiss` 는 응답했을 때 불리지 않으므로 따로 둔다).
4. 앱 창에 포커스가 있어도 똑같이 "항상 위" 로 둔다. 확인 중에 다른 창을 눌러도 확인 창이 가려지지 않게 하기 위해서다.

## 확인한 것

- Electron 28 / Windows 11: 최대화 후 최소화한 창에 `showInactive()` 를 부르면 최대화 상태로 복원되고 포커스는 없다 (`isFocused() === false`). 임시 스크립트로 확인했다.
