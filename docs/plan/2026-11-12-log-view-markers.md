# 실시간 보기 기준점

- 날짜: 2026-11-12
- 구분: 중간 (화면만, 서버에 보내는 것 없음. 위치 추적 로직은 테스트)
- 상태: 진행 중

## 요청
로그가 계속 쌓이는 동안 "여기부터 보겠다" 는 위치를 표시해 두고, 나중에 그 위치부터 내려가며 본다.

## 설계 (사용자 승인)
- 찍기: 제목 줄 깃발 버튼·`Ctrl+M` = 지금 로그 끝. 줄 번호 클릭 = 그 줄 위 (같은 자리면 지움). 최대 10개, 번호는 다시 쓰지 않음.
- 모양: 줄 사이 블록 위젯 `기준점 N · HH:MM:SS` + ✕. 문서 글자가 아니므로 복사·찾기·오류 개수에 섞이지 않는다.
- 위치 추적: `lib/logMarkers.ts` 의 StateField 가 위치를 변경마다 옮긴다 (`MapMode.TrackAfter`: 그 줄의 첫 글자가 지워지면 기준점도 빠짐). 오래된 줄 정리로 지워진 기준점은 빼고 `lost` 에 센다 → 창이 알림.
- 끝에 찍은 기준점은 뒤에 붙는 글자보다 앞에 남는다 (assoc -1): 새 로그가 기준점 아래로 쌓인다.
- 상태 줄: `기준점 N · 뒤 X줄` (가장 최근 기준점 뒤의 줄 수, 누르면 이동), ▲▼ 로 기준점 사이 이동.
- 저장하지 않음. 새로고침(`key={version}` 으로 화면을 새로 만듦)이면 사라진다.
