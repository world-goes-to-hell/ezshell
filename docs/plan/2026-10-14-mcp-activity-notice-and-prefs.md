# MCP 활동: 확인 알림 제목 보완, 보기 설정 기억

날짜: 2026-10-14 · 규모: 작음 (렌더러 중심, main.js 는 두 줄)

## 배경

- 확인 창이 뜰 때 앱 창이 뒤에 있으면 작업표시줄 깜빡임과 Windows 알림으로 알리는 기능은 이미 있다 (`main.js` 의 `alertMcpApproval`).
  다만 알림 제목이 "파일 쓰기"와 "명령" 두 가지뿐이라, 파일 전송과 백그라운드 실행도 "명령 확인 요청"으로 표시됐다.
- 활동 패널의 보기(목록/터미널/서버별)와 `작업 중만` 값은 메모리에만 있어서 앱을 다시 켜면 기본값으로 돌아갔다.

## 설계

- 알림 제목을 요청 종류별로 나눈다: 명령, 백그라운드 실행, 파일 쓰기, 파일 올리기, 파일 내려받기.
  제목을 고르는 함수는 `src/mcp/approvalNotice.js` 에 두고 테스트한다. 본문은 그대로 세션 이름과 위험도만 넣는다 (명령, 경로, 내용은 넣지 않는다).
- 보기와 `작업 중만` 값을 `localStorage` 의 `mcpActivityPrefs` 에 저장한다. 단축키, 최근 명령과 같은 방식이고 main 과 IPC 를 건드리지 않는다.
  `작업 중만` 값은 컴포넌트 상태에서 `mcpActivityStore` 로 옮긴다. 알 수 없는 값은 항목별로 기본값(`터미널`, 꺼짐)으로 바꾼다.
  요청 목록과 출력은 지금처럼 저장하지 않는다.
