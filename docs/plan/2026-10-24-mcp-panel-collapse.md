# MCP 활동 패널: 바깥을 누르면 오른쪽으로 접기

- 날짜: 2026-10-24
- 상태: 구현 완료

## 요구

MCP 활동 패널이 열린 채로 뒤의 셸이나 SFTP 패널을 누르면 패널이 오른쪽으로 줄어들고, 줄어든 패널을 다시 누르면 원래 크기로 돌아온다.

## 결정 사항

1. 앱 화면(`#root`) 안에서 패널과 상태바의 "MCP 활동" 버튼 밖을 누르면 접는다 (셸, SFTP, 사이드바 모두). 누른 동작은 막지 않으므로 셸 입력이나 SFTP 선택은 그대로 된다.
   확인 창, 메뉴처럼 `#root` 밖(포털)에 그려지는 것과 알림(`.toast-container`)은 접지 않는다 (확인 창을 누를 때마다 패널이 접히면 안 된다).
   다른 요소가 이벤트 전파를 막아도 잡히도록 `pointerdown` 을 캡처 단계에서 듣는다.
2. 접힌 패널은 없애지 않고 `transform` 으로 오른쪽으로 밀어 36px 띠만 남긴다. 스크롤 위치와 서버별 보기의 상태가 그대로 남는다. 띠에는 "MCP 활동" 과 확인 대기·실행 중 수를 보여 준다.
3. 띠를 누르거나 상태바 버튼을 누르면 펼친다. 상태바 버튼은 펼쳐져 있을 때만 닫는다 (`togglePanel`: 닫힘 → 열림, 접힘 → 펼침, 펼침 → 닫힘).
4. 접혀 있는 동안 화면 밖 내용은 `inert` 로 Tab 이동을 막고, Esc 로 패널을 닫지 않는다 (셸에서 vim 등으로 Esc 를 누를 때 패널이 닫히면 안 된다).
5. 접힘 상태는 메모리에만 둔다. 패널을 새로 열면 항상 펼친 상태다.
6. 줄어드는 움직임은 0.18초이고, 움직임 줄이기 설정에서는 바로 바뀐다.
