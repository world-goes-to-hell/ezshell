# 로컬 작업 프로젝트에 SSH 세션 묶기

날짜: 2026-11-19
상태: 구현 완료, 화면 테스트 전 (2026-11-19, e7 과 파일 조율 후 aa 가 구현)

구현 메모: 세션 우클릭 메뉴는 `로컬 작업에 묶기`(하위 패널에서 프로젝트를 고르면 묶기/풀기). 탭을 카드에 놓을 때 창으로 분리되지 않도록 `ezshell:tab-drop-taken` 으로 `App.tsx` 의 `mergeDropTaken` 을 세운다.

## 목표

사이드바의 로컬 작업 트리에서 저장된 SSH 세션을 로컬 프로젝트(저장소)에 연결해, 프로젝트 카드 안에 묶어 보여 준다. 앱을 다시 켜도 연결은 남는다.

## 동작

- 연결: 탭 줄의 SSH 탭을 프로젝트 카드에 끌어 놓기, 사이드바 세션을 프로젝트 카드에 끌어 놓기, 세션 우클릭 `로컬 작업에 연결 → <프로젝트>`.
- 표시: 프로젝트 카드 맨 위의 `서버` 줄. 세션 이름과 상태 점(열린 탭이 연결됨/끊김/없음). 누르면 열린 탭으로 가고(`focusTerminal`), 없으면 사이드바에서 누른 것과 같은 경로로 접속한다.
- 해제: 서버 줄의 X, 우클릭 `연결 해제`.
- 다시 켰을 때: 묶음만 보인다. 서버에 자동으로 접속하지 않는다 (운영 서버에 붙을지는 사용자가 정한다, 업데이트 뒤 탭 다시 열기와 같은 원칙).

## 정한 것

- 연결 단위는 프로젝트(저장소 루트, 저장소가 아니면 등록한 폴더)다. 같은 저장소의 워크트리는 대개 같은 서버를 쓴다.
- 저장된 세션만 연결한다. 빠른 연결 탭은 다시 찾을 ID 가 없어서, 놓으려 하면 이유를 알린다. 지워진 세션은 목록에서 빠진다(연결 정보는 그 세션이 다시 생기지 않으므로 다음 저장 때 정리).
- 저장 위치: `localStorage` 의 `ezshell.localProjectServers` = `{ [프로젝트 키]: savedSessionId[] }`. 세션 ID 만 둔다 (주소·계정 없음). 화면 설정 백업(`UI_SETTING_ENTRIES`)에는 넣지 않는다 (세션 ID 는 이 PC 의 세션 파일에만 뜻이 있다).
- 프로젝트 키는 트리가 이미 쓰는 `pathKey`(경로 비교용 형태)로 만든다.

## 바꿀 파일 (예상)

- 새로 만듦: `lib/localProjectServers.ts`(읽기·쓰기·연결·해제·끌기 데이터 해석, +테스트).
- 고침: `Sidebar/LocalProjectsTree.tsx`(서버 줄, 카드에 놓기), `Sidebar/LocalTerminalList.tsx`(세션·탭 정보와 접속 콜백 연결), 사이드바 CSS(`.local-servers*`), 세션 우클릭 메뉴(`Sidebar/SessionItem.tsx` 쪽), 화면 테스트(`local-workspace` 끝 또는 새 명세), `CLAUDE.md`.

## 시험

- 단위: 연결·중복·해제, 손상된 저장값 무시, 끌기 데이터(탭 ID → 저장 세션, `session:<id>`, 빠른 연결 거부).
- 화면: SSH 탭을 카드에 놓으면 서버 줄이 생기고, 창을 다시 불러와도 남으며, 누르면 그 탭으로 가는지. X 로 해제되는지.
