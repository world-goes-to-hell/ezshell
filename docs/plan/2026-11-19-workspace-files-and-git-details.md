# 작업 공간: 파일 열기·편집과 Git 변경 내용

작성: 2026-11-19. 상태: 1~3 완료 (2026-11-19, 화면 테스트 `local-workspace-files`), 4(모양 다듬기)는 GPT 세션에 맡김.

## 배경

작업 공간의 `파일`·`Git` 구역(`Workspace/WorkspaceBrowser.tsx`, main `src/ipc/localProjects.js`)은 지금 다음만 한다.

- 파일: 지금 폴더 한 단계의 이름만 보여 준다. 폴더를 펼치거나 파일을 열 수 없다.
- Git: 최근 커밋 100개의 그래프·제목·작성자만 보여 준다. 커밋에서 바뀐 파일, 커밋하지 않은 변경, 내용 비교가 없다.

사용자 요구 (2026-11-19): 폴더를 펼쳐 안쪽을 보고, 파일을 눌러 내용을 보고 고친다. Git 은 커밋마다 바뀐 파일, 마지막 커밋 뒤 커밋하지 않은 파일, 지금 파일과 Git 에 있는 내용의 비교를 본다.

## 결정

새 편집기를 만들지 않고 서버 파일 창(`RemoteFileWindow`, CodeMirror·좌우 비교 `RemoteCompareView`)을 다시 쓴다. 컨테이너 로그가 파일 대신 `container` 를 가진 문서로 그 창을 쓰는 것과 같은 방식으로, `local` 을 가진 문서를 더한다 (`src/remoteFiles/documents.js`).

### 1. 파일 트리

- 폴더 줄을 누르면 그 자리에서 펼친다 (폴더마다 처음 펼칠 때 한 번 읽음, 폴더당 1,000개는 지금 그대로).
- 파일 줄을 누르면 미리보기, 우클릭·버튼으로 편집. 이미지·PDF 는 미리보기만.
- `.git` 폴더는 목록에서 뺀다.

### 2. 로컬 파일 창 (서버 파일 창 재사용)

- main 의 `local-file-open({ root, path, mode })` 가 문서를 만들고 창을 연다. 읽기·저장은 `fs` 로 한다.
- 저장은 서버 파일과 같은 `review`(diff·토큰) → `save`(같은 내용의 SHA-256) 순서, 디스크 내용이 검토 때와 달라졌으면 쓰지 않는다. 5MB 이하 UTF-8 텍스트만 편집, CRLF 유지.
- 백업 목록 자리에 `Git (HEAD)` 항목을 둔다: 누르면 지금 내용과 HEAD 의 내용을 좌우로 비교하고, 가운데 » 로 그 부분만 되돌린다 (기존 비교 화면 그대로).
- 로컬 파일은 PC 백업 폴더에 따로 백업하지 않는다 (Git 이 있고, 저장 직전 확인 화면이 있다). 저장소가 아닌 폴더에서는 HEAD 비교 항목이 없다.

### 3. Git 변경 내용

- 목록 맨 위에 `커밋하지 않은 변경` 묶음: `git status --porcelain=v2 -z` 로 스테이징됨·수정됨·새 파일·삭제됨을 나눠 보여 준다. 파일을 누르면 로컬 파일 창이 HEAD 비교로 열린다 (오른쪽은 편집 가능).
- 커밋 줄을 누르면 펼쳐서 바뀐 파일 목록(`git show --name-status -z`, 추가·수정·삭제·이름 바꿈)을 보여 준다. 파일을 누르면 그 커밋의 부모와 커밋 내용을 읽기 전용으로 좌우 비교한다.

### 보안 (바꾸면 안 되는 것)

- 창은 경로를 마음대로 보내지 못한다. `root` 는 main 이 아는 폴더만 받는다: 열려 있는 로컬 셸의 시작 폴더, 그 Git 저장소의 최상위, 그 워크트리. 파일 경로는 `root` 기준 상대 경로이고, 실제 경로(링크를 푼 것)가 `root` 안이어야 한다. `\\host\share` 같은 네트워크 경로는 지금처럼 거부한다.
- 커밋은 `^[0-9a-f]{7,40}$` 만, 경로는 git 인자에서 `--` 뒤에 둔다. `git show <커밋>:<경로>` 의 경로는 `..`·절대 경로·제어 문자를 거부한다.
- 읽기 상한: 파일 5MB, diff 목록 2,000개, git 출력 4MB, git 명령 15초.
- 본창·잠금 해제 상태에서만 받고, 잠그면 로컬 파일 창도 닫는다 (서버 파일 미리보기 창과 같은 규칙, 편집 창은 저장하지 않은 내용 때문에 닫지 않음). MCP·원격 접속으로는 내보내지 않는다.

1. main: 로컬 문서(`documents.js`), `local-file-*`·`workspace-git-status`·`workspace-git-commit-files`·`workspace-git-file-at` IPC, 루트 검사. 단위 테스트.
2. 화면: 파일 트리 펼치기·열기, Git 의 변경 묶음과 커밋 펼치기, 로컬 파일 창의 HEAD 비교 항목.
3. 화면 테스트 `local-workspace-files`: 임시 저장소를 만들어 폴더 펼치기 → 파일 편집·저장 → 커밋하지 않은 변경에 나타남 → HEAD 비교 → 커밋 펼쳐 파일 비교.
4. 모양 다듬기는 GPT 세션에 맡긴다 (구조·동작은 이 계획대로 먼저 만든다).
