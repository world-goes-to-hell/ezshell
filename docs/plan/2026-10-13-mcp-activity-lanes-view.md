# MCP 활동: 서버별 보기

날짜: 2026-10-13 · 규모: 중간 (UI 편의 기능, main 프로세스·IPC 변경 없음)

## 배경

여러 에이전트가 여러 서버에 동시에 명령을 내리면, 터미널 보기에서는 서버가 다른 명령과 출력이 한 줄기로 섞인다.
어느 서버에서 무엇이 진행 중인지 한눈에 보기 어렵다.

## 설계

- 보기 전환을 `목록 | 터미널 | 서버별` 로 늘린다. 기본값은 `터미널` 그대로.
- `서버별` 보기는 세션(`sessionId`)마다 영역을 하나씩 만든다.
  - 영역 머리줄: 세션 이름, 실행 중 / 확인 대기 수. 작업 중인 영역은 테두리를 강조한다.
  - 영역 본문: 터미널 보기와 같은 항목(명령, 출력, 종료 상태, 중지). 영역마다 스크롤과 "맨 아래 따라가기"가 독립이다.
  - 배치: 1개면 전체, 2개 이상이면 2열 격자. 줄이 많아지면 세로 스크롤.
  - 순서: 첫 요청이 들어온 순서로 고정 (활동 때마다 바뀌면 읽던 영역이 움직인다).
  - `작업 중만` 토글로 끝난 서버의 영역을 숨긴다.
- 패널 너비는 `서버별` 보기에서 최대 1100px.

## 결정

- 기준은 서버 주소가 아니라 세션이다. 사이드바에서 보는 이름과 맞고, 활동 항목에 이미 `sessionId` 가 있어 렌더러에서만 묶으면 된다.
- 에이전트별 구분은 하지 않는다. MCP 서버가 stateless 이고 토큰이 하나라 요청을 보낸 에이전트를 알 수 없다.

## 테스트할 경우 (`groupBySession`)

- 세션별로 묶이고, 영역 안은 오래된 요청이 먼저다
- 영역 순서는 가장 오래된 요청의 시작 시각 순서다 (새 요청이 와도 바뀌지 않는다)
- 영역 이름은 그 세션의 가장 최근 요청의 이름이다 (세션 이름을 바꾼 경우)
- 실행 중 / 확인 대기 수를 센다
- 빈 목록은 빈 배열
