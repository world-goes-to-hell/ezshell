# 디자인 리뷰: 에이전트 경험 · 작업 공간 · 휴대폰 원격 접속 (2026-11-24)

리뷰한 사람: claude-2 (리뷰어). PL(claude-1)이 범위를 나눴고, 본창 구조·터미널·서버 작업 화면·설정은 claude-3 이 맡았다.
방법: `/plan-design-review` 의 7개 기준을 실제 코드·CSS·CLAUDE.md·`docs/plan/`·`mockups/` 에 적용했다. 화면을 띄워 보지는 않았다 (`npm run build` 금지 상황).
코드는 고치지 않았다.

이 스킬과 다르게 진행한 것:
- 지적마다 사용자에게 묻는 단계는 하지 않았다. 에이전트끼리 진행한 작업이라, 사용자 결정이 필요한 것을 맨 아래 §8 에 모았다.
- 시안 그림(mockup)은 만들지 않았다.
- 높게 매긴 지적 가운데 7개는 리뷰어가 코드에서 직접 다시 확인했다 (표시 `✔`).

DESIGN.md 가 없다. 기준으로 쓴 것:
- `src/renderer/styles/variables.css` 의 토큰
- `themes/` (`chatThemes.ts` 포함)
- CLAUDE.md 의 각 절
- 같은 앱 안의 다른 화면

뒤에서 다시 다루지만, 디자인 토큰 문서(반경·글자 크기·식별 색·주 버튼)가 없어서 생긴 어긋남이 세 영역 모두에 있다.

알려진 버그: 원격 접속의 "하루 동안 이 기기 기억"(새로 고치면 OTP 를 다시 물음)은 codex-5 가 고치는 중이다 (리뷰 8 통과). 이 문서에서는 동작을 평가하지 않았다. 다만 휴대폰 여정 점수는 이 버그 때문에 실제로는 더 나쁘게 느껴진다.

## 3. 정보 구조 (기준 1)

에이전트 채팅 보기, 지금 (`AgentChatCover.tsx:1261-1287`):
```
[종류 표지][역할·이름][제목 복사……………][상태][알림 종][테마]   ← 머리줄
[대화 (가상 목록) · ↑ 이전 질문 띠 · 맨 아래로]
[하단 안내 줄 4종이 번갈아: 질문 대기 / 차단 / 종료 / 시작]   ← 같은 자리, 다른 말투
[인용 카드][입력칸][보내기]
```
제안:
```
[종류·역할·이름][상태(쉬는 중 포함)] ………… [터미널 ⇄][알림][⋯ 테마·제목 복사]
[대화]
[상태 한 줄 + 버튼 하나]  ← 안내 줄은 한 형식으로
[입력칸]
```
- 머리줄의 첫째는 누구인지와 지금 상태, 둘째는 전환 동작이다. 제목 복사·테마는 `⋯` 로 내린다.
- 쉬는 상태도 `준비됨` 처럼 표시한다 (`STATUS_LABELS` 에 idle 이 없음, `AgentChatCover.tsx:52-60`).
- 하단 안내 줄 4종은 `상태 한 문장 + 버튼` 하나로 맞춘다 (`:1389-1413`).

작업 공간 (`WorkspacePanel.tsx`):
- 구역 탭이 아이콘뿐이다. 340px 이상이면 글자를 붙이고, `변경` 탭에 바뀐 파일 수 배지를 단다.
- 머리줄 순서가 구역마다 다르다. 대화 기록은 검색 → 대상이고(`AgentHistoryPanel.tsx:131-157`), 파일·Git 은 대상 → 검색이다. 공용 툴바(대상 → 검색 → 새로 고침)로 맞춘다.

휴대폰 (`web/`):
- 하단 탭 4개는 명확하다. 다만 보는 동안 대기 중인 일이 탭에 보이지 않는다 (확인 대기 수, 에이전트 차단).
- 폰 화면에 어느 PC 에 붙었는지가 없다 (`device-name` 은 이 휴대폰 이름). 같은 것을 두 이름으로 부른다: "에이전트/로컬 작업", "세션/연결 목록" (`agents.js:102`, `index.html:51`).

## 7. 반응형·접근성 (기준 6)

데스크톱 (에이전트·작업 공간):
- **12px 미만 글자가 많다.** 에이전트 쪽은 11px 21곳·10px 8곳이다 (읽음 상태·시각 `AgentMessages.css:187`, 관계도 메타 `:337-338,356`, 속도 버튼 `AgentUsage.css:50`, 슬래시 태그 `AgentChat.css:1151`). 작업 공간 쪽은 11px 에 `--text-muted` 를 겹쳐 쓴다. `--font-xs: 11px`·`--font-sm: 12px` 를 정하고 11px 를 하한으로 둔다. 정보를 담은 글자는 `--text-secondary` 를 쓴다.
- **보이지 않는 탭 정지:** 답변의 `답장`·`띄워 두기` 는 opacity 0 인데 포커스를 받는다. 답변마다 보이지 않는 탭 정지가 둘씩 생긴다 (`ChatQuote.css:1-42`, `AgentChat.css:619-646`). 답변 아래 줄로 옮기고 `:focus-within` 에서 보인다.
- **트리·탭이 키보드로 움직이지 않는다.** 작업 공간 트리는 `role="tree"` 인데 자식이 treeitem 이 아니고 방향키 처리가 없다 (`WorkspaceDetails.tsx:154`). 구역 tablist 도 방향키 이동이 없다 (`WorkspacePanel.tsx:108`). 변경 트리는 줄마다 탭 정지가 2~3개라, 2000줄이면 탭 정지가 수천 개가 된다. AskQuestionCard 의 `role="tablist"` 에도 tabpanel 과 방향키가 없고, `:focus-visible { outline:none }` 이라 포커스가 약하다 (`AskQuestionCard.css:51`).
- **바뀔 때마다 읽히는 영역:** 사용량 줄이 `role="status"` 이고 aria-label 이 계속 바뀐다. 갱신될 때마다 화면 읽기 프로그램이 읽는다 (`AgentUsageMeters.tsx:143`).
- **좁은·낮은 칸:** 사용량 줄의 3단계 컨테이너 쿼리는 좋다. 높이 쿼리는 없어 #10 이 생긴다. 작업 공간 280px 에서는 커밋 줄 메타·그래프(34%·120px)가 제목을 밀어낸다 (`Workspace.css:197`).

휴대폰:
- `maximum-scale=1` 이 손가락 확대를 막는다 (WCAG 1.4.4). 폼의 `autocomplete="off"` 가 OS 의 인증 코드 자동 채움을 막는다 (`index.html:5,21` ✔). 입력칸은 이미 16px 이상이라 확대 차단을 빼도 iOS 의 자동 확대는 일어나지 않는다. `autocomplete="one-time-code"` 를 넣고 6자리가 차면 자동으로 제출한다.
- 넓은 화면(태블릿)의 터치 영역이 44px 미만이다: 트리 줄 38, 탭 닫기 30, `중지` 30, 칩 32, 추가 키 42 (`app.css:957,1025,745,266`). `@media (pointer: coarse)` 에서 44px 이상으로 키운다.
- safe-area 는 아래만 반영돼 있다. 위·좌우가 빠져 가로·홈 화면 앱 모드에서 노치가 화면을 가린다 (`app.css:76,233`).
- 승인 카드가 `role=dialog` 인데 포커스를 옮기지 않는다. 카드 안 diff 가 카드 스크롤 안에서 또 스크롤된다 (`approvals.js:121-129`, `app.css:594`).
- PC 탭을 PC 의 칸 수(예: 200칸) 그대로 13px 로 그려 가로로 계속 밀어야 한다 (`app.js:426`).
