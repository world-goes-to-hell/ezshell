# MCP 활동: 파일 전송 진행 막대, 서버별 영역 끌어서 옮기기, 새 창

- 날짜: 2026-10-24
- 상태: 구현 완료

## 요구

1. MCP 로 파일을 올리는(내려받는) 과정을 눈으로 볼 수 있게 한다.
2. MCP 활동에 기록된 것을 끌어서 위치를 바꿀 수 있게 한다.
3. MCP 활동을 새 창으로 띄울 수 있게 한다.

## 결정 사항

### 1. 파일 전송 진행 막대
- 지금은 1초마다 "진행: 12MB / 40MB (30%)" 같은 글자 줄만 출력에 쌓인다. 활동 항목에 구조화된 `transfer`(방향, 전체 크기, 보낸 크기, 복사 시작 시각)를 넣고, 같은 1초 간격으로 갱신한다 (`transferTools.js`).
- 목록, 터미널, 서버별 보기 모두 막대를 보여 준다: 방향, 보낸 크기 / 전체 크기, 백분율, 속도, 남은 시간. 끝나면 "완료", 실패·중지면 멈춘 위치에서 "중단됨" 으로 표시한다. 계산은 `lib/mcpTransfer.ts` 의 `describeTransfer` 에 두고 테스트한다.
- 속도는 복사 시작 시각부터 계산한다 (요청 시각부터 계산하면 확인 창을 기다린 시간이 섞인다).

### 2. 서버별 영역 끌어서 옮기기
- 개별 기록은 시간순 기록이라 순서를 바꾸면 의미가 깨진다. 그래서 끌어서 옮기는 대상은 서버별 보기의 영역(세션)으로 한다.
- 영역 머리줄을 잡고 다른 영역 위에 놓으면 그 자리로 옮긴다. 순서는 메모리에만 둔다 (활동 목록도 메모리에만 있으므로). 처음 보는 세션의 영역은 끝에 붙는다. 순서 계산은 `lib/mcpActivity.ts` 의 `orderLanes`, `moveLane` 에 두고 테스트한다.
- 끌기 데이터는 앱 전용 형식(`application/x-ezshell-mcp-lane`)만 받는다 (탭 끌기나 파일 끌어 놓기와 섞이지 않게).

### 3. 새 창
- 패널 머리줄의 "새 창으로 열기" 로 MCP 활동 창을 연다. 창은 하나만 두고, 이미 있으면 앞으로 가져온다. 열면 본창의 패널은 닫는다.
- 창은 같은 화면(`McpActivityPanel` 의 `window` 형태)을 쓰고, 활동 목록은 창마다 main 에서 받아 온다 (`mcp-list-activity`, 실시간 갱신 `mcp-activity`, `mcp-activity-output` 은 본창과 새 창 모두에 보낸다).
- 앱을 잠그면 새 창을 닫는다. 명령 출력에 비밀이 섞일 수 있어 잠금 화면 뒤에 남기지 않는다. 잠긴 동안에는 열 수 없다.
- 확인 창은 계속 본창에만 뜬다 (본창이 맨 위로 올라온다).
