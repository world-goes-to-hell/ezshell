# 접힌 사이드바 UI/UX 개선

## 배경
접힌(compact) 사이드바는 같은 모양의 동그라미만 한 줄로 늘어서 있어서, 세션 28개를 쓰는 현재 상태에서는 원하는 세션을 찾으려면 하나씩 호버해야 한다.
레이아웃 버그(가로 넘침, 표시 막대 잘림, 상태 점이 아이콘을 밀어냄)도 있다. 사용자가 개선 방향을 맡겼다.

## 결정 사항
| 문제 | 결정 | 이유 |
|---|---|---|
| 세션 식별 | 아이콘이 기본값(`server`/미지정)이면 이름에서 만든 약어(최대 3자)를 원 안에 표시 | 실제 세션 이름이 `[개발] 바우처 WAS` 형식이라 앞 글자로는 구분이 안 된다. 대괄호 접두어를 떼고 마지막 단어(역할)를 쓴다 |
| 폴더 구분 | 폴더마다 약어가 들어간 작은 폴더 표지를 두고, 클릭하면 펼침/접힘(펼친 모드와 상태 공유) | flyout 보다 구현이 단순하고, 접어 두면 목록 길이도 줄일 수 있다 |
| 세션 색상 | 인라인 배경 대신 CSS 변수로 원 테두리/배경에 반영 | 인라인 배경이 hover 규칙을 이기던 문제 해결 |
| 레이아웃 | 행은 전체 폭, 원(40px)은 행 안에서 가운데. 표시 막대는 행 왼쪽 끝. `scrollbar-gutter: stable` + 얇은 스크롤바, 가로 넘침 숨김 | 폭 계산이 스크롤바 유무와 무관해진다 |
| 상태 점 | 원 오른쪽 아래 배지로 겹쳐 표시 | 아이콘이 가운데에서 벗어나지 않는다 |
| 숨겨진 기능 | 빠른 연결, 새 폴더(사이드바를 펼치고 입력창 열기), 배치, 통계를 아이콘 버튼으로 표시 | 접힌 상태에서도 모든 기능에 접근 |
| 토글 단축키 | `Ctrl+Shift+B` | `Ctrl+B` 는 tmux prefix 라서 피한다 |
| 연결 동작 | 더블클릭 유지 | 운영 서버가 많아서 한 번 클릭으로 연결되면 실수 위험이 크다 |
| 모양 | 원 대신 사각 타일 | 앱 전체가 `--radius-*: 0` 인 사각 디자인이다 |
| 글자 크기 (사용자 피드백) | 폭 72→80px, 타일 40→44px, 세션 약어 11→14px, 폴더 표지 10→12px, 자간 축소 제거, 접힌 폴더 흐림(opacity) 제거 | 12px 미만에서는 한글 획이 뭉개져 읽기 어렵다 |
| 깊은 폴더 (사용자 질문: 4~5단계) | 접힌 모드에서는 폴더의 세션을 하위 폴더보다 먼저 그리고, 표지를 단계마다 6px 들여쓰기(3단계부터 동일), 툴팁에 상위 경로 표시. 펼친/접힘은 폴더 아이콘 대신 화살표로 표시 | 이전에는 모든 하위 폴더가 같은 모양이었고, 상위 폴더의 세션이 마지막 하위 폴더 안에 있는 것처럼 보였다 |
