# 원격 접속: 2차 인증 뒤 하루 동안 코드 없이 재접속

- 날짜: 2026-11-13
- 구분: 중간 (원격 접속의 인증 경계를 바꾼다. 보안 리뷰 대상)
- 상태: 구현 중

## 요청
휴대폰에서 2차 인증(인증 앱의 6자리 코드)을 하고 접속하면, 하루 동안은 다시 코드를 넣지 않아도 접속이 유지되도록 한다. 지금은 연결이 끊기거나(15분 무입력) 화면을 새로 열 때마다 코드를 다시 넣어야 한다.

## 결정
- 2차 인증에 성공하면 그 기기에만 쓰는 **재접속 표(trust ticket)** 를 서버가 발급한다. 32바이트 무작위 값이고, PC 에는 기기 토큰과 똑같이 **해시로만** 저장한다. 만료 시각(발급 시점 + 24시간)을 함께 둔다.
- 휴대폰은 이 표를 `localStorage` 에 저장하고, 24시간 안에 다시 연결하면 코드 대신 `resume`(토큰 + 표)으로 바로 들어온다.
- 로그인 화면에 `하루 동안 이 기기 기억` 체크박스를 둔다 (기본 켬). 끄고 접속하면 표를 발급하지 않아 지금과 같다 (매번 코드).
- 유지 기간은 **발급 시점에서 고정 24시간**이다. 지나면 코드를 다시 받고, 성공하면 새 표가 나온다 (연장식이 아니다).

## 보안 경계 (바꾸면 안 되는 것)
- 표는 두 번째 요소를 대신할 뿐, **기기 토큰(소유 요소)은 여전히 필요**하다. `resume` 은 토큰과 표가 모두 맞아야 한다.
- 표는 평문으로 저장하지 않는다 (해시만). 파일 사본만으로는 표를 알 수 없다.
- 표가 없거나 24시간이 지난 경우는 실패로 세지 않는다 (예상된 일이다). 조용히 코드 입력으로 넘어간다.
- 표가 있고 만료 전인데 값이 틀리면 실패로 센다 (`failed`, 기존 잠금 보호를 그대로 적용: 기기당 5번이면 5분 잠금).
- 앱이 잠겨 있으면 포트가 닫혀 아무것도 받지 않는다 (기존과 같다). 표가 있어도 잠긴 동안에는 접속할 수 없다.
- 기기를 해제하면(`revoke`) 표도 함께 사라진다. 만료된 표는 다음 `resume` 때 지운다.
- `MAX_CLIENTS`·주소별 제한·Tailscale 주소 확인 등 다른 모든 검사는 `signin` 과 똑같이 `resume` 에도 적용한다.

## 구성
- `src/remoteAccess/accessStore.js`: `rememberDevice(deviceId)`(표 발급), `resume(token, ticket)`(표로 접속), `forgetDevice(deviceId)`, 상수 `TRUST_MS`. 기기 레코드에 `trust: { hash, expiresAt }` 추가.
- `src/remoteAccess/server.js`: `signin` 에 `remember` 처리와 `ready` 의 `trust` 전달, 새 메시지 `resume`, 오류 코드 `trust-expired`·`bad-ticket`, 공통 진입 함수 `enter`.
- `src/remoteAccess/web/app.js`: 표 저장·사용(`resume`), 체크박스, 만료 전이면 코드 화면 대신 바로 재접속.
- `src/remoteAccess/web/index.html`: 로그인 폼에 체크박스.

## 보안 리뷰 반영 (security-reviewer)
우회 가능한 치명적 결함은 없었다. resume 는 signin 과 같은 모든 검사를 지나고, 표는 256비트 무작위·해시 저장·상수시간 비교이며, 만료는 서버 시각으로만 본다. 다음을 고쳤다.
- **MEDIUM**: 원격 접속을 껐다 켜도 표가 24시간 남아 분실한 폰이 들어올 수 있었다 → `setEnabled(false)` 가 모든 기기의 표를 지운다. (앱 잠금은 포트만 닫고 표는 남긴다: 잠금 해제는 PC 앞 사람이 하고, 이 기능의 목적이 잠금 해제 뒤 코드 없이 재접속이기 때문이다. 기기 분실은 기존대로 기기 해제로 막는다.)
- **LOW**: 표를 `enter()` 성공 뒤에 발급하고 별도 `trust` 메시지로 보낸다 (전에는 `MAX_CLIENTS` 로 막히면 전달 못 한 표가 유효한 옛 표를 덮어썼다).
- **LOW**: `기억` 체크 없이 로그인하면 옛 표를 지운다 (`forgetDevice`).
- 체크박스 기본값은 켬으로 둔다 (사용자가 "하루 유지"를 요청했다. 기기별로 끌 수 있다).
