# 사이드바 로컬 작업 트리 (2026-11-19)

## 요청

로컬 터미널에서 에이전트로 작업하는 흐름을 Orca 처럼 만들기. Orca 왼쪽 패널처럼 "저장소 → 워크트리 → 에이전트" 를 보여 주고, 컴퓨터를 껐다 켜도 기억한다.

## 결정

- 사이드바 목록 위에 서버/로컬 전환을 두지 않는다 (사용자 결정). 아래쪽 로컬 터미널 칸을 `로컬 작업` 트리로 바꾸고, 절반 높이 제한을 푼다 (세션 목록은 약 세 줄, 96px 를 남긴다).
- 저장소 목록은 `로컬 작업` 창과 같은 `localStorage` 의 `ezshell.localProjects` 다 (`lib/localProjectList.ts`, 앱 데이터 폴더에 있어 재시작 뒤에도 남는다). 두 곳이 같은 모듈로 읽고 쓰며 `ezshell:local-projects-changed` 이벤트로 서로 갱신한다. 처음 제안은 main 파일로 옮기는 것이었으나, 같은 이유로 남는 데다 옮기면 대화상자·마이그레이션이 늘어 그대로 두었다.
- 워크트리는 기존 `local-project-inspect`(`git worktree list`)로 읽는다. 목록이 바뀔 때, 새로 고침 버튼, 창에 포커스가 돌아올 때(30초 간격)만 묻는다 (`hooks/useLocalProjects.ts`). 계속 돌려 보지 않는다.
- 트리: 저장소(같은 저장소의 두 번째 등록 폴더는 하나로) → 워크트리(이름, 여러 개일 때 기본 체크아웃에 `기본`, 브랜치, 열린 탭이 있으면 초록 점) → 그 워크트리에서 연 로컬 터미널 탭(기존 줄 그대로: 칸 배치 표지, 닫기, 에이전트 칩). 어느 워크트리에도 속하지 않는 탭은 `다른 로컬 터미널` 아래.
- 탭의 소속은 셸을 연 폴더(`TerminalInfo.local.cwd`)가 워크트리 폴더이거나 그 아래인지로 정하고, 겹치면 가장 깊은 워크트리 (`lib/localWorkspaceTree.ts`, Windows 경로는 대소문자·슬래시 무시).
- 워크트리를 누르면 열린 탭이 있으면 그 탭으로, 없으면 그 폴더에서 로컬 터미널을 연다 (탭 이름 `<저장소> · <브랜치>`, 대화상자와 같은 형식). 접힘은 `ezshell.localTreeFolded`.
