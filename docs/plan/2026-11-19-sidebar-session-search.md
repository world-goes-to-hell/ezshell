# 사이드바 세션 찾기 (2026-11-19)

## 요청

- 저장된 세션 찾기 창(`기존 세션 선택`)이 불편하니 검색칸을 사이드바로 옮긴다.
- 검색해도 일치하지 않는 세션이 목록에서 사라지면 안 된다. 일치한 세션을 강조하고 그 세션으로 이동(포커스)하면 된다.

## 결정

- 사이드바 버튼 줄 아래, 세션 목록 위에 검색칸을 늘 둔다 (`Sidebar/SessionSearchBox.tsx`). 머리줄의 돋보기 버튼은 없앴다.
- 찾는 규칙(`lib/sessionSearch.ts`): 공백으로 나눈 낱말이 모두(AND) 세션 이름·호스트·계정·폴더 이름 어딘가에 들어 있으면 일치, 대소문자 무시. 찾기 창의 퍼지 검색은 엉뚱한 세션이 섞여 쓰지 않았다.
- 목록은 거르지 않는다. 일치한 세션 줄은 옅은 강조색, 이름의 일치한 글자는 표시, 폴더 이름의 일치한 글자도 표시한다.
- 일치한 세션이 든 폴더는 검색하는 동안만 펼쳐 보인다. 저장된 펼침 상태(`expandedFolders`)는 바꾸지 않아, 검색을 지우면 원래대로 접힌다. 검색 중 사용자가 접은 폴더는 낱말이 바뀔 때까지 접힌 채로 둔다.
- 현재 일치 항목(테두리)은 트리 순서의 첫 번째이고 화면에 보이게 스크롤한다. `↑`/`↓`(또는 칸의 화살표 버튼)로 바꾸며 입력 포커스는 검색칸에 남는다. `Enter` 는 현재 일치 항목에 접속, `Esc` 는 검색어를 지운다. 칸에 `현재/전체` 개수.
- 탭 줄 `+` 메뉴의 `기존 세션 선택…` 과 시작 화면의 `저장된 세션 찾기` 는 찾기 창을 그대로 쓴다 (사이드바를 접었거나 집중 모드일 때도 세션을 고를 수 있어야 한다).
