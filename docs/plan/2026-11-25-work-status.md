## 5. 2.34.0 릴리스 노트 초안

배포할 때 `release-notes/2.34.0.md` 로 옮긴다. 미리 옮기지 않은 이유: 그 폴더의 파일은 앱에 묶여 "업데이트 내용" 에 쓰인다.

```markdown
## 에이전트 메시지와 채팅

- Claude Code·Codex 가 직접 알려 주는 신호로 작업 상태를 정합니다. 쉬는 에이전트를 `작업 중` 으로 보거나, 일하는 에이전트를 쉬는 것으로 보던 일이 크게 줄었습니다.
- 작업 중인 에이전트에게 온 메시지는 입력칸에 알림 문장을 끼워 넣지 않고, 하던 일을 마치는 순간 이어서 읽게 합니다. 좁은 칸에서 알림 문장이 입력칸에 남아 대화가 멈추던 문제가 없어졌습니다.
- `설정 → MCP → 에이전트 메시지` 의 **에이전트 상태 알림** 에서 끌 수 있습니다. 끄면 예전처럼 터미널 화면을 보고 판단합니다.
- Codex 는 처음 한 번 Codex 화면의 `Hooks need review` 에서 ezShell 의 훅을 승인해야 합니다. 칸 위에 안내가 뜨고, `묻지 않기` 를 고르면 다시 묻지 않습니다.
- Claude 의 선택지 질문에서 채팅 카드와 터미널 양식이 번갈아 뜨던 문제를 고쳤습니다. 터미널에서 답하기 시작하면 그 질문이 끝날 때까지 카드를 다시 띄우지 않습니다.
- 에이전트가 잠들 때 다른 칸에서 치던 `Enter` 가 그 에이전트를 깨우던 문제를 고쳤습니다.
- 채팅 머리줄의 에이전트 이름이 `cla...` 처럼 잘리던 문제를 고쳤습니다.
- 에이전트 툴팁에 상태를 어떻게 판단했는지(에이전트가 알려 준 신호인지, 터미널 화면을 본 것인지)가 나옵니다.
- 영역 캡처의 `바로작업` 대상 목록에 에이전트의 역할이 함께 나옵니다.

## 터미널

- 로컬 터미널 탭은 칸 개수 제한 없이 나눌 수 있습니다. SSH 탭은 서버의 채널 제한 때문에 지금처럼 6칸까지입니다.
- 탭이 많으면 탭 줄이 가로로 스크롤되고, `+` 버튼은 항상 오른쪽에 보입니다.
- `Alt` 로 끌어 칸을 닫을 때 그 칸에서 명령이나 에이전트가 실행 중이면 한 번 묻습니다.

## 작업 공간

- Git 변경 목록과 기록 조회가 빨라졌습니다(변경 목록 약 4배). 다시 열 때는 지난 결과를 먼저 보여 주고 뒤에서 새로 읽습니다.

## 서버 작업

- 서버 파일 저장·충돌, SFTP 원격 삭제 확인 창에 어느 세션인지 이름과 색이 나옵니다. 충돌 창의 `내 변경 버림` 은 위험 버튼으로 바뀌었습니다.
- MCP 확인 창은 위험도와 명령을 먼저 보여 줍니다. 긴 명령도 끝까지 봐야 `허용` 이 눌리고, 대기 중인 다음 요청 수가 보입니다.
- DB 의 `읽기 전용` 배지가 엔진마다 실제로 누가 쓰기를 막는지 보여 줍니다 (SQL Server 는 `앱 검사`, Oracle 은 `일부 앱 검사`).
- 컨테이너 패널의 시작·재시작·중지는 `명령 넣기` 로 이름이 바뀌었습니다. 입력줄에 넣기만 하고, `Enter` 를 눌러야 실행됩니다.
- 파일 탐색기가 읽지 못한 폴더를 빈 폴더로 보이던 문제를 고쳤습니다. 원인과 `다시 시도` 가 나옵니다. SFTP 오류 알림이 한국어로 나옵니다.

## 휴대폰 원격 접속

- 새로 고침하면 하루 동안 기억한 인증이 풀리던 문제를 고쳤습니다.
- 목록이나 MCP 활동으로 가도 열어 둔 SSH 셸이 10분 동안 유지되고, `연결 종료` 로 직접 닫을 수 있습니다.
- 화면을 다시 켜거나 연결이 끊기면 자동으로 다시 접속해 보던 화면으로 돌아갑니다.
- iPhone 에서 화면 키보드가 터미널 입력줄을 가리지 않습니다. 넓은 화면에서는 PC 처럼 배치됩니다.

## 그 밖

- 상태 줄이 실제로 연결된 SSH 탭과 재연결 중·끊긴 탭을 따로 셉니다.
- 업데이트 다운로드가 실패하면 알림이 사라지지 않고 `다시 시도` 와 `릴리스 목록` 이 나옵니다.
- MCP 실행 기록을 읽지 못하면 앱 화면이 하얗게 되던 문제를 고쳤습니다.
```

## 6. 작업 방식 메모 (이번 세션에서 정한 것)

- 여러 에이전트가 같은 작업 폴더의 `main` 에서 일했다. 워크트리를 쓰지 않았고, 커밋은 PL(Claude) 만 했다.
  - 역할: 리뷰어, 화면 개발, main 개발, 개발, 검증.
  - 역할과 에이전트 번호는 그 PC 의 ezShell 실행에만 있다. 회사에서는 다시 정한다.
- 검증용 복사본: `git archive HEAD` 에 그 묶음 파일을 얹고 `node_modules` 를 정션으로 잇는다.
  - 지울 때는 정션을 먼저 `cmd /c rmdir` 로 끊는다 (그대로 지우면 원래 `node_modules` 가 지워진다).
- 전체 화면 테스트가 줄줄이 "앱이 디버깅 포트를 열지 않음" 으로 실패하면, 멈춘 node-pty 도우미(`conpty_console_list_agent`)가 포트 9333 을 잡고 있는 것이다. 그 프로세스를 끝내고 명세를 하나씩 다시 돌린다.
- 실제 CLI 로 훅을 시험하는 방법: CLAUDE.md `Agent State From Official Signals` 절의 "실제 CLI 로 시험할 때".
