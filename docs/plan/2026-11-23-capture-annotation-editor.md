# 영역 캡처의 이미지 편집 (표시하고 수정 요청)

2026-11-23 사용자 요청: `Ctrl+Win+Alt` 캡처 → 그림에 화살표로 문제 부분 표시 → 수정 요청 코멘트. 덧붙이면 좋을 기능은 함께 넣어도 된다고 했다.

## 지금 상태 (다른 에이전트가 만든 것, `src/quickCapture.js`·`src/quickCaptureOverlay.js`)
- 지금 모니터를 멈춘 그림으로 덮고(`data:` 페이지, preload 없음, sandbox) 영역을 끌어 고른다.
- 고른 뒤 코멘트 칸과 `복사`(그림+코멘트를 클립보드) / `바로작업`(프로젝트 → 에이전트를 골라 그림 파일과 코멘트를 메시지로 보냄).
- 덮개와 main 은 `executeJavaScript` 의 돌려받는 값으로만 주고받는다.

## 흐름
영역 선택 → **편집** (고른 영역 위에서 표시) → 코멘트 → `복사` / `바로작업`.
- 영역을 고르면 바로 편집 상태다. 도구 막대는 영역 바깥(위 또는 아래)에 붙는다. 코멘트 칸은 지금 자리 그대로.
- `영역 다시 고르기` 로 표시를 버리고 처음부터.

## 도구
- **화살표** (기본): 끈 방향으로 화살표. 문제 부분을 가리키는 주 도구.
- **사각형**: 테두리만.
- **펜**: 자유선.
- **글자**: 누른 자리에 한 줄 글자.
- **번호**: 누를 때마다 ①②③… 원. 처음 붙일 때 코멘트 칸에 `1. ` 줄을 더해 번호와 설명을 잇는다 (덧붙인 기능).
- **모자이크**: 끈 사각형을 픽셀화. 비밀번호·토큰·개인 정보를 가리고 보내기 위한 것 (덧붙인 기능).
- 색 5개(빨강 기본, 노랑, 초록, 파랑, 흰색), 굵기 3단계. 되돌리기·다시(`Ctrl+Z`/`Ctrl+Y`, 버튼), 모두 지우기.

## 결과 그림
- 표시는 덮개의 캔버스에서 원본 화소 기준으로 그린다 (화면 배율·DPI 와 무관하게 선명). 덮개가 고른 영역의 원본 화소에 표시를 합친 PNG 를 만든다.
- main 은 그 PNG 를 그대로 믿지 않는다: `data:image/png;base64,` 형식, 크기 상한(48MB), `nativeImage` 로 읽혀야 하고 크기가 고른 영역의 화소 크기와 같아야 한다. 아니면 표시 없는 원본 영역을 쓴다.
- `복사` 와 `바로작업` 모두 표시가 합쳐진 그림을 쓴다. 표시가 없으면 지금처럼 원본 영역.

## 바꾸지 않는 것
- 덮개는 여전히 preload·Electron API 없이 `data:` 페이지이고 CSP 그대로다 (캔버스는 `data:` 그림만 쓴다).
- 프로젝트·에이전트 고르기와 보내기 경로(`sendCapture`)는 그대로 쓴다.
