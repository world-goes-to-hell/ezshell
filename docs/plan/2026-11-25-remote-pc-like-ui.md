# 휴대폰·태블릿 원격 접속을 PC 와 비슷한 UI/UX 로 (2026-11-25)

사용자 요청: "모바일 / 태블릿 환경에서 PC 와 유사한 UI/UX 제공할 수 있도록 개선".

## 1. 지금 상태

- 휴대폰(좁은 화면): 아래 탭 4개(세션·PC 탭·MCP 활동·에이전트)로 화면을 바꾼다. 한 번에 한 화면만 보이고, 터미널·채팅을 열면 목록이 사라진다 (`web/app.js` 의 `layout`).
- 태블릿(45rem 이상, 높이 40rem 이상): 왼쪽에 연결 목록과 로컬 작업, 오른쪽에 지금 연 항목 하나 (`data-workspace`, 2026-11-24 `e276eb1`). 제목줄·탭 모양·아이콘·글꼴은 데스크톱 파일을 가져온다.
- 서버는 이미 한 기기가 PC 탭 여러 개를 동시에 이어 볼 수 있다 (`server.js` 의 `client.tabs` 가 Map). 원격 셸은 6개, 채팅은 기기당 4개까지다. 그런데 화면은 열린 항목을 하나만 보여 준다: 탭 줄에 탭이 하나뿐이고, 다른 것을 열면 앞의 것을 닫거나 구독을 끊는다 (셸만 10분 유지).
- PC 와 다른 점:
  - 열린 것들을 탭으로 오가지 못한다 (PC 의 탭 줄).
  - 사이드바 모양이 다르다: PC 세션 트리의 폴더 색 선·상태 점·열린 탭 수 배지, 로컬 작업 트리의 에이전트 칩과 작업 중 테두리 빛이 없거나 다르게 생겼다.
  - 채팅이 단순하다: PC 채팅의 말풍선 배치·시각·도구 블록·질문별 토큰 줄·확인 카드·Claude 질문 카드가 없다.
  - 상태 줄이 연결 상태와 기기 이름뿐이다 (PC 는 연결 수·MCP 활동·작업 공간 등).
  - 터미널 색이 테마의 ANSI 16색(`--t-*`)을 받지 않는다 (디자인 리뷰 §6).
  - 휴대폰에서는 목록과 열린 항목이 한 화면에 함께 있을 수 없다.

## 2. 목표

PC 앱을 써 본 사람이 휴대폰·태블릿에서 같은 구조와 같은 모양으로 쓴다. 화면 크기에 맞춰 배치만 바꾼다.

| | PC | 태블릿 (넓은 화면) | 휴대폰 (좁은 화면) |
|---|---|---|---|
| 목록 | 사이드바 | 사이드바 (접기·폭 조절) | 왼쪽 서랍 (☰ 또는 왼쪽 끝에서 밀기) |
| 열린 것 | 탭 줄 | 탭 줄 | 탭 줄 (가로 스크롤) |
| 내용 | 터미널·채팅 | 같음, 가로 방향이면 두 개 나란히 | 하나 |
| 상태 | 상태 줄 | 상태 줄 | 얇은 상태 줄 (키보드가 열리면 숨김) |

아래 탭 4개는 없앤다. 그 자리는 서랍의 구역(연결 목록·로컬 작업·PC 탭)과 제목줄의 `MCP 활동` 버튼이 맡는다.

## 3. 단계

### 1단계: 열린 항목을 탭으로 (뼈대)

- 화면이 "지금 보는 하나" 대신 열린 항목 목록을 갖는다: 원격 셸(이 기기에서 연 SSH), PC 탭 이어 보기, 에이전트 채팅. 탭을 바꿔도 닫지 않는다. 셸은 열린 동안 유지하고, PC 탭·채팅은 보이지 않는 동안 구독을 쉬었다가 돌아오면 다시 붙는다 (전송량·서버 상한을 지키려고).
- 탭 줄은 PC 와 같은 모양(활성 탭 밑줄, 닫기 ×, 종류 아이콘, 에이전트는 상태 점)이고 넘치면 가로 스크롤.
- 휴대폰: 아래 탭을 없애고 왼쪽 서랍에 목록을 둔다. 항목을 고르면 서랍이 닫히고 탭이 열린다.
- 상태 줄: 연결 상태, 열린 셸 수, MCP 대기 건수, 작업 중 에이전트 수.
- 마지막 화면 복원(`rememberView`)은 열린 탭 목록과 앞 탭으로 넓힌다 (셸은 다시 열지 않고 목록만).

### 2단계: PC 와 같은 모양

- 사이드바·서랍: PC 세션 트리 모양(폴더 색 선, 상태 점, 열린 탭 수 배지)과 로컬 작업 트리 모양(에이전트 칩, 작업 중 테두리 빛 `agent-work-trace.css`).
- 채팅: PC 채팅과 같은 말풍선·시각·도구 블록 접기·질문별 토큰 줄·확인 카드 배치. 기능은 지금 휴대폰이 허용하는 범위 그대로다 (슬래시 명령·첨부는 여전히 받지 않음).
- 터미널: 테마의 ANSI 16색과 고정폭 글꼴을 PC 에서 받는다 (`remoteThemeOf` 가 검사한 변수만, 지금 규칙 유지). 마지막 테마를 `localStorage` 에 두어 로그인 화면이 깜빡이지 않게.

### 3단계: 태블릿다운 것과 터치

- 사이드바 접기(PC 의 46px 띠)와 폭 조절, 가로 태블릿에서 두 탭 나란히 보기(화면 나누기, 2개까지).
- 하드웨어 키보드: `Ctrl+Tab`·`Ctrl+숫자` 탭 이동, `Ctrl+W` 탭 닫기 (터미널 입력과 겹치지 않는 범위만).
- 길게 누르기 메뉴: 터미널(복사·붙여넣기·모두 선택), 탭(닫기·오른쪽 탭 닫기).
- 디자인 리뷰의 휴대폰 항목 T5·T14: 터치 영역 44px(`pointer: coarse`), safe-area, OTP 자동 채움, 확대 막지 않기.

## 4. 바꾸면 안 되는 것 (보안·부담)

- 프로토콜과 서버 규칙은 그대로다: 기기 인증, Tailscale 주소, `tabs`·`agents` 설정이 꺼져 있으면 숨김, 빠른 연결 탭은 보기만, 채팅 보내기 규칙(`chatSend`, `/`·`!` 거부, 지속 권한 거부, 0.8초 대기), 기록에 원문 없음.
- 동시에 여러 개를 붙이므로 서버에 기기당 PC 탭 이어 보기 상한을 둔다 (6개 제안, 셸과 같은 수). 보이지 않는 탭의 구독을 쉬게 하는 것은 화면의 일이고, 상한과 전송 밀림 차단(`TAB_BACKLOG_BYTES`, `MAX_BACKLOG_BYTES`)은 서버가 지킨다.
- 휴대폰 화면(`web/`)은 빌드 없는 일반 스크립트로 둔다. 데스크톱 CSS 는 지금처럼 빌드가 복사한 파일만 쓴다.

## 5. 범위 밖

- 휴대폰에서 파일 편집, SFTP, DB 탭, 로컬 셸 직접 입력 (보안 규칙상 만들지 않는다).
- PC 의 칸 나누기(한 탭 안 분할)를 휴대폰에서 조작하는 것. PC 탭을 이어 볼 때는 주 터미널만 (지금과 같음).

## 6. 담당과 순서

- 앱 설치 PWA·기기 등록 링크·PC 브라우저 요소 선택을 구현하고 검증한 작업 트리에서 1단계를 진행했다. 2026-11-25 PL이 기준 커밋 승인과 별개로 작업을 진행하도록 결정했다.
- 1단계는 `app.js`·`index.html`·`app.css` 를 크게 고치므로 한 에이전트가 맡는다. 2단계의 채팅(`agents.js`·`agents.css`)과 사이드바·터미널 테마(`sessions.js`·`controller.js`)는 1단계가 탭 구조를 정한 뒤 두 에이전트가 나눠 맡는다. 3단계는 그 뒤.
- 단계마다: 실패 테스트 먼저(`app.test.js`, `server.test.js`), 390px 휴대폰·1024×768 태블릿 세로·가로 캡처, PL 검토 뒤 다음 단계.
