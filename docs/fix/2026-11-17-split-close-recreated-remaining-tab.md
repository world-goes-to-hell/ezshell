# 분할 패인의 탭을 모두 닫으면 남은 탭의 셸이 다시 연결되던 문제

날짜: 2026-11-17

## 증상
화면을 좌우 패인으로 나눈 상태에서 한쪽 패인의 탭을 모두 닫으면, 남은 패인의 탭에서 탭 안에 분할해 둔 셸이 끊겼다가 새로 연결됐다. 그 셸에서 하던 작업(실행 중인 명령, 화면 내용)이 사라졌다.

## 원인
`App.tsx` 는 단일 화면과 분할 화면을 서로 다른 React 트리로 그렸다 (분할: `split-view-container > split-pane > ...`, 단일: `terminal-wrapper` 목록). 그래서 분할이 풀리거나 생길 때마다 모든 탭의 `TerminalPanel` 이 언마운트됐다가 다시 마운트됐다.
- 탭의 주 셸은 SSH 채널이 main 에 남아 있고 화면은 스냅숏으로 복원해 왔다.
- 탭 안 분할 셸(`SplitTerminal`)은 언마운트될 때 자기 채널을 닫는다(`sshSplitClose`). 다시 마운트되면 새 셸을 연다. 이것이 "끊겼다가 다시 연결" 이다.
- 오늘 패인의 유일한 탭에도 닫기 버튼을 보이게 하면서 이 경로를 누르기 쉬워졌다 (그 전에도 우클릭 메뉴·Ctrl+W·탭 끌기로 같은 일이 일어났다).

## 수정
탭의 내용을 배치와 무관한 한 자리에서 한 번만 그리고, 배치는 그 내용이 담긴 DOM 노드를 어디에 붙일지만 정한다.
- `lib/tabHosts.ts`: 탭마다 DOM 노드 하나(`.tab-host`, `display: contents`). 탭이 없어지면 지운다.
- `App.tsx`: 모든 탭의 내용을 `createPortal(..., tabHost(id), id)` 로 한 곳에서 그린다. 그 자리는 단일/분할 조건문 밖이라 배치가 바뀌어도 언마운트되지 않는다.
- `Terminal/TabSlot.tsx`: 예전에 내용을 직접 그리던 세 자리(주 패인, 보조 패인, 단일 화면)는 이제 `TabSlot` 이고, 자기 탭의 노드를 자기 안으로 옮겨 붙인다.
- 패인별로 달랐던 인자(활성 여부, 포커스·닫기 처리)는 그리는 곳에서 `paneOfTab` 으로 정한다.

## 바꾸면 안 되는 것
- 탭 내용을 `TabSlot` 자리에서 직접 그리지 말 것. 배치가 바뀔 때 다시 언마운트된다.
- `TabSlot` 은 언마운트될 때 노드를 떼지 않는다. 떼면 다음 자리가 붙이기 전까지 내용이 문서 밖에 있게 된다.
- 내용에서 올라오는 React 이벤트는 DOM 부모(`TabSlot`, 패인)가 아니라 그린 자리(App 의 그 위치)로 올라간다. 패인 감싸개에 클릭 처리기를 달아도 탭 내용의 클릭은 받지 못한다.

## 확인
- 개발 서버 화면에서 실제 동작으로 확인: 탭 2개 → 분할 → 보조 패인의 유일한 탭을 X 로 닫기. 남은 탭의 터미널 요소에 달아 둔 표식이 분할 전·분할 후·분할 해제 후 모두 그대로였다 (다시 만들어졌다면 표식이 없다). 닫은 탭의 노드는 지워졌다.
- typecheck, 전체 테스트 통과.
- 실제 SSH 탭의 탭 안 분할 셸로는 확인하지 못했다 (같은 `TerminalPanel` 이 유지되므로 그 안의 `SplitTerminal` 도 유지된다는 추론).

## 후속 수정 (같은 날): 탭 끌어 놓기로 분할이 안 되던 문제
위 수정 뒤, 탭을 터미널 영역으로 끌어 놓아 분할하는 동작이 잘 되지 않았다 (사용자 보고).

원인: 끌어 놓기 처리기(`onDragOver`, `onDrop`)는 `.terminal-area` 에 있다. 탭 내용을 포털로 그리면서 그 자리를 `.terminal-area` **밖**(SFTP 패널 위)에 두었기 때문에, 터미널 내용 위에서 일어난 끌기 이벤트가 `.terminal-area` 의 처리기로 올라가지 않았다. React 이벤트는 DOM 이 아니라 React 트리를 따라 올라간다. 같은 이유로 분할 패인의 `onMouseDown`(누른 패인에 포커스)도 터미널 내용의 클릭을 받지 못했다.

수정:
- 포털을 그리는 자리를 `.terminal-area` **안**(맨 끝)으로 옮겼다. 이 자리도 단일/분할 조건문 밖이라 탭이 다시 만들어지지 않는 것은 그대로다.
- 포털 내용의 맨 바깥에 `display: contents` 감싸개(`.tab-host-content`)를 두고, 분할 화면이면 `onMouseDown` 으로 그 탭이 속한 패인에 포커스를 준다.

확인 (개발 서버 화면): 첫 탭을 끌기 시작 → 놓기 영역 4개 표시 → 터미널 내용 위 오른쪽 가장자리에서 dragover → 오른쪽 놓기 영역 활성 → drop → 좌우 분할. 탭이 다시 만들어지지 않는 검증도 다시 통과.

바꾸면 안 되는 것에 더함: 포털을 그리는 자리는 `.terminal-area` 안이어야 한다. 탭 내용에서 올라오는 이벤트를 받아야 하는 처리기는 그 React 조상에 있어야 한다.
