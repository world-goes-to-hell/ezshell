# 앱이 켜져 있는 동안 새 버전이 배포되어도 알려 주지 않음

- 날짜: 2026-10-27

## 증상
앱을 켜 둔 채로 새 버전이 배포되면 "새 버전 사용 가능" 알림이 뜨지 않았다. 앱을 다시 켜야 알 수 있었다.

## 원인
1. `setupAutoUpdater` 가 앱 시작 3초 뒤 한 번만 `checkForUpdates()` 를 불렀다. 그 뒤로는 확인하지 않았다.
2. 알림을 X 로 닫으면 `dismissed: true` 가 앱을 끌 때까지 남았다. 확인을 더 했더라도 더 새 버전이 보이지 않을 구조였다.
   반대로 `setInfo` 가 부를 때마다 `dismissed` 를 false 로 되돌려, 같은 버전을 다시 찾으면 닫은 알림이 또 떴다 (주기 확인을 넣으면 30분마다 다시 뜬다).

## 수정
- `src/updateChecker.js` 의 `createUpdateChecker`: 시작 3초 뒤, 30분마다, 그리고 창에 다시 포커스가 왔을 때(마지막 확인에서 10분 이상 지났으면) 확인한다. 다운로드 중이거나 받은 뒤에는 확인하지 않는다.
- 이런 자동 확인은 조용히 한다: "확인 중", "최신 버전", 네트워크 오류는 화면에 보내지 않고, 새 버전을 찾았을 때만 알린다 (`isQuiet()`). 바닥줄의 버전을 눌러 하는 수동 확인은 지금처럼 모두 보인다.
- 알림 닫기는 상태와 버전 단위다 (`updateStore` 의 `dismissedKey`, `lib/updateCheck.ts` 의 `updateNoticeKey`/`isUpdateNoticeVisible`). 같은 버전을 다시 찾아도 다시 뜨지 않고, 더 새 버전이나 "다운로드 완료" 는 다시 뜬다. 수동 확인은 닫은 기록을 지운다.
- `src/updateChecker.js` 는 `electron.vite.config.ts` 의 `MAIN_RUNTIME_MODULES` 에 넣어야 빌드에 복사된다.

## 왜 이렇게 했나
배포가 하루에도 여러 번 있어 시작 때 한 번으로는 부족하다. GitHub 의 `latest.yml` 한 파일을 받는 가벼운 확인이라 30분 간격은 부담이 없다. 오류를 매번 보여 주면 오프라인일 때 30분마다 오류가 뜨므로 자동 확인은 결과가 있을 때만 알린다.
