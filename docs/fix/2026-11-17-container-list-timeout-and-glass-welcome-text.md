# 컨테이너 목록이 5초 제한에 걸리던 문제, Glass 시작 화면의 글자가 안 보이던 문제

## 1. 컨테이너 패널: "도커가 5초 안에 응답하지 않았습니다"

### 증상
컨테이너가 20개쯤 있는 서버에서 패널이 항상 시간 초과로 끝났다. 같은 터미널에서 `docker ps` 는 바로 답했다.

### 원인
목록 명령이 `docker ps --format '{{json .}}'` 였다. 이 템플릿은 모든 필드를 읽고 그중에 `.Size` 가 있어서,
도커가 `docker ps -s` 처럼 컨테이너마다 디스크 사용량을 잰다 (출력에 `"Size":"28.7kB (virtual 551MB)"` 가
들어 있는 것으로 확인). 컨테이너가 많거나 큰 서버에서는 이 계산이 `timeout 5` 를 넘는다.

### 수정
`src/containers/parse.js` 의 `LIST_FORMAT`: 패널이 쓰는 필드(ID, Names, Image, Status, Ports)만 필드별
`{{json .필드}}` 로 받아 같은 JSON 줄을 만든다. 읽는 쪽(`readContainerLine`)은 그대로다.
`.State` 는 뺐다: 도커 20.10 미만에서는 템플릿 전체가 실패하고, 창은 이미 `Status` 의 "Up ..." 으로
실행 여부를 판단한다 (`lib/containers.ts`).

바꾸면 안 되는 것: 목록 형식에 `{{json .}}` 이나 `.Size` 를 다시 넣지 말 것.

### 확인
이 PC 의 도커(29.5.3)에서 새 형식이 올바른 JSON 줄을 내는 것, 컨테이너 테스트 25개 통과.
문제가 난 서버에서의 확인은 사용자 확인 대기.

## 2. Glass: 시작 화면의 글자가 창 뒤 배경에 묻힘

### 원인
`glass.css` 가 `.welcome-screen` 을 투명하게 두어, 시작 화면의 글자가 창 뒤(아크릴로 흐려진 바탕 화면) 위에
바로 놓였다. 어두운 테마의 밝은 회색 글자가 밝은 바탕 화면 위에서 읽히지 않았다.

### 수정
Glass 에서 시작 화면 글자 뒤에 거의 불투명한 카드(`.welcome-screen::before`, `--glass-content`)를 둔다.
나머지 영역은 그대로 비친다.
