# SFTP 디렉토리 동기화 강조선이 컬럼 머리글 줄에서만 끊겨 보이던 문제

## 증상
- 동기화를 켜면 로컬/원격 목록 사이 구분선이 강조색이 되는데, 컬럼 머리글 줄 높이에서만 선이 사라졌다 (사용자 화면: ayu-mirage 테마).

## 원인
- 구분선 `.sftp-divider` 는 `position: relative; z-index: 2`, 목록 머리글 `.file-list-header` 는 `position: sticky; z-index: 6`.
  `.sftp-content`, `.sftp-pane`, `.file-list` 가 모두 stacking context 를 만들지 않아 둘이 같은 순서 안에서 비교된다.
- CSS 상으로 원격 머리글은 원격 패널 안에 정확히 들어 있다 (왼쪽 끝 = 패널 왼쪽 끝 = 구분선 오른쪽 끝). 넘친 게 아니라서 `overflow: hidden` 으로 잘리지 않는다.
- UI 배율 80% 에서 이 경계가 소수점(예: 화면 px 711.61~712.41)에 걸리고, 픽셀로 맞춰질 때 구분선과 원격 머리글이 **같은 화면 픽셀 하나**를 차지한다.
  그 픽셀을 z-index 가 높은 머리글이 덮었다. 목록 행은 위치 지정이 없어 구분선 아래에 그려지므로 머리글 줄에서만 끊겼다.
- 측정: 테스트 SFTP 서버 + CDP 로 getBoundingClientRect / elementsFromPoint / 1:1 픽셀 캡처. 창 폭 1100·1500 에서도 같았다.

## 수정
- `.sftp-divider` z-index 2 → 8: 머리글(6)·로딩 오버레이(7) 위, 이름 바꾸기 오류 말풍선(20) 아래.
- 실험한 다른 방법(원격 머리글 1px 띄우기, 머리글 z-index 제거)도 효과는 있었지만, 머리글/목록 동작을 건드리지 않고 배율·테마·창 폭과 무관한 이 방법을 택했다.

## 검증

- 실제 앱 E2E (1:1 화면 픽셀 판독)
  - ayu-mirage / 80% / 동기화 켬: 구분선 열이 머리글 줄·머리글 아래·위쪽 모두 #ffcc66, 1px (기본, 1100, 1500 폭). 600px 스크롤 상태도 동일
  - minimal-dark / minimal-light 도 머리글 줄까지 강조색으로 이어짐
  - 동기화 끔(테두리색)도 머리글 줄에서 이어짐 — 같은 원인으로 끊겨 있었던 것으로 보임
  - 회귀: 동기화 배지 클릭 해제, 로딩 오버레이, 이름 바꾸기 오류 말풍선(구분선 위), 머리글 고정 모두 정상
  - 비교 이미지: scratchpad `compare-sync.png`
- 참고(무관, 기존): 로컬 목록에 스크롤바가 있으면 스크롤바 막대(`--border` 색)가 동기화 끔 구분선 옆에 붙어 약 7px 띠처럼 보인다.
