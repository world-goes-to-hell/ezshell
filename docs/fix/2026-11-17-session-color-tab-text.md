# 세션 색으로 채운 탭의 글자가 검게 보이던 문제

날짜: 2026-11-17

## 증상
분할 패인에서 포커스가 있는 패인의 활성 탭은 세션 색으로 채워진다. 파랑(`#3b82f6`) 세션의 탭이 파란 바탕에 검은 글자로 보여서, 강조 상태의 글자색이 적용되지 않은 것처럼 보였다.

## 원인
글자색은 `lib/colorContrast.ts` 의 `readableTextColor` 가 정한다. 이 함수는 흰색과 검정 중 대비가 더 큰 쪽을 골랐다. 파랑 `#3b82f6` 은 흰 글자 3.7:1, 검은 글자 5.6:1 이라 검정이 선택됐다. 계산은 맞지만, 채도가 높은 중간 밝기의 색(파랑·빨강·보라·분홍)에 검은 글자가 얹히면 강조되지 않은 것으로 읽힌다.

## 수정
흰 글자의 대비가 3:1 이상이면 흰색을 쓰고, 그보다 낮을 때만 검정을 쓴다 (3:1 은 WCAG 가 UI 요소와 굵은 글자에 요구하는 최소값).

| 세션 색 | 이전 | 이후 |
|---|---|---|
| 빨강, 파랑, 보라, 분홍 | 검정 | 흰색 |
| 주황, 노랑, 초록, 청록 | 검정 | 검정 (흰 글자가 3:1 미만) |

감수한 점: 흰 글자가 3:1~4.5:1 구간인 색에서는 일반 본문 기준(4.5:1)보다 대비가 낮다. 탭 이름은 짧은 표지이고 사용자가 고른 색이 바탕이라 받아들였다.

## 확인
`colorContrast.test.ts` 3개 통과, typecheck 통과. 실제 화면은 사용자 확인 필요.

## 추가: 채워진 탭의 아이콘
같은 탭의 DB·로컬 아이콘(`.tab-db-icon` 은 강조색, `.tab-local-icon` 은 흐린 글자색)은 자기 색을 갖고 있어서, 강조색으로 채워진 활성 탭 위에서는 바탕에 묻혀 보이지 않았다. 포커스가 있는 패인의 활성 탭에서는 탭의 글자색을 따르게 했다 (`globals.css`, `color: inherit`). 본 탭 줄의 활성 탭은 채우지 않으므로 해당하지 않는다.
