# 커스텀 테마 만들기 창이 잘려 보이던 문제

## 증상
설정 > 테마 > "커스텀 테마 만들기" 창의 아래쪽과 오른쪽 미리보기가 잘려 보였다.

## 원인
1. 편집 창의 바탕(`.theme-editor-overlay`)은 `position: fixed` 인데 설정 대화상자 안에 그려졌다. 설정 대화상자는 가운데 정렬·애니메이션에 transform 을 쓰고, transform 이 걸린 조상 안에서는 fixed 가 창이 아니라 그 조상 상자를 기준으로 놓인다. 그래서 편집 창이 설정 대화상자 크기(약 690x600)에 맞춰 잘렸다.
2. 내용 격자가 `1fr minmax(300px, 400px)` 였다. `1fr` 은 내용 너비보다 줄지 않아서 좁을 때 미리보기 칸을 상자 밖으로 밀었다.

## 수정
- `ThemeEditor.tsx`: 편집 창을 자체 Radix Dialog 로 페이지에 그린다. `createPortal` 만 쓰지 않은 이유: 설정 대화상자가 포커스와 포인터 입력을 가두기 때문에 밖에 그린 입력칸을 쓸 수 없다. 중첩 Dialog 는 이를 넘겨받고, Esc 는 편집 창만 닫는다.
- `ThemeEditor.css`: 격자를 `minmax(0, 1fr) ...` 로, 가로 넘침은 숨김으로.

## 확인
실제 앱(1200x800)에서 바탕이 창 전체를 덮고, 편집 창과 미리보기가 창 안에 들어오며, 이름 입력·클릭·Esc(설정은 유지)가 동작한다.
