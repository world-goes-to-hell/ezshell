# 말풍선 채팅 테마에서 답변 버튼이 답변 폭을 차지하던 문제 (2026-11-25)

## 증상

카톡 모드 같은 말풍선 테마에서 답변 오른쪽에 약 200px 이 늘 비어 있었다 (사용자 보고, 캡처 첨부).

## 원인

`AgentChatThemes.css` 가 답변 버튼(`답장`·`인계`·`띄워 두기`)을 말풍선과 나란한 flex 형제(`position: static`)로 두었다.
버튼은 포인터를 올릴 때만 보이지만 자리는 늘 차지해서, 말풍선의 최대 폭(95%)이 버튼 폭만큼 줄었다.

## 수정

- 버튼은 말풍선 오른쪽 위에 띄운다 (`position: absolute`, `bottom: 100%`). 답변 상자는 말풍선 폭에 맞추되(`fit-content`) 최소 232px 이라, 짧은 답변에서도 버튼이 화면 왼쪽 밖으로 나가지 않는다. 최대 폭(`min(95%, 88ch)`)은 상자에 둔다.
- 말풍선과 버튼 사이 3px 는 버튼 상자의 안쪽 여백이다. 빈 틈으로 두면 포인터가 위로 올라가는 동안 답변의 hover 가 끝나 버튼을 누를 수 없었다 (화면 시험에서 확인). 버튼 상자는 답변에 포인터나 키보드 포커스가 있을 때만 포인터를 받는다 (평소에는 윗줄을 가리지 않음).
- 좁은 칸에서 버튼을 말풍선 위 줄로 내리던 컨테이너 쿼리는 없앴다 (이제 늘 위에 뜬다).

## 시험

`local-agent-chat-timestamps`: 버튼이 말풍선 위에 있는지(`bottom <= 말풍선 top - 3`), 좁은 칸에서도 떠 있는지 본다. 버튼 수는 `인계` 가 더해져 2개 이상으로 바꿨다.
