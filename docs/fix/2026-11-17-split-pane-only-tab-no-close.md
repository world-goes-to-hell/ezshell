# 분할 패인에 탭이 하나뿐이면 닫기 버튼이 없던 문제

날짜: 2026-11-17

## 증상
화면을 좌우 패인으로 나눈 상태에서, 탭이 하나만 있는 패인의 탭에는 X 버튼이 없었다. 탭을 닫으려면 우클릭 메뉴나 Ctrl+W 를 써야 했다.

## 원인
`SplitPaneTabBar.tsx` 가 닫기 버튼을 `terminalIds.length > 1` 일 때만 그렸다 (첫 커밋부터 있던 조건). 패인이 비는 경우를 피하려던 것으로 보이지만, 스토어의 `removeTerminalFromPane` 은 패인이 비면 분할을 풀고 남은 패인을 단일 화면으로 돌린다. 우클릭 메뉴와 Ctrl+W 도 이미 같은 경로로 마지막 탭을 닫고 있었다.

## 수정
- 조건을 없애고 닫기 버튼을 항상 그린다. 패인의 마지막 탭을 닫으면 분할이 풀린다.
- 닫기 버튼의 hover 배경이 `rgba(255, 255, 255, 0.2)` 로 고정돼 밝은 테마의 활성 탭에서는 보이지 않았다. 탭 글자색(`currentColor`)에서 만들도록 바꿨다.

## 확인
typecheck 통과. 실제 앱에서 오른쪽 패인의 탭 하나를 X 로 닫아 분할이 풀리는지 확인 필요.
