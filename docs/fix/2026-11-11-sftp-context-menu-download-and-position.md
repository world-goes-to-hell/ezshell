# SFTP 우클릭 메뉴: 다운로드가 "파일을 먼저 선택하세요" 로 끝남, 메뉴가 포인터보다 한참 위에 뜸

## 증상
1. SFTP 목록에서 파일을 우클릭하고 `다운로드` 를 누르면 "다운로드할 파일 선택" 알림만 뜨고 받아지지 않는다. `삭제`, `업로드` 도 같은 경로라 같은 문제가 있다.
2. 창 아래쪽에서 우클릭하면 메뉴가 포인터에서 멀리 떨어진 위쪽에 뜬다.

둘 다 2.11.1 에서 메뉴를 `document.body` 에 그리도록 바꾼 뒤에 생겼다.

## 원인
1. 파일 목록(`FileList.tsx` 의 `handleBlur`)은 포커스를 잃으면 선택을 지운다. 메뉴가 목록 안에 있을 때는 메뉴 항목을 눌러도 포커스가 목록에 남았다. 메뉴가 목록 밖(`document.body`)으로 나간 뒤에는 항목을 누르는 순간 목록이 포커스를 잃고, 선택이 지워진 다음에 `onDownload` 가 빈 선택을 읽는다.
2. `openContextMenu` 가 메뉴 높이를 어림해서 클릭 좌표를 먼저 위로 옮기고, 메뉴(`fitMenu`)가 실제 높이로 한 번 더 판단해 옮겨진 좌표에서 위로 열었다. 보정이 두 번 적용됐다.

## 수정
1. 메뉴의 `mousedown` 기본 동작을 막아 포커스가 목록에 남게 했다 (`FileListContextMenu.tsx`). 메뉴에는 포커스를 받는 요소가 없어서 다른 영향은 없다.
2. `openContextMenu` 는 클릭 좌표를 그대로 넘기고, 위치는 `fitMenu` 만 정한다. 쓰지 않게 된 어림값 상수(`CONTEXT_MENU_ITEM_HEIGHT`, `CONTEXT_MENU_WIDTH`, `CONTEXT_MENU_EDGE_GAP`)를 지웠다.

## 바꾸면 안 되는 것
- 메뉴의 `onMouseDown` `preventDefault` 를 지우지 말 것. 지우면 선택에 작용하는 메뉴 항목이 모두 빈 선택으로 실행된다.
- 메뉴 위치를 부르는 쪽에서 미리 보정하지 말 것.
