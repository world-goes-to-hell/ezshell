# Terminal Right-Click Menu

[공통 작업 규칙과 기능별 목록](../../CLAUDE.md)

터미널(탭의 주 터미널과 분할 셸)에서 우클릭하면 메뉴가 뜬다 (`Terminal/useTerminalContextMenu.tsx`, `TerminalContextMenu.tsx`). 맨 위에 복사·붙여넣기·모두 선택, 그 아래 `분할`(좌우 분할·상하 분할·칸 크기 균등화·이 칸 닫기, 우클릭한 칸에 적용: 감싸개의 `data-pane`), `편의`(이름 찾기, 내용 찾기, 화면에서 찾기, 화면 지우기, 전체 출력 복사, 출력을 파일로 저장, 파일 탐색기), `스니펫`(저장한 스니펫 15개까지를 입력줄에 넣음, 실행하지 않음. 그 아래 `스니펫 추가…`(선택한 글자가 있으면 그 글자가 명령으로 들어간 채 열림)와 `스니펫 관리…`), `세션`(탭 복제, 로그 저장, SFTP, 연결 종료) 하위 메뉴가 있다. 포인터 위치에 빈 기준점을 두고 여는 Radix DropdownMenu 이다 (modal 아님: 다른 곳을 우클릭하면 메뉴가 옮겨 간다).
- 바꾸면 안 되는 것: 우클릭은 앱의 메뉴 몫이라 마우스 보고로 셸에 보내지 않는다 (`lib/rightClickReports.ts`, 로컬 터미널·SSH 주 터미널·분할 칸의 `onData`). 마우스 보고를 켠 Codex 는 오른쪽 버튼 보고를 받으면 클립보드를 입력칸에 붙여 넣어, 메뉴를 여는 우클릭이 에이전트에 글을 넣었다 (`docs/fix/2026-11-20-right-click-pasted-into-agent.md`). 메뉴가 없는 분리 터미널 창은 우클릭을 그대로 넘긴다.
- 복사·붙여넣기·화면 지우기·찾기는 우클릭한 그 터미널에 적용한다. 터미널마다 그려지는 요소를 `lib/terminalPanes.ts` 에 등록해 두고 `terminalPaneAt` 으로 찾는다. 터미널 영역 위에 그려지는 패널(포트 포워딩 등)에서는 메뉴를 띄우지 않는다.
- 이름 찾기·내용 찾기(`TerminalFindDialog.tsx`, 명령 생성은 `lib/terminalFind.ts`)는 `find` / `grep -rnIF` 명령을 만들어 `terminal.paste` 로 입력줄에 넣는다. 찾을 위치는 현재 폴더(`.`), 루트(`/`, `/proc` `/sys` `/dev` 제외), 폴더 지정 중에서 고르고 `localStorage` 의 `terminalFindPrefs` 에 기억한다.
  - 바꾸면 안 되는 것: 앱이 명령을 실행하지 않는다 (줄바꿈을 붙이지 않고, 사용자가 Enter 를 누른다). 큰 폴더 검색은 운영 서버 디스크를 오래 읽는다. 입력값은 작은따옴표로 감싸고, 줄바꿈·제어 문자는 앞뒤 공백을 자르기 전에 거부한다 (줄바꿈이 들어가면 입력되는 순간 앞부분이 실행된다).
- 복사·붙여넣기·모두 선택과 화면 지우기·출력 복사·출력 저장은 `terminalMenuCommon.tsx` 에 있고 로컬 터미널 탭도 같은 항목을 쓴다. 출력 글자는 `lib/terminalText.ts` 가 버퍼에서 읽는다 (너비에서 접힌 줄은 한 줄로 잇는다). 찾기 창은 터미널에서 선택한 한 줄 글자를 찾을 말로 채운다.
- `편의` 의 `SFTP 를 현재 폴더로`(`lib/sftpSync.ts`)는 탭의 SFTP 패널을 터미널이 있는 폴더로 연다 (닫혀 있으면 그 경로로 열고, 열려 있으면 `ezshell:sftp-goto` 이벤트로 이동). 터미널의 폴더는 프롬프트·창 제목에서 읽은 `TerminalInfo.currentPath` 이고, `~` 는 SFTP `realpath('.')`(`sftp-realpath`)로 바꾼다. 서버에 명령을 보내 경로를 묻지 않는다 (셸에 글자가 찍히고, vim 같은 프로그램 안에서는 입력이 된다). 그래서 프롬프트에 전체 경로가 보이지 않는 셸에서는 알 수 없다고 안내한다.
- 화면에 찍힌 파일·폴더 이름을 우클릭하면 메뉴 맨 위에 그 이름과 SFTP 목록에서 하던 동작이 먼저 나온다 (파일: 미리보기·편집·실시간 보기·다운로드·SFTP 에서 위치 열기·경로 복사, 폴더: SFTP 에서 열기·`cd` 입력·경로 복사). 이름은 포인터 아래 낱말(한 줄 선택이 있으면 그 선택)이고 `lib/terminalTarget.ts` 가 읽는다. 경로는 탭의 `currentPath`(프롬프트에서 읽은 폴더) 기준이며 분할 셸은 폴더를 모르므로 절대 경로만 찾는다. 서버에는 SFTP `stat` 하나만 보낸다 (`sftp-stat`, 60초 기억. 로그인 폴더는 세션마다 한 번만 묻는다). 전체 화면 프로그램(vim 등)에서는 찾지 않는다. 구현: `terminalTargetMenu.tsx`.
  - 바꾸면 안 되는 것: 메뉴는 파일 정보를 받은 뒤에 한 번에 연다 (최대 0.4초 기다림). 연 뒤에 항목을 끼워 넣으면 포인터 아래 항목이 밀려 다른 것을 누르게 된다.
- 파일·폴더 이름에 포인터를 올리면 밑줄이 생기고 안내가 뜬다 (`terminalFileLinks.ts`, xterm 링크 제공자). `Ctrl+클릭` 은 편집(큰 파일은 미리보기)·폴더는 SFTP 에서 열기, 그냥 클릭은 아무것도 하지 않는다 (포커스를 주려는 클릭에 창이 열리면 안 된다). 바꾸면 안 되는 것: 포인터가 0.06초 머문 줄의 낱말만(줄당 12개까지) 서버에 묻고, 이미 답을 아는 줄은 기다리지 않고 바로 밑줄을 긋는다. 화면 전체를 미리 조회하지 않는다 (운영 서버에 요청이 쏟아진다).
- 파일 영역(`terminalFileZone.ts`, 계산은 `lib/terminalFileZone.ts`): 탭의 주 터미널에서 폴더(`currentPath`)가 마지막으로 바뀐 프롬프트 줄부터 지금 커서 줄 위까지를 테두리로 두르고 오른쪽 위에 그 폴더를 적는다. 상대 이름은 현재 영역이나 원래 절대 경로가 확인된 이전 파일 목록에서 밑줄·우클릭 메뉴를 낸다. 영역은 명령 줄마다 나뉘고(프롬프트에서 Enter 를 누른 줄에 표식, `lib/terminalFileZone.ts` 의 `listingBase`), 명령마다 이름의 기준 폴더가 다르다: `ls ../`·`ls /var/log` 처럼 폴더 하나를 준 `ls` 는 그 폴더(`../test.txt` 로 찾고 테두리도 그 폴더 이름), `ls a b`·`ls -R`·`tree`·`;`/`&&` 로 이은 명령은 알 수 없어 테두리·링크 없음, 그 밖은 지금 폴더. 테두리는 파일 목록을 찍는 `ls` 계열 명령(`isListing`)의 출력에만 그린다 (`docker ps` 같은 출력에 두르면 없는 파일이 있는 것처럼 보인다). 그 밖의 출력(`cat`, `grep -rn`, 로그)의 이름은 테두리 없이 지금 폴더 기준으로 밑줄·메뉴를 낸다. `/`·`~` 로 시작하는 이름은 어디서나. `편의` 의 `파일 영역 테두리 끄기/켜기` 는 테두리만 감추고(`localStorage` 의 `terminalFileZone`) 규칙은 그대로다. 폴더가 바뀌면 기존 영역의 현재 경로 조회를 즉시 닫는다. 다음 프롬프트까지의 출력 범위와 원래 절대 경로가 확인된 `ls` 계열 목록만 두 엑스텀 표식으로 보관한다. 인수가 있으면 SFTP 로 단일 디렉터리인지 확인한다. 새 시작 표식은 빈 `terminal.write('', 콜백)` 의 콜백에서 커서 줄에 둔다. xterm 은 쓰기를 순서대로 처리하므로 그때는 새 폴더를 알린 출력까지 화면에 있다 (`onWriteParsed` 에 걸면 아직 처리되지 않은 앞 조각 직후에 불려 `cd` 명령 줄에 박혔다). 프롬프트 줄만 있는 영역(`cd` 직후, 빈 Enter)은 그리지 않는다 (`zoneHasOutput`). xterm 은 표식 줄이 화면 밖이면 꾸밈을 숨기므로 보이는 부분만, 그 첫 줄에 임시 표식을 두고 그린다. 스크롤 막대 이동은 `onScroll` 을 내지 않아 `onRender` 로도 다시 그린다. 설계: `docs/plan/2026-11-13-terminal-file-zone.md`.
- 하위 메뉴는 종류별로 구분선(`MENU_SEPARATOR`)을 둔다: `편의` 는 찾기 / 출력 / 파일, `세션` 은 `연결 종료` 를 따로. 항목을 더할 때 맞는 묶음에 넣는다.
- 스니펫 추가 창(`SnippetModal`)은 메뉴 항목을 누른 동작이 끝난 뒤에(`setTimeout`) 연다. 이 창은 바깥을 누르면 닫히므로, 같은 클릭이 창의 배경에 닿으면 열리자마자 닫힌다.
- 탭 복제는 `ezshell:duplicate-tab` 이벤트로 `App.tsx` 에 넘긴다 (복제 로직이 App 에 있다).
- 시험할 때: 하위 메뉴는 포인터가 지나온 경로로 열림 유지를 판단한다. CDP 로 포인터를 한 번에 옮기면 하위 메뉴가 닫히므로 여러 번에 나눠 움직인다.
