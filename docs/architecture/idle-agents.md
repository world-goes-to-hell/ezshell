# Idle Agents (쉬는 에이전트의 메모리 비우기·잠재우기)

[공통 작업 규칙과 기능별 목록](../../CLAUDE.md)

로컬 셸의 Claude Code·Codex 가 쉬는 동안 메모리를 돌려받는다 (2026-11-21 사용자 요청. 이 PC 에서 Claude CLI 하나 450~900MB, MCP 서버마다 약 100MB). 설정 > MCP > 에이전트 메시지 탭의 `쉬는 에이전트의 메모리`(`Settings/AgentIdleSettings.tsx`, `localStorage` 의 `agentIdle`, `lib/agentIdlePrefs.ts`, 화면 설정 백업 목록에 있음)에서 고르고, 창이 시작할 때·바꿀 때 `agent-idle-configure` 로 main 에 보낸다 (`stores/agentSleepStore.ts` 의 `startAgentSleep`). main 은 `src/agentIdle.js`(30초마다)와 `localShell.js` 의 `sleep`/`wake`/`stayAwake`. 쉼은 상태가 `idle` 로 이어진 시간이다 (`entry.activeAt`: 상태가 idle 이 아닐 때, 사용자 입력, 깨우기 문장·채팅 보내기 때 갱신).
- 메모리 비우기(기본 10분): CLI 와 그 아래 프로세스 모두에 Windows `EmptyWorkingSet` (PowerShell 로, pid 는 정수만). 쉼이 이어지는 동안 한 번. 상태는 그대로이고 다시 일하면 페이지가 돌아온다. Windows 만.
- 잠재우기(기본 끔): 셸에 직접 입력해 띄운 에이전트(`externalAgent`)만. ezShell 이 띄운 에이전트는 셸 자체라 CLI 를 끄면 셸이 끝난다 (업데이트 뒤 다시 연 탭도 그렇다: 아직 잠재우지 못함). 채팅 보내기와 같은 `submitText` 로 `/exit`(Codex `/quit`)를 넣는다: 입력칸이 비어 있지 않으면 거기서 그만둔다. 15초 안에 안 끝나면 프로세스 트리를 끝낸다. 칸은 `AgentChat/AgentSleepCover.tsx` 로 덮이고(채팅 보기 위, `깨우기`·`터미널로 쓰기`), 잠든 동안 셸 입력은 버린다 (`write`: 깨우기 줄 앞에 글자가 붙으면 안 된다). 깨우기(칸 버튼, 그 에이전트에게 메시지가 오면 `wakeInbox`)는 셸에 `claude --resume <id>` / `codex resume <id>` 를 친다 (`resumeCommand`). 잠재우기에서 Claude 세션 id 는 OS에서 시작 시각을 확인한 세션 파일을 우선 쓰고, 파일이 확인되지 않으면 앱이 확인한 재개 id를 쓴다. 둘 다 없으면 잠재우지 않는다. Codex는 명시적 재개 UUID와 이름이 일치하는 롤아웃을 찾았을 때 잠재운다 (`main.js` 의 `sessionOf`). 끈 CLI 의 명령줄에서 권한·모델 옵션(`--dangerously-skip-permissions`, `--permission-mode`, `--model`, Codex `--yolo`·`--sandbox`·`-a`·`-m` 등, 값은 `[\w.:-]` 만)을 읽어 다시 붙인다 (`launchFlags`). 실행 중 `/model` 로 바꾼 것은 이어지지 않는다.
- 같은 id 로 돌아온다: `agentMessages.sleep` 이 에이전트를 `sleeping`(상태 `sleeping`, `resumeId`)으로 남기고, `isConnected` 가 잠든 에이전트를 연결된 것으로 쳐서 `list_agents` 에 나오고 메시지를 받는다 (받으면 `onInboxChanged` → 깨움). CLI·MCP 가 끝나도 `archiveExternal` 은 잠든 에이전트를 지우지 않는다. 다시 띄운 CLI 의 MCP 가 붙으면 `bindAgentProcess` 가 잠든 칸의 옛 id 를 다시 쓴다. 2분 안에 안 붙거나 셸이 닫히거나 `터미널로 쓰기` 면 `cancelSleep({ ended: true })` 로 끝난 에이전트가 된다. 잠든 동안 온 메시지는 깨어난 뒤 평소의 편지함 알림 문장으로 알린다.
- 바꾸면 안 되는 것 (백그라운드 명령): CLI 가 지금 셸을 돌리고 있으면 잠재우지 않는다 (`runsCommand`: Claude 의 Git Bash, Codex 의 PowerShell). 단 CLI 와 함께(60초 안에) 뜬 셸은 MCP 서버의 껍데기라 뺀다: ezShell 메시지 MCP 가 `powershell.exe`(그 밖은 `/bin/sh`)로 돌아서, 셸 자식만 보면 직접 띄운 에이전트가 늘 바쁜 것으로 나왔다. 그래서 프로세스 목록을 시작 시각과 함께 따로 읽는다 (`processList`). 거절한 것은 5분 뒤 다시 본다.
- 화면 테스트 `local-agent-sleep` (`e2e/support/agentSleepApp.js`: `EZSHELL_TEST_IDLE_MINUTE_MS` 로 1분을 1초로. 패키징된 앱은 이 값을 읽지 않는다). 가짜 에이전트는 붙여 넣은 `/exit`·`/quit` 의 Enter 로 끝나고(`<id>-exits`), 시작 인자를 `<id>-argv` 에 적는다. 종료 파일(`<id>-exit-code`)은 읽고 지운다 (같은 셸에서 다시 띄운 가짜가 바로 끝나지 않게).
