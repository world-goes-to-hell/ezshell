# 화면 테스트 명세와 도우미

[공통 작업 규칙과 기능별 목록](../../CLAUDE.md)

화면 테스트:`npm run build` 뒤 `npm run e2e` (전부) 또는 `npm run e2e -- shortcuts` (하나). `e2e/run.js` 가 명세(`e2e/specs/*.js`)마다 빌드된 앱을 새 프로필(시스템 임시 폴더)로 띄우고 CDP 로 조작한 뒤 끝낸다. 실제 앱 데이터는 건드리지 않는다. 화면 캡처는 `e2e/.out/`(커밋 안 함). 명세: 서버가 필요 없는 것(로컬 터미널 분할·탭으로 빼기 `local-split`, 단축키 `shortcuts`, 로그 강조 `log-highlight`, 분리 창 위치 `window-place`, 화면 설정 백업 `ui-settings`)과, 이름이 `ssh-` 로 시작해 실행기가 시험용 SSH 서버(`e2e/support/sshd.js`)를 띄워 주는 것(`ssh-sftp`, 칸 나누기·자리 바꾸기·탭으로 빼기 `ssh-panes`, 끊김·셸 종료·재연결 `ssh-reconnect`, 재연결 실패 `ssh-reconnect-fail`(약 90초), 분할 셸 채널 재시도 `ssh-split-retry`, 터미널·SFTP 창 분리와 병합 `ssh-detach`, 탭을 다른 탭의 칸으로 병합 `ssh-tab-merge`, 터미널에 파일 끌어 놓기 업로드 `ssh-drop-upload`, 서버 파일 창의 미리보기·편집·실시간 보기·이미지·PDF `ssh-remote-file`, 실시간 보기의 오류·기준점 이동과 목록 패널 `ssh-log-view`, 업데이트 뒤 탭 다시 열기 `ssh-restore-tabs`)과 가짜 대화 기록으로 띄우는 에이전트 기록 패널 `local-agent-history`(실행기 `e2e/support/agentHistoryApp.js`, 로컬 셸의 실행 인자를 기록하고 에이전트 CLI 대신 빈 셸을 띄운다), 창을 다시 불러온 뒤 로컬 셸을 탭으로 되살리기 `local-reload`과 프로필만 쓰는 세션 파일 암호화 `session-secrets`, 컨테이너 이름 검색 `ssh-container-search`(시험 서버가 `docker ps` 에 가짜 목록으로 답한다), 에이전트 대화 끌어 놓기 `ssh-agent-drop`(가짜 기록 시작 파일), 훅으로 받는 에이전트 상태 `local-agent-hooks`(가짜 Claude 가 실제 훅 리포터를 부른다), 사이드바 로컬 작업 트리 `local-workspace`(프로필에 작은 Git 저장소와 워크트리를 만든다), Antigravity 채팅 보기 `local-agent-chat-antigravity`(가짜 `agy` 와 상태 줄·OSC·기록 fixture, `e2e/support/antigravityChatApp.js`), 마우스 포인터 모양·효과 `pointer-themes`(세트를 고르면 `:root` 커서 변수가 blob: 그림, 효과 캔버스가 생기고 사라짐), 채팅 말풍선의 시각 표시와 답변 버튼 위치 `local-agent-chat-timestamps`, 테마별 시작 화면 `startup-theme`(프로필을 저장하고 Electron 을 따로 띄운다, `e2e/support/startupThemeApp.js`). 창의 콘솔 오류와 CSP 거부는 `driver.js` 의 `pageProblems` 로 모은다. 시험 서버의 셸은 낱말 몇 개를 안다: `exit`, `drop`(연결 끊기), `refuse`(다음 채널 요청 두 번 거부), `halt N`(N초 동안 새 연결 거부), `burst`(`/var/trace.log` 에 오류 한 건 추가). 새 명세는 공용 도우미 `e2e/support/driver.js`(CDP 연결, 포인터·키 입력, 잠금 해제, 시험 서버 접속)를 쓴다.
