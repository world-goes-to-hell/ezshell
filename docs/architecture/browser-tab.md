# Browser Tab Links and Menu (브라우저 탭의 새 창 링크·우클릭 메뉴)

[공통 작업 규칙과 기능별 목록](../../CLAUDE.md)

브라우저 탭의 페이지(`src/ipc/browserReview.js` 의 `createTab`)에서 새 창으로 여는 링크(`target="_blank"`, `window.open`, Ctrl·가운데 클릭)는 앱의 새 브라우저 탭에서 연다 (`openLink`, http(s) 만). 우클릭은 Electron 기본 메뉴다 (`src/ipc/browserContextMenu.js`: 링크·이미지·입력칸·선택·빈 곳마다 다른 항목, 맨 아래 `검사` 는 개발자 도구를 따로 띄운 창으로 열고 `inspectElement`). 페이지 안의 키는 F12·`Ctrl+Shift+I`(개발자 도구), `Alt+←/→`, `F5`·`Ctrl+R`. 바꾸면 안 되는 것: 페이지는 앱 화면 위에 그려지므로 HTML 메뉴로 바꾸면 가려진다. 새 창(`action: 'allow'`)을 허용하지 않는다 (앱의 세션·샌드박스 규칙 밖의 창이 생긴다). 2026-11-23 사용자 보고. 설명: `docs/fix/2026-11-23-browser-tab-links-context-menu.md`. 화면 테스트 `browser-review`.
- 요소 수정 요청의 받는 사람은 프로젝트를 먼저 고르고 그 프로젝트의 에이전트를 고른다 (2026-11-26 사용자 요청: 폴더 경로가 긴 에이전트 목록만으로는 어느 프로젝트인지 알기 어려웠다). main 의 `browser-review-projects` 가 에이전트를 저장소의 주 체크아웃별로 묶고 `상위 폴더 / 폴더`로 이름 붙인다 (`src/agentProjects.js`, 캡처 바로작업과 같은 규칙). 탭을 연 곳의 폴더(실행 구성 줄의 열기는 `{ folder }`, 서버 칩은 `{ shellId }` 로 main 이 그 셸의 폴더를 찾음, 작업 공간 파일은 그 루트, 탭 안에서 새 창으로 연 링크는 원래 탭의 것)를 탭마다 기억해 그 프로젝트를 먼저 고른다. 없으면 프로젝트가 하나일 때만 고르고, 고른 프로젝트에 에이전트가 하나면 그 에이전트도 고른다 (`lib/browserReviewProjects.ts`). 바꾸면 안 되는 것: 화면이 준 폴더는 화면 표시용 힌트이고 권한이 아니다. 그 폴더에서 Git 을 돌리기 전에 이 PC 의 절대 경로인지 본다 (`preferredProject`, 네트워크 경로 조회는 Windows 자격 증명을 보낼 수 있다). 보내기는 지금처럼 main 이 받는 에이전트를 다시 확인한다.
- 주소창 자동완성 (`Browser/BrowserAddressBar.tsx`, `lib/browserAddressSuggestions.ts`, 2026-11-26 사용자 요청): 방문 기록과 즐겨찾기에서 입력한 글자로 시작하는 주소(앞의 `www.` 무시), 주소의 한 부분(`.`·`/` 뒤), 주소·제목에 든 것 순으로 최근 것부터 6개를 주소창 아래에 보인다. 입력 글자로 시작하는 주소가 있으면 주소창에서 나머지를 채우고 그 부분을 선택해 둔다 (지우는 중이나 IME 조합 중에는 채우지 않는다). 화살표로 고르고 Enter·클릭으로 열며, Esc 는 입력한 글자로 되돌린다. 채운 주소나 고른 항목은 저장된 주소 그대로 연다. 목록은 페이지 위에 그려지므로 보이는 동안 페이지를 숨긴다 (`appOverlays` 의 `.browser-address-suggestions`). 바꾸면 안 되는 것: 같은 완성으로 다음 글자를 칠 때는 주소 값이 그대로라 React 가 다시 그리지 않으므로, 완성마다 횟수를 올려 선택 범위를 다시 놓는다.
- 방문 기록: 이 앱의 브라우저 탭에서 다 열린 http(s) 페이지를 기록한다 (`browserBookmarkStore.recordVisit`, 같은 주소는 하나로 맨 앞에, 제목이 오면 바꾼다, 1000개). 전에는 다른 브라우저에서 가져온 기록만 있었다. 작업 공간 파일 미리보기는 기록하지 않는다.
- 로그인 상태 유지는 기본으로 켜져 있다 (`browser-profile.json` 에 사용자가 끈 기록이 있을 때만 끈다. 2026-11-26 사용자 보고: 다시 시작하면 로그인이 풀렸다). 켜진 탭은 `persist:ezshell-browser-review` 세션을 써서 쿠키가 프로필 폴더에 남는다. 설정을 바꾸면 새 탭부터 적용된다. 계정·비밀번호 저장은 지금처럼 `로그인 정보` 창에서 한다 (페이지의 로그인 양식을 보고 저장을 제안하지는 않는다).
