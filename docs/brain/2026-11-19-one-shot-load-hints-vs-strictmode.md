# 창의 첫 load 에 한 번만 주는 값은 개발 실행(StrictMode)에서 사라질 수 있다

파일 창을 "어떻게 열지"(HEAD 와 비교, 특정 줄로) main 이 첫 `load` 답에 한 번만 싣고 지우게 만들었더니, 화면 테스트(빌드본)는 통과하는데 사용자의 개발 실행 창에서는 동작하지 않았다.

- 원인: 개발 실행은 React StrictMode 라서 `useEffect(() => load())` 가 두 번 돈다. main 은 첫 요청에서 값을 지우고, 두 답 중 값이 없는 쪽이 먼저 그려지면 화면은 처음 그릴 때만 그 값을 읽으므로 끝내 모른다 (두 답의 도착 순서는 파일 읽기 속도에 달려 있어 들쭉날쭉).
- 화면 테스트는 빌드본(StrictMode 없음)으로 돌아서 잡지 못한다. 사용자는 개발 실행(`npm run dev`)으로 쓴다.
- 대응: 한 번만 주고 지우지 말고, 창을 연 뒤 잠깐(`OPEN_HINT_MS` 5초) 동안의 모든 load 에 준다 (`src/remoteFiles/documents.js`). 단위 테스트에서 load 두 번을 동시에 보내 둘 다 값을 받는지 본다.
- 일반화: main 이 상태를 "읽으면 지우는" 방식으로 창에 넘기는 곳은 StrictMode 의 두 번 요청을 견디는지 본다.
